# Canvas spec: sysdesign-m6-gateway-jobs

- **Course and chapter:** system-design, 6.6 ("API gateways"), beat 4 "Switch gateway jobs on and off". New slug.
- **Renderer:** custom beat canvas on `BeatFrame`, with `SvgNode` cards, `SvgButton` blocks, `DotGrid`, `VerdictBanner` and `BeatButton` (Replay). Custom because the picture is a gateway of tappable switches between three callers and three services.
- **Claim:** A gateway should run the checks every service shares and nothing that needs a service's data.
- **Model** (`models/gateway-jobs.ts`): six jobs, each on or off: TLS (on), token check (on), rate limit (on), request id (on), order rules (off), routing (on). Three callers: Huda (GET /orders/512, valid token), a scraper (valid token, a burst of 6) and a stranger (no token, POST /payments). A request passes every job that is on, top to bottom. The hop as a whole costs about 50 microseconds [S3]; no per-job time is shown. If routing is off the gateway does not forward, so callers go straight to each service and none of the gateway's checks stand in the way.
- **Inputs:** tap a block to switch it (the blocks are the controls, each a switch). Replay outside the picture.
- **Picture:** the callers on top, the gateway in the middle with its six jobs, the services below. The line from each caller to its service runs behind the opaque gateway. Requests are dots outside the gateway; inside it the jobs they pass light up one after another, and the job that stops a request turns red. Service pills carry the result: Search "limited: 429" or "flooded" (and a pile of dots), Payments "blocked: 401" or "stranger in", Orders "order 512 ok" or "no request id". Caller pills show "plain text" (TLS off) or "calls direct" (routing off). Order rules on draws a red dashed arrow from the gateway to Orders with the label "copy of / every order".
- **Verdicts (first matching, in this order):** token check off "Anyone can call payments"; rate limit off "Scraper floods search"; TLS off "Traffic readable on the wire"; routing off "Client must know every service"; request id off "No id to trace this request"; order rules on "Gateway now needs every order"; default "Thin gateway: checks, then routes".
- **Playback:** 7.5 second loop; after a switch the settled picture shows and the replay starts 0.9 seconds later. Under reduced motion no dots move and the pills and verdict tell the result.
- **Accessibility:** each block is a `role="button"` with `aria-pressed` and a label that says the job, its state and what a tap does.
- **Sources:** [S3] proxy hop; [S30] API Gateway; [S31] nginx limits.
