# Canvas spec: product-m6-said-or-built

- **Course and chapter:** product-sense, 6.2 "Design skills and agents that build screens", beat 5.
- **Renderer:** custom, on the reusable specimen compare beat (`primitives/specimen-beats.tsx`, two versions shown as a switch). This folder holds only data. Reason: the learner should see a tool's own list next to what a check finds, one claim at a time.
- **Claim:** A tool's stated reason is a claim. In one study of five tools, about a quarter of stated design reasons were not in the finished interface [B9]. Open the page and measure.
- **Model:** a list of three claims for a made-up first draft of Halaqa's home screen (fictional): body text is 16 px; hint text passes 4.5 to 1; Join buttons are 44 px tall. First view: the tool's list. Second view: the same claims with a pill each: measured 14 px (bad); measured 3.03 to 1, the grey #949494 on white from the 2.5 table (bad); measured 44 px (good).
- **Versions:** Tool said, Measured. Verdicts: "Three claims from the tool" (accent), "2 of 3 claims did not hold" (bad).
- **Inputs:** tap the switch (or Tab and Enter).
- **What changes:** each claim gains a measured result.
- **What the learner should notice:** one claim holds and two do not, and the tool's calm list looked the same before and after. Only the measurement told them apart.
- **Accessibility:** each version has a one-sentence alt; a polite live region reads the version, the alt and the verdict; the switch buttons are real buttons. Results are words in the pills, not colour alone.
- **Limits (fold):** the list and the measurements are invented for the lesson. The study is one study of five tools, so it is no rate for any one tool [B9]. Halaqa is fictional.
- **Sources:** AIES 2026, 120 interfaces from five tools [B9]; NN/g on AI prototyping tools [B8]; WCAG 2.2 1.4.3 [A1].
