# Canvas spec: sysdesign-m22-send-a-message

- **Course and chapter:** system-design, 22.1 beat 1 ("A message is easy to send").
- **Renderer:** `scene` (data only).
- **Claim:** Sending a chat message is two small facts the sender can see: the server has it (one tick), and the other phone has it (two ticks).
- **Story:** Layla's phone sends "are you ok?" to Dardasha. Dardasha saves it and replies "sent", so Layla sees one tick. Dardasha passes the message to Sami's phone, Sami's phone confirms, and Layla sees two ticks. Verdict: "Sent, then delivered: two ticks".
- **Numbers:** None. Names and the story are made up.
- **Sources:** None needed (set-the-scene story).
