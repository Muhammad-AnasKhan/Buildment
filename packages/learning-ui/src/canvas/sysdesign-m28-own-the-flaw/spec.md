# Canvas spec: sysdesign-m28-own-the-flaw

- **Course and chapter:** system-design, 28.3 beat 4 ("When you are wrong, say so").
- **Renderer:** `scene` (data only).
- **Claim:** When the interviewer finds a real weakness, name it in one sentence, then either show it is inside the agreed scope or change the design, and say what the change costs.
- **Story:** The interviewer asks "can I guess codes?". The candidate says "yes: counters", then sends "scope: links public" and "private: random". The interviewer says "good, noted". Verdict: "Own it: scope it or fix it".
- **Numbers:** None.
- **Sources:** Chapter 20.3 (counter codes are guessable; private pastes need random codes).
