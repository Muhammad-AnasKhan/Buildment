# Canvas spec: product-m2-line-height

- **Course and chapter:** product-sense, 2.3 "Type that reads on a phone", the second beat (an extra canvas).
- **Renderer:** custom, on the reusable specimen compare beat. This folder holds only data. Reason: line height is easiest to judge by looking at the same paragraph at different values.
- **Claim:** A line height of about 1.5 makes it easy for the eye to find the start of the next line. At 1.0 the lines crowd each other. At 2.2 the lines drift apart and the paragraph starts to look like separate lines.
- **Model:** one paragraph (a Halaqa group description, 31 words) under a 17 bold title, set at 15 with a line height of 1.0, 1.5 and 2.2 times the text size. Verdicts: "Lines crowd each other" (bad), "Easy to follow each line" (good), "Lines drift apart" (warn). Page heights: 233, 270 and 323 units.
- **Inputs:** three pills (Tight, About 1.5, Loose).
- **What changes:** the space between lines, the height of the page and the verdict.
- **What the learner should notice:** the words and the size are the same in all three; only the space between lines changes.
- **Accessibility:** the pills form a labelled group; a polite live region reads each version and verdict; the SVG has a title; text at least 11 units.
- **Limits (fold):** the best line height depends on the font and the line length; the verdicts are practice advice, not a measured result; Halaqa is fictional.
- **Sources:** Material 3 line height about 1.5 for body text [A36]; Tailwind's default body line height 1.5 [A50]; WCAG 1.4.12 requires content to survive a line height of 1.5 [A14]; one typography guide suggests 120 to 145 percent [A34].
