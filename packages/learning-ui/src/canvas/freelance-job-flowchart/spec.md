# Lina's flowchart for a freelance offer

- **Slug:** `freelance-job-flowchart`
- **Course:** Think Clearly, chapter 2.5 "Flowcharts: draw a decision".
- **Teaching claim:** A flowchart turns a decision into questions with yes and no paths, so anyone who follows it reaches the same result for the same facts, and you can explain every step.
- **Renderer:** state machine. The boxes are the flowchart's steps and questions; each arrow is labelled with the answer that leads to it.

## Model

Five boxes: Deadline fits?, Ask for time, Pay fair?, Accept, Decline politely. Six arrows. Two end boxes. The first step shows the offer arriving at the first question. The walk-through follows one offer (40 dollars, 2 days) through the no path at the deadline, the detour to ask for time and the yes path at pay. The last step is a second offer (5 dollars) that ends at Decline politely.

## Learning interaction

- **What this shows:** each question box and the answer that picks the next arrow.
- **Try this:** predict the arrow at the deadline question; find the path when the client refuses more time.
- **Limits:** only two questions; a real flowchart could ask more.

The chapter puts a Predict before the canvas and a quiz question after it.

## QA
