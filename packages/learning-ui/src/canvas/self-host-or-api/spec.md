# Self-host or call an API

- **Slug:** `self-host-or-api`
- **Course:** AI Engineering Interview, chapter 11.7 "Beyond one GPU, and choosing how to serve".
- **Teaching claim:** Whether to self-host or call a hosted API depends on how much you weight data control, cost at steady high volume and control of latency and model version against team effort and time to launch. Neither wins on every weighting.
- **Renderer:** factor (export `selfHostOrApi`). Two options, five criteria, three weight levels.

## Model

`total(option) = sum over criteria of weight x score`, from `renderers/factor/model.ts`. Scores are the example's own judgement on a 1 to 5 scale, where a higher score is better for that option. They are not measurements.

| Criterion | Hosted API | Self-hosted engine |
|---|---|---|
| Data stays in network | 2 | 5 |
| Low cost at volume | 2 | 4 |
| Low team effort | 5 | 1 |
| Fast to launch | 5 | 2 |
| Latency and version control | 2 | 5 |

Weights: 1 nice to have, 2 important, 3 very important. Default weights are all 2. Worked values: default 32 to 34 (self-hosted by 2). Data 3: 34 to 39 (self-hosted by 5). Data 3, effort 3, launch 3: 44 to 42 (hosted API by 2). All 1: 16 to 17. All 3: 48 to 51. Highest possible total 75.

## Learning interaction

- **What this shows:** two total bars, the leader and margin, and one weight control per criterion with its score x weight line.
- **Try this:** raise data to 3 (self-hosted leads 39 to 34); keep that and raise effort and launch to 3 (hosted API leads 44 to 42).
- **What changed:** generated by `describeChange` in `renderers/factor/model.ts`, for example "You raised Data stays in network from 2 (important) to 3 (very important). That moved Hosted API +2 points, Self-hosted engine +5 points. Self-hosted engine still leads, now by 5 points."
- **Limits:** the scores and weights are the example's judgement for one team and one assistant, treated as exact; model quality, reliability, contract terms and the break-even volume are left out; real choices rest on the team's own numbers.

The chapter puts a predict right before the canvas and a transfer quiz after the copy blocks. The chapter's prose and table teach the claim without the canvas.
