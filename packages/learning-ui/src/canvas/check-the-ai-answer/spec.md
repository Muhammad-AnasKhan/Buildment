# Huda checks an AI answer about a scholarship

- **Slug:** `check-the-ai-answer`
- **Course:** Think Clearly, chapter 7.4 "Check the AI's answer".
- **Teaching claim:** An AI answer can sound sure and still be wrong. Three checks catch most problems: do the rough numbers agree, where does it come from, and what does the source itself say. A name of a source is not a source.
- **Renderer:** sequence (three lanes: Huda, AI tool, Source).

## Model

Eight steps. The AI answer has an internal mismatch (2,000 per month for 12 months cannot total 2,400), so the rough-number check finds that something is wrong. Asking for the source returns only a name. The source page gives a different deadline (1 March, not 15 March) and 200 per month, and its numbers agree (200 x 12 = 2,400). The scholarship is fictional.

## Learning interaction

- **What this shows:** each check as a message or a loop on Huda's lane.
- **Try this:** do the multiplication before step 3; say which check found the wrong deadline and why rough numbers could not.
- **Limits:** real sources can be old, hard to find or wrong; ask the organisation directly when unclear.

The chapter puts a Predict before the canvas and a quiz question after it.
