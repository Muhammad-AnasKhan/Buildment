# Canvas spec: product-m2-one-step

- **Course and chapter:** product-sense, 2.4 "Space does the grouping", the fourth beat (an extra canvas).
- **Renderer:** custom, on the reusable specimen compare beat. This folder holds only data. Reason: "use only the multiples of one step" is a claim about how a screen looks, so the learner should see a list with wandering gaps next to the same list with steady ones. It replaces a diagram that only listed the multiples.
- **Claim:** When every gap comes from one step, the list has a steady rhythm and groups show. When the gaps are arbitrary (5, 17, 6, 13, 9), the list looks slightly off, even if nobody can say why.
- **Model:** the same three Halaqa groups (a name at 14 semibold and a time and place at 12.5 grey) under a "Study groups" header. Strays: the gaps are 5 inside the first group, 17 between the first and second, 6 inside the second, 13 between the second and third, and 9 inside the third. One step: 4 inside every group and 24 between groups, all multiples of 4. Verdicts: "The gaps wander" (warn), "One step, steady rhythm" (good).
- **Inputs:** two buttons (Strays, One step).
- **What changes:** the gaps and the verdict. The words are the same.
- **What the learner should notice:** the second list looks calmer and its groups show; the first looks uneven.
- **Accessibility:** the two buttons form a labelled group; a polite live region reads each version, its description and verdict; the SVG has a title; text at least 12.5 units.
- **Limits (fold):** a step is a convention for consistency, not a test result; the effect is small at a glance; the amounts are drawn units; Halaqa is fictional.
- **Sources:** Material 3 on consistent spacing [A90]; the 4 dp and 8 dp conventions [A40] and Tailwind's 0.25rem unit [A49], as practice.
