# Canvas spec: product-m2-three-sizes

- **Course and chapter:** product-sense, 2.2 "One thing first: visual hierarchy", the third beat (an extra canvas).
- **Renderer:** custom, on the reusable specimen compare beat. This folder holds only data. Reason: "no more than three sizes" is easier to believe when the learner switches between one, three and six sizes of the same page.
- **Claim:** With one size nothing comes first. With three sizes (a large title, a medium detail size, a small note) the order of the lines is clear. With six sizes set out of order of importance, the sizes compete and the eye has no order to follow.
- **Model:** one Halaqa group page (title, when and where, seats left, a one-line description, host, a Join button) in three versions. Weight and colour are identical on all three pages (every line regular, normal text colour), so size is the only thing that changes. 1 size: every line at 14. 3 sizes: title 22, details and description 16, host note 13, button 16. 6 sizes: title 15, when 21, seats 11, description 13, host 28, button 18, so the least important line is the largest and the name is small. The words are the same in all three. Verdicts: "Flat: no order" (bad), "The order is clear" (good), "Sizes ignore importance" (warn).
- **Inputs:** three pills (1 size, 3 sizes, 6 sizes).
- **What changes:** the screen and the verdict.
- **What the learner should notice:** order comes from a few clearly different steps that follow importance, not from many small differences. Size alone, with weight and colour held the same, is enough to make or lose the order.
- **Accessibility:** the pills form a labelled group; a polite live region reads each version and verdict; the SVG has a title; text at least 11 units.
- **Limits (fold):** the three-size guide comes from one source and a long page may need more steps; sizes are drawn units, not pixels; Halaqa and its people are fictional.
- **Sources:** NN/g on visual hierarchy, no more than three sizes [A69].
