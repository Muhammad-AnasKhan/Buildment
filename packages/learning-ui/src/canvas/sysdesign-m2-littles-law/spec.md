# Canvas spec: sysdesign-m2-littles-law

- **Course and chapter:** system-design, 2.5 beat 4.
- **Renderer:** `scene` (data only).
- **Claim:** Little's law: the average number inside equals arrival rate times average time inside.
- **Story:** Requests stream in at 200 per second, each staying 50 ms; the server's second line settles at 10 inside. Verdict: "L = 200/s x 0.05 s = 10".
- **Numbers:** 200 x 0.05 = 10 (illustrative rate and time).
