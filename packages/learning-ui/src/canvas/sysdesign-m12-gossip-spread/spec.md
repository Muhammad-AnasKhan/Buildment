# Canvas spec: sysdesign-m12-gossip-spread

- **Course and chapter:** system-design, 12.8 ("Gossip and failure detection"), beat 2 "Drag the size and the fanout". New slug.
- **Renderer:** custom beat canvas on `BeatFrame`: a sample-dot panel, a growth curve drawn in the picture, two `RailSlider` rails (cluster size on a log rail, fanout on an even rail), one `SvgChip` toggle "Suspect a healthy node", `DotGrid`, `VerdictBanner`, the beat clock for the playhead. Model: `models/gossip-spread.ts`.
- **Claim:** Gossip reaches every node in about log N rounds, with a fixed load per node. A bigger fanout cuts the rounds. A false suspicion spreads as fast as true news, so the suspicion time must be longer than the spread.
- **Model:** one node knows at round 0. Each round every informed node tells f other nodes picked at random. The expected number informed follows x(r+1) = x + (N - x) x (1 - (1 - 1 / (N - 1))^(f x x)), x(0) = 1. Rounds to reach everyone = the first round with N - x below 0.5.
- **Inputs:** cluster size 7, 16, 100, 1,000, 10,000 (default 100); fanout 1, 2, 3 (default 1). Arrow keys move one snap point; Home and End jump to the ends.
- **Numbers (model; the simulation in the chapter agrees within 0.5 round):** N = 7: 5, 3, 3. N = 16: 7, 5, 4. N = 100: 12, 7, 6. N = 1,000: 18, 11, 8. N = 10,000: 24, 14, 11 (fanout 1, 2, 3). Curve for N = 1,000, f = 1: 1, 2, 4, 8, 16, 31, 61, 117, 215, 367, 562, 751, 882, 951, 981, 993, 997, 999, 1,000.
- **False suspicion:** the toggle marks one healthy node as suspected at round 0. The rumor follows the same curve; the target hears it by the time half the cluster knows (first round with x at least N / 2; round 10 for N = 1,000, f = 1) and starts its correction, which needs the same number of rounds again (18). Mixed for 10 + 18 = 28 rounds. The picture draws the rumor in red and the correction in green, and the card reads "suspicion time must be above 28 rounds".
- **Picture:** left, a panel of up to 49 sample dots that light in a scattered order as the playhead moves (blue; red for the false rumor, green where the correction has arrived); right, the curve of the share who know against rounds (axis 0 to 30 rounds, 0 to 40 with the rumor), with a dashed marker and a label at the round when everyone knows. Two cards: "rounds to reach everyone" and "messages per node per round" (the fanout). The playhead moves 2.5 rounds a second and rests for 3 rounds at the end.
- **Verdicts:** "1,000 nodes hear it in 18 rounds" (good); with the rumor running "A false rumor spreads just as fast" (warn), and when the playhead reaches the end "Correction done after about 28 rounds" (good).
- **Reduced motion:** the playhead sits at the end: the curve is drawn complete, every dot is lit (green for the rumor), and the verdict is the final one.
- **Accessibility:** both rails are sliders with value text "1,000 nodes, fanout 1, 18 rounds"; the toggle is a real button with a pressed state; the SVG description gives the figures.
- **Sources:** infection-style spread and suspicion in SWIM [S72]. The round counts are the course simulation. The log N shape is flagged as a source needed note in the chapter.
