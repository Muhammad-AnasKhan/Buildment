# Canvas spec: product-m2-colour-jobs

- **Course and chapter:** product-sense, 2.5 "Colour with a job, contrast you can measure", the first beat (an extra canvas).
- **Renderer:** custom, on the reusable specimen compare beat. This folder holds only data. Reason: "colour with a job" is clearer when the learner sees a page where every part has a colour and the same page with one.
- **Claim:** When every part has its own colour, no colour means anything and nothing leads. When one accent colour is kept for the main action, colour tells the reader where to act.
- **Model:** a Halaqa group page. Many: four status pills in four tones (open, 2 seats left, exam Thursday, library), a Join button beside a red Report button, and a Share button. One accent: three neutral pills, one filled Join this group button, an outlined Share button and a plain Report a problem. The words are almost the same; only the use of colour changes. Verdicts: "Every part has a colour" (bad), "Colour means: act here" (good).
- **Inputs:** two buttons (Many, One accent).
- **What changes:** the colours and the verdict.
- **What the learner should notice:** in the first page the red pill says "Exam Thursday", which is not an error; red has no job there.
- **Accessibility:** the two buttons form a labelled group; a polite live region reads each version and verdict; the SVG has a title; text at least 11 units. Status is also written in words in both versions.
- **Limits (fold):** one accent is a start, not a law; a product can have a second colour with a clear job, such as red for a destructive action; the colours are the reader's theme colours; Halaqa is fictional.
- **Sources:** the course's own practice, with the contrast bars from WCAG 1.4.3 and 1.4.11 [A1, A2] and "never colour alone" from WCAG 1.4.1 [A3].
