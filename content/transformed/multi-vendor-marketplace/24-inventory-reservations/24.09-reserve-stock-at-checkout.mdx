# 24.09 — Reserve stock at checkout

Wire reservations into the same handler that today creates orders and a PaymentIntent. Order of operations matters: **validate cart → reserve all lines → persist checkoutId on PI metadata → create PI**.

## Step 1 — Service module

Create `server/modules/inventory/reserve.js`:

```javascript
import mongoose from 'mongoose';
import { StockReservation } from '../../models/stockReservation.model.js';
import { Product } from '../../models/product.model.js';
import { getActiveHeldQuantity } from './atp.js';
import { RESERVATION_TTL_MINUTES } from './constants.js';

export async function reserveForCheckout({ checkoutId, lines, paymentIntentId = null }) {
  const expiresAt = new Date(Date.now() + RESERVATION_TTL_MINUTES * 60_000);
  const session = await mongoose.startSession();
  session.startTransaction();
  try {
    for (const line of lines) {
      const product = await Product.findById(line.productId).session(session);
      if (!product) throw Object.assign(new Error('PRODUCT_NOT_FOUND'), { status: 404 });
      const held = await getActiveHeldQuantity(product._id);
      const available = product.stockQty - held;
      if (line.quantity > available) {
        throw Object.assign(new Error('INSUFFICIENT_STOCK'), {
          status: 409,
          productId: product._id,
          available,
        });
      }
      await StockReservation.create(
        [{
          productId: product._id,
          storeId: product.storeId,
          quantity: line.quantity,
          checkoutId,
          paymentIntentId,
          expiresAt,
          status: 'active',
        }],
        { session }
      );
    }
    await session.commitTransaction();
  } catch (err) {
    await session.abortTransaction();
    throw err;
  } finally {
    session.endSession();
  }
}
```

Adapt field names (`storeId`, line shape) to match your cart module from Chapter 16.

## Step 2 — Checkout handler

Generate a stable `checkoutId` (UUID) per attempt. Call `reserveForCheckout` **before** Stripe `paymentIntents.create`. Put `checkoutId` in PaymentIntent metadata for webhook correlation.

On 409, return JSON:

```json
{
  "error": "INSUFFICIENT_STOCK",
  "productId": "...",
  "available": 0
}
```

Client should toast and refresh product/cart — do not send the user to Stripe.

## Step 3 — Client copy

When `availableQty < cart quantity`, disable increment button on cart lines (Chapter 17 UI tweak).
