## Chapter 3 — Why MongoDB checklist (gate)

### Checklist

- [ ] **Why** this marketplace uses MongoDB instead of starting from SQL (domain + course path + document aggregates — not "because MERN")
- [ ] **One case** where PostgreSQL might be the better tool for a marketplace
- [ ] Difference between **reference** and **embed** with FreshMarket examples
- [ ] Why **order lines are embedded** with snapshot fields
- [ ] Why **cart items reference** live products but include `storeId`
- [ ] Why **vendor name is not copied** onto every product
- [ ] Why **profile is separate** from user identity document
- [ ] Grocery fields on product: **unit, stockQty, isPerishable** — why they matter
- [ ] Where **`docs/erd-draft.md`** lives and what it contains
- [ ] `docs/erd-draft.md` committed with diagram
- [ ] Collection inventory table in that file
- [ ] Embed vs reference audit in that file
- [ ] Actor paragraphs (vendor + customer) in that file
- [ ] Actor × collection operations table
- [ ] Seed plan and isolation test list noted (can be brief)

### Learning log — write now

Answer **in your own words** in the fields below:

1. **Why MongoDB for your marketplace?** Give two reasons tied to this project (grocery fields, order embeds, JSON API, etc.) — not generic NoSQL slogans.

2. **Steelman SQL:** What is the **strongest** argument for PostgreSQL for this same product? Why does the course still use MongoDB?

3. **Embed vs reference:** Walk through checkout — what is embedded on the order document, what is referenced, and what gets copied into the snapshot at the moment of purchase?

4. **Denormalisation:** Explain why copying `vendorName` onto every product is dangerous but copying `priceAtPurchase` onto an order line is correct.

5. **Actor isolation:** How does your ERD ensure Vendor A cannot update Vendor B's product? Where is the enforcement point (DB vs application)?

6. **Open question:** One modelling decision you left open for Chapter 5 — what is it and how will you decide?

7. **Diagram:** Paste your Mermaid or link to your diagram file inside the learning log.
