## Step 1 — Create the page

**Route:** `/vendor/products/new`  
**File:** `client/src/pages/vendor/CreateProduct.jsx`

**Title:** Add product  
**Helper text:** "New products start as drafts until you publish."  
**Buttons:** Save product · Cancel (back to list, no save)

---

## Step 2 — Form fields

| Field | Control | Validation |
|---|---|---|
| `name` | text | required |
| `description` | textarea | optional |
| `price` | number | required, > 0 |
| `unit` | select | required — match server enum |
| `weightOrQuantity` | text/number | per your ERD |
| `stockQty` | number | required, ≥ 0 |
| `isPerishable` | checkbox | optional |

**Unit options** — must match server exactly: `each`, `kg`, `g`, `bunch`, `pack`, `litre`

**Do not include** `isPublished` — server defaults to draft (`false`). Publishing comes in 12.9.

**Do not send** `storeId` or `vendorId` — server sets store from JWT.

---

## Step 3 — Wire createProduct()

```
POST /api/products
Authorization: Bearer <vendor-token>
Body: { name, description?, price, unit, stockQty, isPerishable?, weightOrQuantity? }
```

---

## Step 4 — Handle responses

| Status | Action |
|---|---|
| 201 | Navigate to `/vendor/products` — list refetches |
| 400 | Map API errors to fields — keep form values |
| 404 | No store — link to open-shop |

Disable submit while loading. Wait for 201 — no optimistic row (see 12.4).

---

## Step 5 — Verify end-to-end

1. Submit valid product
2. Redirect to list — new row shows **Draft**
3. Compass — Product with correct `storeId`
4. Try invalid price — 400 with inline error

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Send storeId in body | Server derives from vendor's store |
| Auto-publish on create | Draft until 12.9 toggle |
| Unit enum mismatch | Copy exact strings from schema |
| List doesn't refresh | Refetch on navigate back |
