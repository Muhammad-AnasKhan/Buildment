## Step 1 — Create ProductList.jsx

**Route:** `/vendor/products`  
**Title:** "Your products"

Add a primary button: **Add product** → links to `/vendor/products/new` (you build that form in 12.7).

---

## Step 2 — Add listVendorProducts() helper

```javascript
// api/products.js
GET /api/vendor/products
Authorization: Bearer <vendor-token>
```

Parse the response — array of products or `{ products: [...] }` — match your Chapter 11 shape.

---

## Step 3 — Fetch on page load

```
1. setLoading(true)
2. call listVendorProducts()
3. on success → setProducts(data)
4. on error → setError message
5. setLoading(false)  ← always in finally
```

Refetch when returning from create/edit pages.

---

## Step 4 — Build the table columns

| Column | Field | Example |
|---|---|---|
| Name | `name` | Basmati Rice |
| Price | `price` + `unit` | ₹120 / kg |
| Stock | `stockQty` | 50 |
| Perishable | `isPerishable` | Yes/No badge |
| Status | `isPublished` | Draft or Published |
| Actions | — | Edit → `/vendor/products/:id/edit` |

---

## Step 5 — Handle all UX states

| State | Show |
|---|---|
| Loading | Spinner — **not** "no products" |
| Empty (200 + []) | "No products yet" + Add product CTA |
| Error | "Could not load products" + Retry |
| Success | Full table |

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Use GET /products (public) | Vendor inventory = GET /vendor/products |
| Show all vendors' products | Wrong endpoint or missing auth |
| Flash empty during load | Check loading flag first |
| Hardcoded table rows | Always API-driven |
