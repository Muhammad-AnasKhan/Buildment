## Next — Cart API (Chapter 16)

Backend before cart UI (same pairing):

| Chapter 15 (done) | Chapter 16 (next) |
|---|---|
| Customer browses `/shop` | Customer **persists** items in server-side cart |
| Add-to-cart stub logs or toasts | `POST /cart` with productId, storeId, quantity |
| Public `GET /products` | Authenticated `GET /cart` scoped to logged-in user |
| Two store names on grid | Two storeIds on cart lines — checkout split preview |

- `POST /cart` — add item with **productId, storeId, quantity**  
- `GET /cart` — user's cart, populated products  
- `PATCH /cart/:itemId`, `DELETE /cart/:itemId`  
- **User scoping** — User A never sees User B's cart  
- **storeId on line** — multi-vendor grouping for checkout  

Chapter 17 wires detail page button to POST /cart and builds cart page UI.

</Callout>
