## If something fails

| Problem | Likely fix |
|---|---|
| Empty grid | Ch 14 — publish products + seed |
| One store only | Add/publish products for second vendor |
| Filters do nothing | Network tab — params not sent |
| Same products on page 2 | page state not updating |
| Broken images | Ch 13 imageUrl or Cloudinary |
| CORS errors | Server CORS config |

Fix bugs in the relevant earlier lesson — do not patch around API issues in React.
