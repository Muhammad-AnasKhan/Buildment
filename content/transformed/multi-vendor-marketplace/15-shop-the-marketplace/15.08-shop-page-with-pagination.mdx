## Step 1 — Add state to Shop.jsx

| State variable | Purpose |
|---|---|
| `items` | Products on current page |
| `page` | Current page number (start at 1) |
| `limit` | Page size — use **20** to match API default |
| `totalPages`, `total` | From API response |
| `loading`, `error` | UX flags |
| `category`, `storeId` | From filter bar (15.7) |

---

## Step 2 — Fetch when inputs change

When `page`, `category`, or `storeId` changes, call the API:

```javascript
// Pseudocode
const params = {
  page,
  limit: 20,
  ...(category && { category }),
  ...(storeId && { storeId }),
}
const data = await getProducts(params)
setItems(data.items)
setTotalPages(data.totalPages)
setTotal(data.total)
```

Use `useEffect` — or your preferred data-fetch pattern.

</Callout>

## Step 3 — Render the grid

```jsx
<div className="product-grid">
  {items.map(p => (
    <ProductCard key={p.id} product={p} />
  ))}
</div>
```

Use CSS grid — 2 columns on mobile, 3–4 on desktop. Match the editorial layout from 15.2 if you can.

---

## Step 4 — Handle loading, empty, and error

| Condition | Show |
|---|---|
| `loading` | Spinner or skeleton cards — not "no products" |
| `error` | Message + retry button |
| `items.length === 0` && !loading | "No products match your filters" + clear filters link |
| Success | Grid + pagination |

---

## Step 5 — Add pagination controls

**Recommended:** Prev / Next + "Page X of Y"

| Control | Rule |
|---|---|
| Prev | Disabled when `page === 1` |
| Next | Disabled when `page === totalPages` |
| Page text | `Page {page} of {totalPages}` |

When user clicks Next → `setPage(page + 1)` → useEffect refetches.

**Do not** fetch 500 products and paginate in React — the API paginates for a reason.

---

## Step 6 — Connect filters (from 15.7)

When category or store changes:

1. `setPage(1)` — reset to first page
2. Refetch with new params

If you skip resetting page, filter changes can show an empty page (e.g. page 5 of a filtered list with only 1 page).

---

## Step 7 — Multi-vendor proof

Open the shop in your browser. You should see products from **at least two different store names** on the grid at once. If you only see one vendor, check your seed data — not your CSS.

---

## Common mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| Client-side filter on paginated data | Missing products | Refetch API with params |
| No loading state | Flash of empty grid | Show spinner while fetching |
| Page not reset on filter | Empty page after filter | `setPage(1)` on filter change |
| limit: 500 | Slow, breaks pagination | Use limit: 20 |
