A vendor without a shop should not reach `/vendor/products` and get confusing API errors. The layout checks **does this vendor have a store?** and redirects to open-shop if not.

<BigWordAlert term="Redirect guard" plainEnglish="Client logic that sends users to the right page based on auth role and setup completion." whyItMatters="FreshMarket login sends vendors to setup or dashboard depending on store existence." />

Think of it like signing a lease before entering the stockroom.

---

## Step 1 — Gate logic in VendorLayout

On mount (and optionally on route change):

```
1. Not authenticated → /login
2. role !== 'vendor' → customer home (/shop)
3. Current path is /vendor/open-shop → skip store check, render <Outlet />
4. getMyStore()
   - 200 → cache store in context; render <Outlet />
   - 404 → navigate('/vendor/open-shop', { replace: true })
   - 401 → logout / login
```

Use `{ replace: true }` so the back button does not trap the user in a redirect loop.

---

## Step 2 — Which routes need a store?

| Path | Store required? | GET me 404 |
|---|---|---|
| `/vendor/open-shop` | **No** | Stay — show form |
| `/vendor`, `/vendor/settings` | Yes | Redirect open-shop |
| `/vendor/products` | Yes | Redirect open-shop |

While GET me is loading, show a layout spinner — do not flash gated content.

---

## Step 3 — Optional: VendorStoreContext

Shared state helps OpenShop, Settings, and Layout use the same store object:

| State | Used for |
|---|---|
| `store` | Nav display, PATCH id |
| `loading` | Gate spinner |
| `refetch()` | After POST in OpenShop |

After successful open-shop POST: `refetch()` then `navigate('/vendor')`.

---

## Step 4 — Post-login routing

| Role | After login |
|---|---|
| vendor | `/vendor` — gate sends storeless users to open-shop automatically |
| customer | `/` or `/shop` |

Do **not** hardcode open-shop in login handler — the layout owns the gate.

---

## Step 5 — Manual tests (required)

| Test | Expected |
|---|---|
| Fresh vendor → visit `/vendor/products` | Ends on open-shop |
| Fresh vendor on open-shop | Stays on open-shop (no loop) |
| Create shop → navigate dashboard | Gate passes, no manual URL |
| Seed vendor with store | Skips open-shop |
| Customer → `/vendor` | Blocked / redirected |

---

## Common mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| Gate runs on open-shop too | Infinite redirect | Exclude open-shop path |
| No refetch after POST | Stuck on open-shop after 201 | refetch before navigate |
| Spinner never ends | GET me fails silently | Check API URL + CORS |
