Vendor pages share the same header, navigation, and auth checks. Build the **layout once** — then drop in forms in 10.7 and 10.8 without copying boilerplate.

<BigWordAlert term="Vendor layout shell" plainEnglish="Shared sidebar, header, and outlet for all `/vendor/*` pages — consistent dashboard chrome." whyItMatters="Product list, create product, and settings share one layout — shoppers never see this shell." />

---

## Step 1 — Create the folder structure

```
client/src/
  layouts/
    VendorLayout.jsx       ← NEW
  pages/vendor/
    OpenShop.jsx           ← stub for now
    StoreSettings.jsx      ← stub
    VendorHome.jsx         ← optional placeholder
  api/
    stores.js              ← helper stubs
```

---

## Step 2 — Build VendorLayout.jsx

The layout wraps all `/vendor/*` routes and renders child pages through '&lt;Outlet />'.`

**Phase 1 responsibilities (this lesson):**

| Check | Behaviour |
|---|---|
| Logged in? | No → redirect `/login` |
| Vendor role? | Customer → redirect `/shop` or home |
| Store exists? | Stub for now — full gate in **10.9** |
| Nav + header | Dashboard · Settings · Products (stub OK) |
| Child routes | `<Outlet />` renders nested page |

Use `useAuth()` from Chapter 7.

---

## Step 3 — Register nested routes

In `App.jsx`:

| Path | Component |
|---|---|
| `/vendor` | `VendorLayout` (parent) |
| `/vendor/open-shop` | `OpenShop` |
| `/vendor/settings` | `StoreSettings` |
| `/vendor` (index) | `VendorHome` or redirect |
| `/vendor/products` | Stub — "Products in Chapter 12" |

Parent route uses `element={<VendorLayout />}` with child routes nested inside.

---

## Step 4 — Add minimal shell UI

Header should include:

- App name + "Vendor" label
- Nav links: Dashboard · Settings · Products
- Logout button

Keep it clean — match the editorial style from the course intro. No fancy component library required.

## Step 5 — Stub stores.js helpers

```javascript
// api/stores.js — signatures only for now
export async function getMyStore()      // GET /stores/me
```

Match the pattern from your auth API helpers in Chapter 7.

## Step 6 — Page stubs

Do **not** build full forms in this commit.
