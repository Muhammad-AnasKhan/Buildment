This is the most important handler in Week 3. One customer checkout can create **multiple orders** — one per vendor. Your cart UI already showed this split in Chapter 17; now the server enforces it.

## What happens at checkout

## Before you start

Use `GET /cart` to confirm your test customer has items from two different `storeId` values. Make sure the Order model from Chapter 5 exists, the route from 18.9 is mounted, and a customer token can call a protected route. These are the four pieces this step needs.

## Step 1 — Implement checkout(userId) — phase 1

In `orders.service.js`, build the pipeline in this order (snapshots and stock come in 18.11–18.12):

1. **Load cart** — all items for `userId`, product populated
2. **Empty check** — if no items → `400 { message: 'Cart is empty' }`
3. **Group by storeId** — `Map<storeId, lines[]>`
4. **For each store group**, build one Order:
   - `customerId` = userId
   - `storeId` = group key
   - `status` = `'pending'`
   - `orderItems` = copy from cart lines (refine in 18.11)
   - `total` = sum of line totals from current product price
5. **Insert** — `Order.insertMany(orders)` or loop inside transaction
6. **Return** — `{ orders: createdOrders }`

---

## Step 2 — Validate before insert

Reject the checkout with `400` if a product is missing or unpublished, a quantity is below one, or a cart line's `storeId` does not match its product. Check all lines before creating any order so a bad line cannot leave a partial checkout.

Never trust grouping from the client body — read the cart from the database.

## Step 3 — Wire the route

```
POST /api/checkout
Middleware: requireAuth → requireRole('customer')
Body: {} (optional deliveryNote later)
```

Vendor tokens must get **403** on this route.

## Response shape

```json
{
  "orders": [
    { "_id": "...", "storeId": "...", "total": 305, "orderItems": [...] },
    { "_id": "...", "storeId": "...", "total": 40, "orderItems": [...] }
  ]
}
```

Array length = number of distinct stores in cart.

---

## Common mistakes

| Mistake | Result | Fix |
|---|---|---|
| One order with mixed stores | Vendors can't fulfil | groupBy storeId |
| Client sends store groups | Tamperable | Server reads cart |
| Skip empty cart check | Ghost orders | 400 early |
| Vendor can checkout | Wrong role | requireRole('customer') |
