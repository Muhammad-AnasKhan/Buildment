Imagine a customer orders rice at ₹120/kg. Next week the vendor raises the price to ₹150. The customer's **order history** must still show ₹120 — that is what they agreed to pay.

<BigWordAlert term="Immutable order line" plainEnglish="Order line fields frozen at purchase — product document can change later without altering receipt." whyItMatters="Support disputes and vendor payouts rely on accurate historical order line data." />

This lesson implements that rule by **copying** product fields onto each order line at checkout.

## The problem in plain English

| Without snapshot | With snapshot |
|---|---|
| Order stores only `productId` | Order stores `priceAtPurchase`, `nameAtPurchase`, `unitAtPurchase` |
| Vendor edits price → old orders look wrong | Order history stays correct forever |
| Refunds and support become impossible | Production-grade order records |

You read about this trap in **18.2**. This lesson is the fix.

---

## Step 1 — Copy these fields per cart line

When building each `orderItems[]` entry, read the product **once** and copy:

| Snapshot field | Copy from |
|---|---|
| `productId` | `line.productId` |
| `nameAtPurchase` | `product.name` |
| `priceAtPurchase` | `product.price` |
| `unitAtPurchase` | `product.unit` |
| `quantity` | `line.quantity` |
| `lineTotal` | `priceAtPurchase × quantity` |

Order `total` = sum of `lineTotal` in that order.

---

## Step 2 — Never read live price for old orders

After the order is saved:

- Vendor PATCH on product → does **not** update existing orders
- Order status changes (`pending` → `packed`) → does **not** change line prices
- Chapter 20 order history UI reads `priceAtPurchase` — never `product.price`

---

## Step 3 — Verify in Compass

After checkout, open an Order document. Each line should look like:

```json
{
  "productId": "...",
  "nameAtPurchase": "Basmati Rice",
  "priceAtPurchase": 120,
  "unitAtPurchase": "kg",
  "quantity": 2,
  "lineTotal": 240
}
```

---

## Step 4 — Quick immutability test

1. Checkout one product
2. Note `priceAtPurchase` in Compass
3. Change product price in vendor dashboard or Compass
4. Order line **unchanged** — still old price

Document this test in your learning log.

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Store only productId + quantity | Copy all snapshot fields |
| Recompute total from live product on GET | Use stored lineTotal |
| Update snapshots when status changes | Snapshots are write-once |

---

## Verify checklist

- [ ] Compass shows snapshot fields on each line
- [ ] `total` matches sum of line totals
- [ ] Unit visible (`kg`, `litre`, etc.)
- [ ] Product price change does not alter old order
