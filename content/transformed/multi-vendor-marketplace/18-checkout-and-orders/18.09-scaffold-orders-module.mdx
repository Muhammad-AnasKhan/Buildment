## Step 1 — Create the folder

```
server/src/modules/orders/
  orders.routes.js
  orders.service.js
  orders.schema.js    ← optional validation for checkout body
```

---

## Step 2 — Define routes

| Method | Path | Middleware | Handler |
|---|---|---|---|
| POST | `/checkout` | requireAuth, requireRole('customer') | checkoutHandler |
| GET | `/orders/my` | requireAuth, requireRole('customer') | listMyOrdersHandler |
| GET | `/vendor/orders` | requireAuth, requireRole('vendor') | listVendorOrdersHandler |

Match your existing mount style — e.g. `app.use('/api', ordersRouter)`.

Handlers can return **501 Not Implemented** until 18.10 — but routes must **not** 404.

---

## Step 3 — Stub service exports

`orders.service.js`:

| Function | Purpose |
|---|---|
| `checkout(userId)` | Full pipeline — 18.10+ |
| `listOrdersForCustomer(userId)` | Customer history — 18.15 |
| `listOrdersForVendor(userId)` | Vendor inbox — 18.14 |

Keep handlers thin — call service functions.

---

## Step 4 — Checkout body schema (optional)

Body may be empty `{}` for MVP. If you accept optional fields:

```javascript
{ deliveryNote?: string }
```

**Never** accept `customerId` from body — owner comes from JWT only.

---

## Step 5 — Mount and smoke test

1. Start server — no crash
2. `POST /checkout` with customer token → 501 or stub (not 404)
3. Vendor token on customer-only route → 403
