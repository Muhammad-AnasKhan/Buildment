## What you are building

![Cart page — UI preview](/showcase/multi-vendor-marketplace/cart-page.png)

*Production-style UI preview — two store sections, subtotals, estimated total.*

When a logged-in customer opens `/cart`, they should see:

1. Every item they added, **grouped under the store that sells it**
2. A **subtotal per store** (not one confusing grand blob)
3. An **estimated grand total** at the bottom
4. A checkout button that can stay disabled until Chapter 18

This matters because checkout in Chapter 18 creates **one order per store**. If the cart page already shows that split, the customer is not surprised later.

---

## Step 2 — Fetch the cart on page load

When `Cart.jsx` mounts:

1. Set `loading = true`
2. Call `GET /cart` with the customer's Bearer token
3. On success → save `items` in state, set `loading = false`
4. On 401 → redirect to login
5. On network error → show a message with a retry button

<Callout type="warning" title="Show loading, not empty">
While `loading` is true, show a spinner or skeleton. Do **not** show "Your cart is empty" until the request finishes — that confuses students during demos.
</Callout>

Add a helper in `client/src/api/` if you have not yet:

```
getCart() → GET /api/cart
```

---

## Step 3 — Group items by store

The API returns a **flat** `items` array. Your job is to turn it into **sections** for display.

Each item has a `storeId`. Use that as the group key:

```javascript
// Pseudocode — you write the real version
// Input: items from GET /cart
// Output: groups = [{ storeId, storeName, lines: [...] }, ...]

const groups = new Map()
for (const item of items) {
  const key = item.storeId
  if (!groups.has(key)) {
    groups.set(key, {
      storeName: item.store?.name ?? 'Store',
      lines: []
    })
  }
  groups.get(key).lines.push(item)
}
```

Pick a sort order for sections (alphabetical by store name is fine) and note it in your README.

## Step 4 — Build `StoreCartGroup`

**File:** `client/src/components/StoreCartGroup.jsx`

Each group renders:

| What to show | Where it comes from |
|---|---|
| Store name | Section heading — `store.name` from API |
| Product rows | One row per line in that group |
| Store subtotal | Sum of `(price × quantity)` for lines in **this section only** |

Subtotal formula for one line:

```
lineTotal = product.price × item.quantity
```

Use the same currency formatting as your shop pages from Chapter 15.

## Step 5 — Build `CartItemRow` (display only)

**File:** `client/src/components/CartItemRow.jsx`

For this step, rows are **read-only**. You add +/− buttons in 17.6.

Minimum content per row:

- Product name
- Unit + unit price (e.g. `₹120/kg`)
- Quantity (just a number for now)
- Line total (`price × quantity`)

## Step 6 — Empty state

## Common mistakes

| Mistake | What goes wrong | Fix |
|---|---|---|
| Flat list (no grouping) | Customer surprised at checkout split | Group by `storeId` |
| Hardcoded store names | Breaks with real seed data | Use `store.name` from API |
| Empty state during loading | Looks broken for 2 seconds | Check `loading` flag first |
| Skipping protected route | Cart visible without login | Reuse Chapter 7 pattern |
| Client-side-only cart | Items vanish on refresh | Always `GET /cart` from server |
