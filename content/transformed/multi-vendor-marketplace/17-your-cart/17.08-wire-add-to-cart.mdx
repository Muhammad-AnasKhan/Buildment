## Step 1 — Open `ProductDetail.jsx`

You built this page in Chapter 15. Find the add-to-cart button (or add one if it was a stub).

Minimum UI on the detail page:

- Product name, price, unit, stock (already there)
- Quantity picker — default **1**, minimum **1**
- **Add to cart** button

---

## Step 2 — Check login before POST

The cart API requires a logged-in **customer**.

| User state | What happens on click |
|---|---|
| Not logged in | Redirect to login, or show "Log in to add" |
| Logged in | Continue to POST |

Minimum for the gate: unauthenticated users cannot add items.

---

## Step 3 — Call POST /cart

```
POST /api/cart
Authorization: Bearer <token>
Body: { "productId": "<id>", "quantity": <n> }
```

Use `productId` from the loaded product document (or route param — same id).

Add helper:

```
addToCart(productId, quantity) → POST /cart
```

**Success (201):** Item added or quantity merged per your Chapter 16 rules.

---

## Step 4 — Show feedback

After success, tell the user something happened:

| Pattern | OK? |
|---|---|
| Small toast: "Added to cart" | Yes |
| Inline message under the button | Yes |
| Auto-redirect to `/cart` | Discouraged — interrupts browsing |

Staying on the product page with a confirmation message is the best default.

---

## Step 5 — Handle errors

| Status | Meaning | UI |
|---|---|---|
| 401 | Not logged in | Redirect to login |
| 400 | Stock or validation failed | Show the API error message |
| 404 | Product not found | "Product unavailable" |

If `stockQty === 0` on the detail page, disable the add button and show "Out of stock".

---

## Step 6 — Test the multi-vendor path

This is the Week 3 proof:

1. Log in as a customer
2. Open a product from **Vendor A** → add to cart
3. Open a product from **Vendor B** → add to cart
4. Open `/cart` → you should see **two store sections**

If you only ever test one vendor, you will miss the whole point of this marketplace.

---

## Common mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| POST without token | 401 every time | Attach Bearer header |
| Client-only cart array | Items vanish on refresh | Must hit API |
| Wrong product id | 404 | Use id from loaded product |
| No feedback after add | User clicks twice | Show confirmation |
