Every e-commerce site shows a cart icon with a number. Without it, your marketplace feels unfinished — customers forget they already added items.

## Step 1 — Create `CartIcon.jsx`

**File:** `client/src/components/CartIcon.jsx`

Contents:

- A cart icon (SVG or icon library — your choice)
- A small badge with a number when count > 0
- Clicking the icon navigates to `/cart`
- Accessible label: `aria-label="Cart, 3 items"` (update number dynamically)

Mount it in the **customer layout header** — wherever shop and product detail pages already show navigation. Hide it on vendor-only layouts.

---

## Step 2 — Pick your counting rule

You must pick **one** rule and document it in README:

| Rule | What the badge shows | Good for |
|---|---|---|
| **Line count** | Number of rows in cart | "3 different products" |
| **Unit count** | Sum of all `quantity` values | Grocery — "3 kg total items" |

For a grocery marketplace, **unit count** usually matches customer language better (one line with qty 3 shows "3").

---

## Step 3 — Fetch count from the server

Use `GET /cart` — no separate count endpoint required.

```javascript
// Pseudocode
const items = await getCart()
const count = items.reduce((sum, line) => sum + line.quantity, 0)  // unit count
// OR: const count = items.length  // line count
```

Do **not** read from localStorage — the cart lives in MongoDB.

---

## Step 4 — Refresh when things change

Refetch count after:

| Event | Refresh? |
|---|---|
| App load / customer login | Yes |
| After add to cart (17.8) | Yes |
| After PATCH or DELETE on cart page | Yes |
| User logs out | Clear badge to zero/hidden |

Optional: a shared `useCart()` hook so `CartIcon`, `Cart.jsx`, and `ProductDetail` do not duplicate fetch logic. Not required for the gate.

---

## Step 5 — Display rules

| Count | Badge |
|---|---|
| 0 | Hidden or no number |
| 1–99 | Show integer |
| 100+ | Optional `99+` cap |

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Badge never updates after add | Call refresh from ProductDetail success handler |
| Badge shows on vendor dashboard | Only mount on customer layout |
| Count from React state only | Always derive from `GET /cart` |
| Badge survives logout | Clear on logout handler |
