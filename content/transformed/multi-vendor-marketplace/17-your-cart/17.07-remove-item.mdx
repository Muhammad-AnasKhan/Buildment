## Step 1 — Add a Remove control

On each `CartItemRow`, add:

- A **Remove** text link or trash icon
- An accessible label (screen readers need "Remove Basmati Rice from cart")

A confirm dialog is optional for MVP — one click remove is fine.

Disable the button while DELETE is in flight.

---

## Step 2 — Call DELETE /cart/:itemId

```
DELETE /api/cart/:itemId
Authorization: Bearer <token>
```

Again: `itemId` = cart line `_id`, not `productId`.

Helper:

```
removeCartItem(itemId) → DELETE /cart/:itemId
```

**Success:** 204 or 200 — match your Chapter 16 implementation.

---

## Step 3 — Update the UI after success

Simplest approach: **refetch `GET /cart`** and re-render — same pattern as 17.6.

Do not remove the row from React state until the API succeeds (unless you implement optimistic UI with rollback).

---

## Step 4 — Clean up empty store sections

When the last item in a store group is removed:

- Remove the **entire store section** — do not leave an empty "Green Valley Grocers" heading with no rows underneath

When the last item in the whole cart is removed:

- Show the **empty cart state** from 17.5

---

## Step 5 — Align with the − button (17.6)

If you chose "− at quantity 1 calls DELETE" in 17.6, both paths should use the same `removeCartItem` helper. Document this in README.

---

## Error handling

| Status | UI |
|---|---|
| 404 | Refetch cart — item may already be gone |
| 401 | Redirect login |
| Network error | Show retry message |
