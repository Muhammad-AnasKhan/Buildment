**Why this step matters:** Customers close tabs. Networks drop. Your server might crash after Stripe marks a Payment Intent **succeeded** but before `POST /checkout` finishes. Webhooks are Stripe's **retryable phone call** — "this payment really succeeded."

**Where the project is now:** Checkout verifies PI on `POST /checkout`; no webhook route; Stripe cannot notify your app asynchronously.

**After this step:** `POST /webhooks/stripe` accepts raw JSON, verifies `Stripe-Signature` with `STRIPE_WEBHOOK_SECRET`, handles `payment_intent.succeeded` idempotently.

## Route mounting — critical Express detail

Webhook signature uses **raw body bytes**. Your app likely uses `express.json()` globally.

**Spec:**

1. Register webhook route **before** `express.json()` **or** use `express.raw({ type: 'application/json' })` on **only** `/webhooks/stripe`.
2. Pass raw `Buffer` body to `stripe.webhooks.constructEvent(body, signature, webhookSecret)`.

Wrong parser → signature always fails → 400 → Stripe retries forever.

Document mount order in README with one-line diagram.

**No JWT.** Auth is signature only.

## handleStripeWebhook(rawBody, signatureHeader) — contract

**Steps (spec — you implement):**

1. If missing signature header → 400.
2. `constructEvent` — on failure log and return 400 (invalid signature).
3. Switch on `event.type`:
   - **`payment_intent.succeeded`:** extract `paymentIntent.id` from event object.
     - If orders already exist for this PI → return 200 (no-op).
     - Else optionally enqueue checkout or call shared `verifyAndCheckout` **only if** you can resolve `userId` from metadata and cart still valid — **minimum gate:** log + 200; **course gate:** idempotent order creation or documented defer to client checkout retry.
   - **`payment_intent.payment_failed`:** log; 200.
   - **Other types:** 200 ignore (do not 404).
4. Return **200 JSON `{ received: true }`** quickly.

Course expectation: webhook proves **signature verification** and **idempotent handler** — align order creation strategy with 19.13.

## ✅ Do / ❌ Don't

**✅ Do:** Return 200 for events you intentionally ignore — stops endless retries.

**✅ Do:** Use constant-time compare via Stripe SDK — do not roll your own HMAC.

**❌ Don't:** Parse webhook with `express.json()` on same route.

**❌ Don't:** Run 30s checkout transaction synchronously in webhook without idempotency.

**❌ Don't:** Expose webhook URL without signature verify "for testing".
