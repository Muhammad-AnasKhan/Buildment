# 25.10 — Recalculate cart totals

Create `server/modules/pricing/computeCartPricing.js` — single source of truth for cart display and checkout.

## Discount computation

```javascript
function computeDiscountCents(coupon, eligibleSubtotalCents) {
  if (coupon.type === 'fixed_cents') {
    return Math.min(coupon.value, eligibleSubtotalCents);
  }
  let discount = Math.round((eligibleSubtotalCents * coupon.value) / 100);
  if (coupon.maxDiscountCents != null) {
    discount = Math.min(discount, coupon.maxDiscountCents);
  }
  return discount;
}
```

## Line allocation

After `discountTotalCents`, map each cart line:

- Non-eligible lines → `discountCents: 0`
- Eligible lines → proportional share; fix off-by-one on largest line

Return structure from 25.03 for client cart UI: show subtotal, discount row, total.

## Client (Chapter 17 extension)

Add coupon input + “Apply” calling POST `/cart/coupon`. Bind displayed total to **server response only** — remove any local `reduce` that applies discount.
