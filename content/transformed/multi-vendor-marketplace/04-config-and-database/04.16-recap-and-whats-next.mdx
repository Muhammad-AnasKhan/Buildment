## Decisions you can defend in a viva

Prepare short answers:

1. **Why env vars instead of hardcoded URI?** — 12-factor; different per environment; secrets not in Git.

2. **Why validate config at startup?** — Fail fast; clear errors; avoid Mongoose obscure failures.

3. **Why connect before listen?** — Health and first requests assume DB ready; deploy platforms expect dependency order.

4. **Why separate `config.js` and `db.js`?** — Separation of concerns; seed script imports connect without Express.

5. **Why is `MONGODB_URI` server-only?** — Client bundle is public; URI grants DB access.

6. **What does `db: connected` prove?** — Mongoose connection state — not that schemas or data exist yet.
