# 25.03 — What you'll build

> **[Learn]** · Chapter 25 — Promotions & pricing · *Blueprint*

## Collections

**Coupon**

| Field | Notes |
|---|---|
| `code` | Uppercase normalized unique index |
| `scope` | `platform` \| `store` |
| `storeId` | Required when scope is store |
| `type` | `percent` \| `fixed_cents` |
| `value` | 10 = 10% or 1000 = $10.00 |
| `maxDiscountCents` | Cap for percent type |
| `minSubtotalCents` | Minimum eligible subtotal |
| `startsAt` / `endsAt` | Validity window |
| `maxRedemptions` | Global cap |
| `maxRedemptionsPerUser` | Per customer |
| `isActive` | Kill switch |

**CouponRedemption** — append-only `{ couponId, userId, orderId, discountCents, createdAt }` for audits and per-user counts.

## Routes

| Method | Path | Role |
|---|---|---|
| POST | `/cart/coupon` | Apply code → pricing preview |
| DELETE | `/cart/coupon` | Remove applied code |
| POST | `/coupons/validate` | Optional dry-run for UI (same core validator) |

Vendor admin (stretch): `POST /vendor/coupons` — document in learning log if you skip UI and seed coupons.

## Pricing service

`computeCartPricing(cart, user, appliedCoupon)` returns:

```typescript
{
  lines: Array<{ productId, subtotalCents, discountCents, payableCents }>,
  discountTotalCents: number,
  subtotalCents: number,
  totalCents: number,
  coupon: { code, scope } | null,
  errors: []
}
```

## Checkout integration

- Checkout start calls `computeCartPricing` — reject if coupon now invalid (expired mid-session).
- Order documents store `discountCents`, `couponCode`, `pricingVersion: 1`.
- Increment global redemption count in same transaction as order create (or on payment success — pick one and document).

## Abuse controls

- Rate limit `POST /cart/coupon` by IP + user (e.g. 20/min).
- Normalize codes (`trim`, uppercase) to block case variants.
- Do not leak “code exists but not for you” — generic invalid message for wrong store scope.
