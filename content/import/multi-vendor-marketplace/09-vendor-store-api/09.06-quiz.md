# 9.6 — Quiz

The store API establishes the ownership pattern reused by later vendor resources. Check its contracts before scaffolding the module.

```quiz
type: mcq
question: A vendor who already owns a store calls POST /stores again. Which result best expresses the conflict?
options:
  - 201 Created with a second store
  - 409 Conflict because the one-store rule is already satisfied
  - 401 Unauthorized because the vendor is logged in
  - 500 Internal Server Error
correct: 1
```

```quiz
type: mcq
question: Where should vendorId for a newly created store come from?
options:
  - The authenticated user on the server
  - A hidden form field trusted by the route
  - A query parameter supplied by React
  - The requested store slug
correct: 0
```

```quiz
type: mcq
question: Why should /stores/me be registered before /stores/:id?
options:
  - Otherwise the parameter route may interpret me as an ID
  - Express requires alphabetical route order
  - The me route must be public
  - MongoDB reserves the word me
correct: 0
```
