# 15.6 — Product card component

> **[Build]** · Chapter 15 — Shop the marketplace · *Reusable card*

Every product on the shop page appears inside a **ProductCard**. Build it once, reuse it everywhere. This is also where customers first see **which vendor** sells each item — that is what makes it a marketplace.

<BigWordAlert term="Product card component" plainEnglish="Reusable UI showing image, title, price, vendor — links to detail page and add-to-cart." whyItMatters="Same card renders in grid and search results — one component, consistent shop feel." />

---

## Step 1 — Create the file

**File:** `client/src/components/ProductCard.jsx`

**Props:**

| Prop | Type | Required |
|---|---|---|
| `product` | object | yes |

The parent (`Shop.jsx`) passes each product from `GET /products`. The card does **not** fetch data itself.

---

## Step 2 — Know the API shape

From Chapter 14, each product looks like:

```javascript
{
  id: string,
  name: string,
  price: number,
  unit: string,           // e.g. "kg", "litre", "each"
  imageUrl?: string,
  store?: { id: string, name: string }
}
```

---

## Step 3 — Build the layout

| Region | What to show |
|---|---|
| Image | `<img src={imageUrl} />` or a grey placeholder |
| Title | Product name — links to `/shop/${id}` |
| Price line | e.g. `₹120 / kg` |
| Store line | `Sold by Green Valley` — use `store?.name` |

**Tip:** Make the whole card clickable, not just the title — better UX on mobile.

---

## Step 4 — Format price + unit

| API values | Display |
|---|---|
| price 120, unit kg | `₹120 / kg` |
| price 65, unit litre | `₹65 / litre` |

Create a small `formatPrice(price, unit)` helper and reuse it on the detail page later.

---

## Step 5 — Handle missing photos

If `!imageUrl`:

- Show a fixed-height grey box with "No photo" text, or
- Use a simple placeholder icon

Set `object-fit: cover` on images so the grid stays aligned.

---

## Step 6 — Test with one mock product

Temporarily render one card in `Shop.jsx` with hardcoded props — just to check layout. Remove the mock when 15.8 fetches real data.

```jsx
// Temporary smoke test in Shop.jsx
<ProductCard product={{
  id: '1', name: 'Test Rice', price: 120, unit: 'kg',
  store: { id: 'a', name: 'Green Valley' }
}} />
```

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Calling `getProduct(id)` inside each card | N+1 API calls — parent fetches list once |
| Hiding store name | Defeats multi-vendor identity |
| No image fallback | Broken grid layout |
| Filtering unpublished in client | Trust Chapter 14 API — don't duplicate |
