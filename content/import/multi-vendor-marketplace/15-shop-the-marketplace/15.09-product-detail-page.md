# 15.9 — Product detail page

> **[Build]** · Chapter 15 — Shop the marketplace · *Single product + add-to-cart stub*

The shop grid shows a **preview**. The detail page is where the customer reads the full description and decides to buy. You also prepare the **Add to cart** button that Chapter 17 will wire to the API.

## Step 1 — Fetch the product

In `ProductDetail.jsx`:

```javascript
const { productId } = useParams()

// On mount:
// const product = await getProduct(productId)
```

One API call: `GET /products/:id` — do **not** fetch the whole catalogue and search client-side.

---

## Step 2 — Handle loading and errors

| API result | UI |
|---|---|
| Loading | Spinner |
| 404 | "Product not found" + link back to `/shop` |
| Network error | Message + retry |
| Success | Full layout below |

Add: `<Link to="/shop">← Back to shop</Link>`

---

## Step 3 — Build the layout

| Section | Source field |
|---|---|
| Large photo | `imageUrl` or placeholder |
| Title | `name` |
| Price line | `price` + `unit` — reuse formatter from ProductCard |
| Store | "Sold by {store.name}" |
| Description | `description` if API returns it |
| Extra meta | `category`, stock if shown |

---

## Step 4 — Add the Add to cart button (stub)

The button must **exist and look real** — but does not call the cart API yet (Chapter 16 builds the API, Chapter 17 wires the button).

```javascript
function handleAddToCart() {
  // TODO Chapter 17: POST /cart
  console.log({
    productId: product.id,
    storeId: product.store?.id,
    quantity: 1,
  })
  alert('Cart wiring in Chapter 17')
}
```

<Callout type="info" title="Why a stub now?">
You are finishing the **browse** chapter. Cart API comes in Chapter 16. Wiring comes in Chapter 17. Building the button layout now means Chapter 17 is just connecting one onClick handler — not redesigning the page.
</Callout>

**Important:** Make sure `product.store.id` is available — Chapter 16 cart lines need `storeId`.

---

## Step 5 — Optional quantity picker

You may add +/− for quantity (local React state only). Default quantity: **1**. No API call until Chapter 17.

---

## Step 6 — Test both vendors

Open detail pages for:

- A product from **Store A**
- A product from **Store B**

Both should show the correct store name and stub log the right `storeId`.

---

## Common mistakes

| Mistake | Fix |
|---|---|
| POST /cart in Chapter 15 | Wait for Ch 16 API — stub only |
| Fetch all products to find one | Use `GET /products/:id` |
| Missing store.id in stub | Cart needs storeId in Ch 16 |
| No 404 UI | Invalid URL looks broken |
