# 15.12 — Checklist and learning log
> **[Gate]** · Chapter 15 — Shop the marketplace

This is the **gate** for Chapter 15. Tick every box honestly and answer the learning log below before opening Chapter 16.

## Chapter 15 — Shop the marketplace checklist (gate)

Do **not** open Chapter 16 until every box is ticked and learning log answers are written below.

### Routes & navigation

- [ ] `/shop` renders Shop page
- [ ] `/shop/:productId` renders ProductDetail
- [ ] Nav link to shop from home or global header
- [ ] No collision with vendor `/vendor/*` routes

### Shop page

- [ ] Fetches `GET /products` with page, limit, optional category, storeId
- [ ] Renders grid of ProductCard components
- [ ] Loading and error states handled
- [ ] Empty state when no products match filters
- [ ] Pagination controls (Prev/Next or equivalent) using `totalPages`
- [ ] Filter change resets to page 1

### ProductCard

- [ ] Shows imageUrl or placeholder
- [ ] Shows name, price/unit, store.name
- [ ] Links to product detail

### Filters

- [ ] Category filter refetches API with `category` param
- [ ] Store filter refetches API with `storeId` param
- [ ] Clear filters restores full catalogue

### Product detail

- [ ] Fetches `GET /products/:id`
- [ ] Shows image, name, price, unit, store, description if available
- [ ] 404 handling for missing product
- [ ] Add to cart button present — stub until Ch 17 (logs or TODO comment with productId + storeId)

### Multi-vendor browse (gate)

- [ ] Shop grid shows products from **≥2 stores** (seed permitting)
- [ ] Verified in browser — not API-only

### API discipline

- [ ] No duplicate publish/stock filtering in client
- [ ] No per-card detail API calls on grid
- [ ] Uses `client/src/api/products.js` helpers

### Prior gates

- [ ] Chapter 14 public catalogue API complete
- [ ] Chapter 13 images display from Cloudinary URLs
- [ ] Why shop consumes API instead of embedding catalogue logic
- [ ] Why page resets when filter changes
- [ ] Why storeId needed on future cart line (preview Ch 16)
- [ ] Difference customer shop vs vendor product list UI

### Learning log — write now

Answer **in your own words** in the fields below:

1. **Data flow:** Trace one shop page load from React to MongoDB and back — include query params.

2. **Card design:** What fields from API appear on ProductCard? What did you exclude?

3. **Filters:** How do category and store filters map to API params? Where do option lists come from?

4. **Pagination:** How does UI use `total`, `page`, `totalPages`? What happens on last page Next click?

5. **Two vendors:** Name the two stores visible in your browse demo. How did you verify?

6. **Detail page:** Paste stub add-to-cart payload shape you will send in Ch 17.

7. **Errors:** What does UI show for 404 product and network failure?

8. **Chapter 16 preview:** What must cart API store per line besides productId?
