# 16.5 — Quiz

A cart is private user data and a staging area, not a completed sale. Check its trust boundaries before mounting the routes.

```quiz
type: mcq
question: Why keep storeId on a cart line when the product also references its store?
options:
  - It supports grouping lines by vendor during split checkout
  - It lets the client choose any vendor for a product
  - It permanently snapshots the purchase
  - It replaces productId
correct: 0
```

```quiz
type: mcq
question: User B sends User A's cart item ID to PATCH /cart/:itemId. What must the server do?
options:
  - Update it because the ID is valid
  - Reject it because every cart lookup is scoped to the authenticated user
  - Trust an ownerId in the body
  - Copy it into User B's cart automatically
correct: 1
```

```quiz
type: mcq
question: When should FreshMarket treat stock as sold rather than merely requested?
options:
  - When a product page opens
  - When an item is added to a cart
  - During the checkout flow under the course's stock rules
  - When the cart quantity input gains focus
correct: 2
```
