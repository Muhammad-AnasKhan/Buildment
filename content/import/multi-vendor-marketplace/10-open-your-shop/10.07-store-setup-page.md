## Step 1 — Build the form fields

**Route:** `/vendor/open-shop`  
**File:** `client/src/pages/vendor/OpenShop.jsx`

| Field | Required | Notes |
|---|---|---|
| `name` | yes | Trim whitespace — "Green Valley Grocers" |
| `description` | no | Textarea — short pitch for customers |
| `address` | yes (if API requires) | Pickup/delivery area |
| `logoUrl` | no | Text URL for MVP — upload comes later |

Page title: **Open your shop**  
Helper text: one shop per vendor.

---

## Step 2 — Client validation

Before calling the API:

- Block empty `name`
- Show errors next to fields — do not clear the form on failure

Server validation from Chapter 9 is still authoritative — client validation is for faster feedback.

---

## Step 3 — Wire createStore()

```javascript
// api/stores.js
POST /api/stores
Authorization: Bearer <vendor-token>
Body: { name, description?, address, logoUrl? }
```

**Never send:** `vendorId`, `_id` — server sets owner from JWT.

---

## Step 4 — Handle every response

| Status | What to do |
|---|---|
| **201** | Refetch store context → navigate to `/vendor` |
| **400** | Show field errors from API — keep typed values |
| **409** | "You already have a shop" + link to settings |
| **401** | Redirect to login |

Disable the submit button while request is in flight — prevents double-click creating duplicate requests.

---

## Step 5 — Success navigation

After 201:

1. Call `getMyStore()` or refresh auth/store context
2. Navigate to vendor home or dashboard
3. Optional: brief "Shop created" message

<Callout type="warning" title="Refetch before navigate">
If you skip refetching store state, the layout gate in 10.9 may still think you have no store and redirect back to open-shop in a loop.
</Callout>

---

## Step 6 — Test the full path

1. Register a **new** vendor (or delete store in Compass for test user)
2. Log in → should reach open-shop form
3. Submit valid data → 201 → vendor home
4. Check Compass — Store document with correct `userId`

Also test: customer role cannot access this page.

---

## Common mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| Form clears on 400 | User re-types everything | Keep state on error |
| No refetch after 201 | Redirect loop | getMyStore before navigate |
| Send vendorId in body | Security smell | JWT only |
| Double submit | 409 conflict | Disable button while loading |
