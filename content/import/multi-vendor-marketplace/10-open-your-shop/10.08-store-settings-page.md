# 10.8 — Store settings page

> **[Build]** · Chapter 10 — Open your shop · *GET me + PATCH*

Opening a shop (10.7) is a **one-time** POST. Settings is the **ongoing edit** screen — change name, description, or address anytime.

<BigWordAlert term="Settings form" plainEnglish="Edit page for existing store fields — pre-filled from API, PATCH on save." whyItMatters="Vendors update delivery hours and description here without re-running full onboarding." />

## Step 1 — Create StoreSettings.jsx

**Route:** `/vendor/settings`  
**Nav link:** Settings in VendorLayout header

Same fields as open-shop — different page title and save button label.

---

## Step 2 — Load existing store on mount

```
1. setLoading(true)
2. getMyStore() → GET /stores/me
3. 200 → fill form fields; save store._id for PATCH
4. 404 → redirect /vendor/open-shop (no store yet)
5. 401 → redirect login
6. setLoading(false)
```

<Callout type="warning" title="Never hardcode store id">
The `_id` for PATCH comes from GET /stores/me — not from React state you typed manually.
</Callout>

Show a spinner while loading — do not show an empty form during fetch.

---

## Step 3 — Build the save handler

```
onSubmit:
  1. Client validate (same rules as open-shop)
  2. updateStore(storeId, formData) → PATCH /stores/:id
  3. 200 → show "Changes saved"; sync form from response
  4. 400 → map errors to fields
  5. 403 → should not happen for own store — show error banner
```

Optional: PATCH only changed fields. Sending the full body is fine for MVP.

---

## Step 4 — Reuse form fields from OpenShop

Extract shared fields into `StoreFormFields.jsx` if you can — same inputs for POST and PATCH reduces bugs.

| Field | Pre-filled | Editable |
|---|---|---|
| name | ✓ | ✓ |
| description | ✓ | ✓ |
| address | ✓ | ✓ |
| logoUrl | ✓ | ✓ |

---

## Step 5 — Verify persistence

1. Change shop name in settings → Save
2. Hard refresh the page — new name still there
3. curl `GET /stores/me` — matches browser

---

## Common mistakes

| Mistake | Fix |
|---|---|
| Empty form while loading | Show spinner until GET me returns |
| PATCH without store id | Read id from GET me response |
| 404 not handled | Redirect to open-shop |
| Success but stale UI | Update form from PATCH response |
