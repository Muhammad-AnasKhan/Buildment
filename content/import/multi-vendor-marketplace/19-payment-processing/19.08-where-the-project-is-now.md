# 19.8 — Where the project is now

> **[Build]** · Chapter 19 — Payment processing · *Recap Ch 18 checkout API*

**Why this step matters:** Payment touches checkout, cart totals, Order schema, and a new webhook route — this pause confirms Chapter 18 gate is real before you add Stripe dependencies.

**Where the project is now:** `POST /checkout` works without payment — split orders, snapshots, stock, cart clear, list routes. **No** Payment Intents, **no** `stripePaymentIntentId` on orders, **no** webhook. Anyone authenticated can checkout for free.

**After this chapter:** Unpaid checkout rejected; Payment Intent created from cart; checkout verifies `succeeded` with Stripe API; orders marked `paymentStatus: 'paid'`; webhook verifies signatures.

**Pause before Stripe.** Confirm checkout pipeline and schema are ready. This sub-chapter maps what exists and what Chapter 19 adds.

## Order model audit

Open Order schema from Chapter 5 / 18. Add before 19.11:

| Field | Required for Ch 19 |
|---|---|
| `stripePaymentIntentId` | ✓ string, indexed recommended |

**Optional index:** `{ stripePaymentIntentId: 1 }` — speeds idempotency lookup (19.13).

## Pre-payment curl baseline

Logged-in customer with items in cart:

```bash
# Still succeeds today — must FAIL after 19.11
curl -s -X POST http://localhost:5000/api/checkout \\
  -H "Authorization: Bearer <customer-token>" \\
  -H "Content-Type: application/json" \\
  -d '{}'
```

Save this response shape — after 19.11, same call should return **400** with message about missing or unpaid payment.

```bash
# Cart total source of truth
curl -s http://localhost:5000/api/cart \\
  -H "Authorization: Bearer <customer-token>"
```

Note line totals — Payment Intent amount must match **your server's sum**, not a client calculator.
