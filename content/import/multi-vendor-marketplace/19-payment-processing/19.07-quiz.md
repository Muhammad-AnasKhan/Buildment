# 19.7 — Quiz

Payment code must distrust browser totals and tolerate repeated network events. Check the boundary before adding Stripe.

```quiz
type: mcq
question: Where should the amount for a Payment Intent come from?
options:
  - A total submitted by React without verification
  - A server-side calculation from authoritative product and cart data
  - A number typed in the Stripe Dashboard
  - The customer's previous order total
correct: 1
```

```quiz
type: mcq
question: Why does the Stripe webhook route need access to the raw request body?
options:
  - Stripe signature verification depends on the exact received bytes
  - JSON cannot represent payment events
  - Raw bodies bypass authentication
  - It exposes the secret key to the browser
correct: 0
```

```quiz
type: mcq
question: Why must payment-event handling be idempotent?
options:
  - Stripe may retry delivery, and one event must not create duplicate effects
  - MongoDB cannot save payment IDs
  - A customer can use only one card
  - React renders every component twice in production
correct: 0
```
