# 18.8 — Where the project is now

> **[Build]** · Chapter 18 — Checkout & orders API · *Cart with multi-vendor items*

**Why this step matters:** Checkout touches cart, products, orders, and stock in one flow — this pause confirms Order schema snapshot fields and a filled multi-vendor cart exist before you write transaction logic.

**Where the project is now:** Cart API and UI complete (Ch 16–17). Order **model** may exist from Ch 5 but **checkout routes are empty**. No split orders, no snapshots at runtime yet.

**After this chapter:** `POST /checkout` creates one order per vendor with frozen line prices; stock decrements atomically; cart clears; list routes for customer and vendor.

**Pause before checkout.** Confirm cart, models, and auth are ready. This sub-chapter maps what exists and what Chapter 18 adds.

## ✅ Do / ❌ Don't

**✅ Do:** Fix Order schema **before** 18.10 if snapshot fields missing — retrofitting after checkout is painful.

**✅ Do:** Test cart with items from **two stores** before building checkout — split logic needs real data.

**❌ Don't:** Store only `productId` on order lines without `priceAtPurchase` — Chapter 18.2 trap.

**❌ Don't:** Decrement stock before order insert succeeds — order of operations matters in 18.12.
