# 18.7 — Quiz

Checkout turns temporary cart intent into durable records. Check the decisions that keep multi-vendor orders and stock consistent.

```quiz
type: mcq
question: A cart contains products from two stores. How should FreshMarket persist the checkout?
options:
  - One order with no vendor ownership
  - Two vendor-owned orders linked to the same shopper checkout
  - One order per cart line regardless of store
  - No orders until each vendor logs in

```

```quiz
type: mcq
question: Why does each order line store priceAtPurchase?
options:
  - To preserve the charged price if the live product changes later

```
