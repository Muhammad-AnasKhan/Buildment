# 8.7 — Quiz

A logged-in vendor is not automatically allowed to modify every vendor resource. Check the difference between identity, role, and ownership before documenting the rules.

```quiz
type: mcq
question: Vendor B changes a product ID in the URL and reaches Vendor A's product. What server check prevents the update?
options:
  - Verify the product's store belongs to the authenticated vendor
  - Trust the vendorId sent in the request body
  - Hide the edit button in React
  - Confirm only that the requester has any valid token
correct: 0
```

```quiz
type: mcq
question: When is 403 Forbidden more appropriate than 401 Unauthorized?
options:
  - No credentials were sent
  - Credentials are valid, but the user lacks permission for this resource
  - A new resource was created
  - Two stores use the same slug
correct: 1
```

```quiz
type: mcq
question: Why must authorization use the authenticated identity rather than userId from the request body?
options:
  - Request bodies cannot contain IDs
  - A client can alter body fields and impersonate another owner
  - JWTs cannot contain a subject claim
  - MongoDB generates ownership automatically
correct: 1
```

**Next:** Turn these decisions into an authorization matrix you can test route by route.
