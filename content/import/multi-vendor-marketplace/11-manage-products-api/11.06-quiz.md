# 11.6 — Quiz

Product management routes must expose a vendor's complete working catalogue without weakening ownership. Check the boundary before building it.

```quiz
type: mcq
question: Where should storeId for a new product come from?
options:
  - The authenticated vendor's owned store resolved by the server
  - Any storeId in the request body
  - The first store in the database
  - The public product URL
correct: 0
```

```quiz
type: mcq
question: Vendor B tries to patch Vendor A's product. What should the API return after authenticating Vendor B?
options:
  - 200 because both users are vendors
  - 403 because the product is outside Vendor B's ownership chain
  - 401 because Vendor B has a valid token
  - 201 because PATCH creates a copy
correct: 1
```

```quiz
type: mcq
question: Why should GET /vendor/products include unpublished products?
options:
  - Vendors need to manage drafts and paused listings that shoppers cannot browse
  - Unpublished products must appear in public search
  - Publication status belongs only in React state
  - It avoids checking ownership
```
