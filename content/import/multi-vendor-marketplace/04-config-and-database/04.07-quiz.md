# 4.7 — Quiz

Configuration mistakes often look like application bugs. Check that you can separate safe configuration from secrets and make database readiness part of startup.

```quiz
type: mcq
question: Which file is safe to commit for teammates who need to configure the FreshMarket server?
options:
  - server/.env containing working credentials
  - server/.env.example containing variable names and safe placeholders
  - A copy of the production secret manager export
  - A log of the MongoDB connection string
correct: 1
```

```quiz
type: mcq
question: Why should the server connect to MongoDB before it starts listening for HTTP requests?
options:
  - It prevents routes from accepting work while their required database is unavailable
  - It makes every MongoDB query run in the browser
  - It removes the need for error handling after startup
  - It automatically seeds production data
correct: 0
```

```quiz
type: mcq
question: Which value must stay in server-side configuration rather than a Vite client environment variable?
options:
  - The public application name
  - The public API base URL
  - The MongoDB connection string with credentials
  - A UI feature label
correct: 2
```
