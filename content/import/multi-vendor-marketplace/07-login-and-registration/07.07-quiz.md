# 7.7 — Quiz

Browser authentication has failure states that an isolated API test cannot reveal. Check the refresh and route-protection flow before building the screens.

```quiz
type: mcq
question: Why does FreshMarket avoid keeping a long-lived access token in localStorage?

  - localStorage values cannot be strings
  - JavaScript-accessible storage increases the impact of an XSS attack
  - localStorage is sent automatically with every request
  - Vite deletes localStorage in production

```

```quiz
type: mcq
question: What should the API client do after an expired access token causes a 401?
options:
  - Retry forever with the same token
  - Refresh once, retry the original request once, then fail cleanly
  - Treat it as a 403 ownership failure
  - Redirect before asking the server to refresh
correct: 1
```
