# 5.7 — Quiz

The model must preserve both current marketplace data and historical purchase facts. Check the ownership and snapshot choices before you create schemas.

```quiz
type: mcq
question: Why should a Product reference storeId instead of copying the store name as its ownership link?
options:
  - A stable reference preserves ownership even when the store name changes
  - MongoDB cannot store the same string twice
  - Store names are secret configuration
  - It allows customers to edit the vendor
correct: 0
```

```quiz
type: mcq
question: Which data belongs in an order-line snapshot at checkout?
options:
  - Only productId, with every receipt reading the current product later
  - Product name, quantity, and price agreed at purchase time
  - The vendor's password hash
  - The customer's current cart subtotal only
correct: 1
```

```quiz
type: mcq
question: What is the ownership path used to decide whether a vendor may edit a product?
options:
  - Product to customer to cart
  - Product to store to vendor user
  - Product to order to payment
  - Product to category to administrator
correct: 1
```
