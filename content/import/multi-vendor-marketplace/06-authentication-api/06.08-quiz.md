# 6.8 — Quiz

Authentication protects every later private route. Check that password storage and token responsibilities are clear before you implement them.

```quiz
type: mcq
question: Why is bcrypt appropriate for storing FreshMarket passwords?
options:
  - It is deliberately slow and salted, making password guessing more expensive
  - It encrypts passwords so the client can decrypt them
  - It stores the original password inside the hash
  - It removes the need for HTTPS
correct: 0
```

```quiz
type: mcq
question: What should the access-token payload contain?
options:
  - The user's password and database connection string
  - Only claims needed to identify the user and role for a short-lived request
  - Every field from the user document
  - The Stripe secret key
correct: 1
```

```quiz
type: mcq
question: A request has no valid credentials. Which response best fits that failure?
options:
  - 401 Unauthorized because identity was not established
  - 403 Forbidden because ownership was checked
  - 409 Conflict because the email exists
  - 201 Created because the token can be added later
correct: 0
```
