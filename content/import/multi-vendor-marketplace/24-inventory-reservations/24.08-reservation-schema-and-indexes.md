# 24.08 — Reservation schema and indexes

> **[Build]** · Chapter 24 — Inventory reservations · *Model layer*

Create the reservation collection before wiring routes. Correctness comes from a guarded Product
update and a transaction that writes the matching reservation—not from reading availability and
hoping no other request changes it.

## Step 1 — Model file

Add `server/models/stockReservation.model.js`:

```javascript
import mongoose from 'mongoose';

const STATUSES = ['active', 'confirmed', 'released'];

const stockReservationSchema = new mongoose.Schema(
  {
    productId: { type: mongoose.Schema.Types.ObjectId, ref: 'Product', required: true, index: true },
    storeId: { type: mongoose.Schema.Types.ObjectId, ref: 'Store', required: true },
    quantity: { type: Number, required: true, min: 1 },
    status: { type: String, enum: STATUSES, default: 'active', index: true },
    checkoutId: { type: String, required: true, index: true },
    paymentIntentId: { type: String, default: null, index: true },
    expiresAt: { type: Date, required: true },
    confirmedAt: Date,
    releasedAt: Date,
  },
  { timestamps: true }
);

stockReservationSchema.index({ checkoutId: 1, productId: 1 }, { unique: true });
stockReservationSchema.index({ expiresAt: 1, status: 1 });

export const StockReservation = mongoose.model('StockReservation', stockReservationSchema);
```

Export from your models barrel if the project uses one.

The unique checkout/product index makes a retried checkout idempotent instead of creating a second
hold for the same line.

## Step 2 — Add the Product counter

Add this field to the existing Product schema:

```javascript
reservedQty: { type: Number, default: 0, min: 0 },
```

Backfill existing products before relying on the field:

```javascript
await Product.updateMany(
  { reservedQty: { $exists: false } },
  { $set: { reservedQty: 0 } }
);
```

## Step 3 — Constants

Define `RESERVATION_TTL_MINUTES = 15` in `server/modules/inventory/constants.js` (or config) so checkout and worker share one value.

## Step 4 — ATP helper (read path)

Do not aggregate StockReservation on every catalogue read. Serialize availability from the Product
document:

```javascript
export function productInventoryView(product) {
  const stockQty = product.stockQty ?? 0;
  const reservedQty = product.reservedQty ?? 0;
  return {
    stockQty,
    reservedQty,
    availableQty: Math.max(0, stockQty - reservedQty),
  };
}
```

Keep raw counters server-owned. Clients may display them, but they never submit trusted inventory
totals back to checkout.

## Verify

- Restart API; ensure model loads without duplicate index warnings.
- In mongosh, `db.stockreservations.getIndexes()` shows the unique checkout/product index and the expiry sweep index.
- Existing Product rows have `reservedQty: 0`.
