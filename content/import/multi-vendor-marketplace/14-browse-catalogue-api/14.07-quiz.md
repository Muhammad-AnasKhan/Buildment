# 14.7 — Quiz

Public does not mean unbounded or unfiltered. Check the catalogue query contract before implementing the read routes.

```quiz
type: mcq
question: A naive catalogue loads 20 products, then queries each product's store separately. How many database queries does that usually create?
options:
  - 1
  - 2
  - 20
  - 21
correct: 3
```

```quiz
type: mcq
question: Which products should a shopper-facing catalogue return?
options:
  - Every product, including vendor drafts
  - Products that satisfy the public publication and availability rules
  - Only products owned by the current shopper
  - Deleted products referenced by old orders
correct: 1
```

```quiz
type: mcq
question: Why should GET /vendor/products remain separate from public GET /products?
options:
  - The two audiences need different filters, fields, and authorization
  - Express cannot reuse a Product model
  - Public routes cannot accept query parameters
  - Vendors should never see unpublished products
correct: 0
```
