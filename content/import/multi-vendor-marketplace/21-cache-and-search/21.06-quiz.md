# 21.6 — Quiz

A cache is useful only when stale or unavailable data cannot corrupt private state. Check what FreshMarket may cache and how it should fail.

```quiz
type: mcq
question: Why should GET /cart not use the shared public catalogue cache?
options:
  - Cart data is user-specific and changes with each shopper action
  - Redis can store only public strings
  - Cart routes never read data
  - MongoDB automatically caches carts forever
correct: 0
```

```quiz
type: mcq
question: Redis is temporarily unavailable during a catalogue request. What is the safest fallback?
options:
  - Return another shopper's cached response
  - Read from MongoDB and continue without caching that response
  - Fail checkout and delete the cart
  - Treat the empty cache as an empty catalogue
correct: 1
```

```quiz
type: mcq
question: Which fields are useful in a grocery product text index?
options:
  - Searchable product names, descriptions, and relevant category terms
  - Password hashes and JWT secrets
  - Redis connection credentials
  - Customer payment-method data
correct: 0
```
