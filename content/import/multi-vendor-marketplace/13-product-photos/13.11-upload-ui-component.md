# 13.11 — Upload UI component

> **[Build]** · Chapter 13 — Product photos · *File picker → FormData → API*

The API accepts uploads (13.9). This lesson adds the **file picker** on the vendor edit page and **thumbnails** in the product list — the Week 2 demo moment when the shop stops looking like a spreadsheet.

<BigWordAlert term="File input component" plainEnglish="React UI with preview, progress, and error states for selecting and uploading an image." whyItMatters="Vendor edit form embeds this component — UX determines whether vendors actually add photos." />

---

## Recommended flow (simplest)

1. Vendor creates product (Chapter 12) — saves as draft
2. Redirects to **edit page**
3. Uploads photo there (needs `productId` for the route)

Show a hint on create page: *"Save product first, then add photo on the edit page."*

---

## Step 1 — Create ImageUpload.jsx

**File:** `client/src/components/ImageUpload.jsx`

| Prop | Purpose |
|---|---|
| `productId` | POST target |
| `currentUrl` | Show existing thumbnail |
| `onSuccess` | Parent refreshes product state |

**UI elements:**

- File input — accept `image/jpeg,image/png,image/webp`
- Preview of selected file (optional)
- Upload button
- Loading spinner during request
- Error message area

---

## Step 2 — POST with FormData

```javascript
const form = new FormData()
form.append('image', file)

await api.post(`/products/${productId}/image`, form)
// Do NOT set Content-Type header — browser sets multipart boundary
```

Bearer token must still attach via Chapter 7 interceptor — test that multipart requests include Authorization.

---

## Step 3 — Wire into EditProduct.jsx

- Pass `product.id` and `product.imageUrl` to ImageUpload
- On success → update local state or refetch product
- Optional success message: "Photo uploaded"

---

## Step 4 — Add thumbnails to ProductList

| Column | Display |
|---|---|
| Image | 48×48 img with `object-fit: cover` |
| Name | unchanged |

No `imageUrl`? Show grey placeholder — "No photo"

---

## Step 5 — Client-side checks (UX only)

| Check | Message |
|---|---|
| File > 5 MB | Before upload |
| Wrong file type | Before upload |
| No file selected | Disable upload button |

Server still enforces — never skip server validation.

---

## Verify end-to-end

2. Thumbnail appears in list without full page reload
3. Shop page (Ch 15) shows Cloudinary image when product is published
