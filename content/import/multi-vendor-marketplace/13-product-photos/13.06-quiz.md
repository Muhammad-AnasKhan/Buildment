# 13.6 — Quiz

An upload flow crosses browser, API, storage, and database boundaries. Check which data and credentials belong at each boundary.

```quiz
type: mcq
question: What should the Product document store for a Cloudinary image?
options:
  - The full image binary encoded inside every product
  - A delivery URL and the storage public ID needed for lifecycle operations
  - The Cloudinary API secret
  - The browser's temporary file path
correct: 1
```

```quiz
type: mcq
question: Why must Cloudinary's API secret stay on the server?
options:
  - Client bundles can be inspected and would expose the credential
  - React cannot upload files
  - Environment variables work only in MongoDB
  - URLs cannot be returned to browsers
correct: 0
```

```quiz
type: mcq
question: What must happen before Vendor B can replace a photo on a product ID?
options:
  - The server must verify the product belongs to Vendor B's store
  - The client must hide other products
  - The image must be converted to base64
  - The product must be publicly published
correct: 0
```
