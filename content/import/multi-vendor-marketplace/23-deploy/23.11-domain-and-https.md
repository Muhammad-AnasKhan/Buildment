# 23.11 — Domain and HTTPS

> **[Build]** · Chapter 23 — Deploy · *DNS + TLS certificate*

**Why this step matters:** HTTP-only demos fail the gate and break secure cookies from Chapter 7. HTTPS is what makes your URL pasteable in a portfolio without mentors seeing browser security warnings.

**Where the project is now:** API and worker are deployed. Most platforms already provide an HTTPS generated domain; a VPS may still expose only a private application port behind the reverse proxy you are configuring.

**After this step:** The final API origin serves a valid certificate and is the value the client will use. A custom domain is optional; a stable HTTPS platform domain is sufficient for the gate.

## DNS contract

| Record | Points to |
|---|---|
| `api.yourdomain.com` | API host load balancer / VPS IP |
| `app.yourdomain.com` or `www` | Client static host |

PaaS often provides `*.onrender.com` — custom domain optional but professional.

## TLS sources

| Setup | TLS |
|---|---|
| Vercel / Netlify / Render | Automatic |
| VPS + Caddy | Auto Let's Encrypt |
| VPS + Nginx + certbot | Manual renew cron |

**Gate:** Browser and `curl` trust the full certificate chain without bypassing warnings. A self-signed public demo does not pass.

## Certificate renewal

Note auto-renew on PaaS vs certbot timer on VPS — one sentence in README.

## API behind proxy

If Nginx terminates TLS:

```
proxy_pass http://127.0.0.1:5000;
proxy_set_header X-Forwarded-Proto https;
```

Set Express `trust proxy` only for proxies you actually control or trust. This setting changes how Express interprets forwarded protocol and client IP, which affects secure cookies and rate limiting.

## Verify the final origin

- Open `/health` at the final HTTPS origin.
- Inspect the certificate hostname and expiry.
- Confirm plain HTTP redirects to HTTPS if you expose port 80.
- Confirm the API still sees requests as secure behind the proxy.
- Update Stripe's **test-mode** webhook endpoint to the final HTTPS API URL and store its new signing secret.

## ✅ Do / ❌ Don't

**✅ Do:** Wait for DNS propagation — up to 48h, usually minutes.

**❌ Don't:** Ship HTTP-only production URL for gate.
