# 23.8 — Production env checklist

**After this step:** Every required variable documented; production host env configured.

<BigWordAlert term="Production env checklist" plainEnglish="List of env vars, secrets, and URLs that must differ from local dev — verified before go-live." whyItMatters="FreshMarket production needs live MongoDB Atlas, Stripe live keys, Cloudinary, Redis URLs." />

---

## server/.env.example — minimum keys

| Variable | Purpose |
|---|---|
| `MONGODB_URI` | Production database |
| `PORT` | Often set by host |
| `NODE_ENV` | `production` |
| `JWT_ACCESS_SECRET` | Auth |
| `JWT_REFRESH_SECRET` or pepper | Auth |
| `CLOUDINARY_CLOUD_NAME` | Images |
| `CLOUDINARY_API_KEY` | Images |
| `CLOUDINARY_API_SECRET` | Images |
| `REDIS_URL` | Cache — optional if fallback |
| `CLIENT_ORIGIN` or CORS origin | Production client URL |

Add any vars your `config.js` validates — list must match code.

---

## client/.env.example

| Variable | Purpose |
|---|---|
| `VITE_API_URL` | `https://api.yourdomain.com` at build |

---

## Host configuration contract

Copy each key to deploy panel. **No blank required secrets.**

Verify `NODE_ENV=production` on API — affects logging and cookies if secure flag.

---

## Production JWT cookies

If refresh token uses httpOnly cookie (Ch 7), set `Secure` and `SameSite` appropriately for HTTPS cross-origin if client and API on different subdomains.

---

## Commit

```bash
git add server/.env.example client/.env.example README.md
git commit -m "docs: complete production env checklist"
```

---

## ✅ Do / ❌ Don't

**✅ Do:** Cross-check every `process.env` / `config.` read in server code.

**❌ Don't:** Deploy with localhost MongoDB URI.
