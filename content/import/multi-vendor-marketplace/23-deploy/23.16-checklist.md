## Chapter 23 — Deploy checklist (gate)

Do not continue to Chapter 24 until every box is supported by a URL, log, revision, or test result.

### Secrets

- [ ] `git log --all --full-history -- "**/.env"` empty
- [ ] Production secrets only on host env panel
- [ ] `server/.env.example` and `client/.env.example` complete

### Deploy

- [ ] API live at **HTTPS** URL
- [ ] Client live at **HTTPS** URL
- [ ] Worker deployed as a separately supervised long-running process
- [ ] `curl https://api.../health` → 200, `db: connected`
- [ ] Client built with production `VITE_API_URL`
- [ ] CORS allows production client origin
- [ ] Stripe is in test mode; deployed webhook endpoint verifies signatures

### Smoke tests (23.13)

- [ ] Health on production
- [ ] Login on production
- [ ] Browse products on production
- [ ] Add to cart on production
- [ ] Checkout on production
- [ ] Vendor orders visible on production
- [ ] Matching checkout job consumed by the production worker

### Operations

- [ ] Restart/redeploy survival test passed (23.14)
- [ ] Job queued during worker downtime completed after restart without duplicate effect
- [ ] Previous known-good API, worker, and client revisions recorded
- [ ] Low-risk rollback mechanism rehearsed
- [ ] README Deploy section documents your path

- [ ] Chapter 20 browser commerce demo

### Learning log — write now

Answer **in your own words** in the fields below:

1. **Live URLs:** Paste production client URL and API URL (HTTPS).

2. **Host choice:** VPS vs PaaS — what did you pick and why?

3. **Env:** List production env vars set on host — names only, no values.

4. **Build:** How do you build client for production? What if API URL changes?

5. **Smoke test:** Which step was hardest on production? How did you fix it?

6. **Restart:** Describe restart survival test.

7. **Rollback:** Which revisions and configuration would you restore, and what data cannot be rolled back with application code?

8. **Worker recovery:** What proved that a job queued during worker downtime survived and ran once?
