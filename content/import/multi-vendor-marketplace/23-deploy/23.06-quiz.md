# 23.6 — Quiz

Deployment changes origins, URLs, and secret delivery. Check the configuration path before moving FreshMarket off localhost.

```quiz
type: mcq
question: Why must VITE_API_URL be present when the client production bundle is built?

  - Vite substitutes exposed environment values into the client bundle at build time
  - Browsers can read the server's private environment automatically
  - MongoDB injects the API URL after every request
  - CORS creates missing variables

```

```quiz
type: mcq
question: Why must the API CORS configuration include the deployed client origin?
options:
  - The browser enforces cross-origin access against the API response
  - It makes server secrets public
  - It replaces HTTPS
  - It lets every origin send credentialed requests
correct: 0
```
