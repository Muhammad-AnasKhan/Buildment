# 23.6 — Quiz

Deployment changes origins, URLs, and secret delivery. Check the configuration path before moving FreshMarket off localhost.

```quiz
type: mcq
question: Why must VITE_API_URL be present when the client production bundle is built?
options:
  - Vite substitutes exposed env values into the bundle at build time
  - Browsers can read the server's environment variables automatically
  - MongoDB injects the API URL into the bundle after every request
  - CORS creates the missing variables when the bundle loads
correct: 0
```

```quiz
type: mcq
question: Why must the API CORS configuration include the deployed client origin?
options:
  - The browser blocks the cross-origin API read
  - It makes the server's secret keys public
  - It replaces HTTPS with same-origin checks
  - It lets every origin send credentialed requests
correct: 0
```

type: mcq
