```quiz

question: Why does this course use a module-based folder layout under server/src/modules/ instead of a flat controllers/ folder?
options:
  - MongoDB requires a separate folder for every collection
  - Each domain keeps its routes, model, and logic together
  - Vite only resolves imports that live in module folders
  - It removes the need to set any environment variables
correct: 1
```
