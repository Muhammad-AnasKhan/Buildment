# 12.9 — Publish toggle

> **[Build]** · Chapter 12 — Vendor dashboard · *Draft vs Published*

**Draft** = back office only. **Published** = customers can see it in the shop (Chapter 14 filters on this field).

<BigWordAlert term="Publish toggle" plainEnglish="Switch that sets product.isPublished — controls visibility on public shop without deleting." whyItMatters="Vendors hide out-of-season items from shoppers while keeping them in dashboard history." />

The toggle lets vendors control when a product goes live — without deleting it.

---

## Step 1 — Add toggle to edit page

On `EditProduct.jsx`, add a switch or checkbox:

- Label: **Published**
- Bound to `isPublished` field
- Helper text: "Published products appear in the marketplace shop."

You can also save publish state with the main Save button — both patterns work.

---

## Step 2 — PATCH on toggle

```
onToggle(newValue):
  1. setPublishing(true)
  2. updateProduct(id, { isPublished: newValue })
  3. 200 → update local state; show Published/Draft label
  4. error → revert toggle; show error message
```

Optimistic UI is OK here — revert if PATCH fails.

Or batch with other field changes on one Save click.

---

## Step 3 — Show status in product list

Update the Status column from 12.6:

| isPublished | Badge |
|---|---|
| `false` | **Draft** — muted/grey styling |
| `true` | **Published** — green/accent styling |

Refetch list when returning from edit so badges stay current.

---

## What each state means

| State | Vendor list | Public shop (Ch 14) |
|---|---|---|
| Draft | Visible | Hidden |
| Published | Visible | Visible (if in stock) |

---

## Step 4 — Test both directions

1. Create product → should start as **Draft** (server default)
2. Toggle publish → list shows Published; Compass `isPublished: true`
3. Toggle unpublish → back to Draft

Publishing with zero stock is OK — Chapter 14 may hide out-of-stock items from browse.

---

## PATCH body example

```json
{ "isPublished": true }
```

Partial PATCH — can combine with name/price in one request.
