## Chapter 12 — Vendor dashboard checklist (gate)

Do **not** open Chapter 13 until every box is ticked and learning log answers are written below.

### API helpers

- [ ] `api/products.js` — listVendorProducts, createProduct, updateProduct
- [ ] All calls use authenticated client (Bearer / interceptor)
- [ ] Response parsing matches Ch 11 JSON shape

### Product list page

- [ ] `/vendor/products` renders table from GET /vendor/products  
  *Verify:* Only YOUR products — not another vendor's.
- [ ] Columns: name, price/unit, stock, perishable, publish status
- [ ] Loading, empty, and error states implemented
- [ ] "Add product" → `/vendor/products/new`
- [ ] Edit → `/vendor/products/:id/edit`

### Create product page

- [ ] Form: name, price, unit, weightOrQuantity, stockQty, isPerishable
- [ ] POST /products — 201 on success
- [ ] 400 field errors displayed
- [ ] Success → list shows new product as **Draft**

### Edit product page

- [ ] Loads product by id
- [ ] PATCH /products/:id — 200 on success
- [ ] Changes persist after refresh
- [ ] 404/403 handled with clear message

### Publish toggle

- [ ] Publish from edit UI → list shows **Published** badge
- [ ] Compass `isPublished: true`
- [ ] Unpublish back to Draft works

### Onboarding & gate

- [ ] Storeless vendor cannot reach product pages (Ch 10 gate)
- [ ] Vendor with store accesses full product flow

### Verification (12.10)

- [ ] Browser: create draft → edit price → publish — no curl needed
- [ ] Network tab: GET list, POST create, PATCH update/publish
- [ ] Compass matches final UI state

### Prior gates

- [ ] Ch 11 product API + 403 tests still pass
- [ ] Ch 10 store onboarding still works
- [ ] I can explain draft vs published and Ch 14 relationship
- [ ] I can explain why store gate precedes product pages

### Learning log — write now

2. **Create flow:** List form fields and client validations. What happens on 201?

4. **Publish:** Where is toggle UI? What PATCH payload? How does table reflect status?

6. **Routes:** List all vendor product routes in your router.
