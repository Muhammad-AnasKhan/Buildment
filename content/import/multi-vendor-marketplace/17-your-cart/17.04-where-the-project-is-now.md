# 17.4 — Where the project is now

> **[Build]** · Chapter 17 — Your cart · *Cart API ready*

## API contracts to verify before 17.5

Run as logged-in **customer** (not vendor):

<ApiRequestPanel title="Verify cart API before UI">

<ApiRequest
  label="Add item from store A"
  method="POST"
  url="http://localhost:5000/api/cart"
  bearer="<token>"
  body='{"productId":"<id1>","quantity":2}'
  responseStatus={200}
  responseBody='{"items":[{"productId":"...","storeId":"...","quantity":2}]}'
/>

<ApiRequest
  label="Get cart (expect two stores after second add)"
  method="GET"
  url="http://localhost:5000/api/cart"
  bearer="<token>"
  responseStatus={200}
  responseBody='{"items":[{"storeId":"store-a","product":{"name":"..."}},{"storeId":"store-b","product":{"name":"..."}}]}'
/>

</ApiRequestPanel>

**Expected:** Response includes **two items** with different `storeId` values; populated `product` and `store` (or equivalent) for display.

If populate is missing, fix Chapter 16 before building UI — otherwise cart page shows raw ObjectIds.
