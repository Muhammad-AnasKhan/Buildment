```quiz

question: "Tamer writes steps to send a design to a client: 1. Attach the file. 2. Write a short message. 3. Press send. 4. Check that the file is the final version. What is the main problem?"
options:
  - "Step 4 should come first, before he attaches anything"
  - "Step 2 should be removed, since clients do not read it"
  - "Step 3 should come before step 2, to save some time"
  - "Nothing is wrong, because all four steps are there"
correct: 0
explanations:
  - "Right. A check only helps before the file is sent. After step 3, a wrong file is already with the client."
  - "A short message helps the client understand what they received. Removing it does not fix the real problem: the check comes too late."
  - "If he presses send before he writes the message, the client gets no message. This makes it worse."
  - "All the steps are there, but the order is wrong. A check after sending cannot stop a mistake."
```

```quiz
type: mcq
question: "Huda writes steps for a new helper who will make tea for guests. Which step could the helper follow without asking a question?"
options:
  - "Put a little sugar in the tea"
  - "Boil the water until it is ready"
  - "Put 2 spoons of sugar in the pot"
  - "Make the tea the way guests like"
correct: 2
explanations:
  - "'A little' means different amounts to different people. The helper would need to ask how much."
  - "'Until it is ready' does not say what ready means. 'Until it boils' would be clearer."
  - "Right. It names one action and an exact amount. Anyone can follow it the same way."
  - "The helper does not know how these guests like their tea. This step makes them ask."
```

```quiz
type: mcq
question: "What comes next in this sequence: 5, 8, 14, 23, 35, ...?"
options:
  - "47"
  - "50"
  - "44"
  - "70"
correct: 1
explanations:
  - "This adds 12 again. But the change grows each time: 3, 6, 9, 12, so the next change is 15."
  - "Right. The changes are 3, 6, 9 and 12, so each change is 3 more than the last. The next change is 15, and 35 plus 15 is 50."
  - "This adds 9. Check the rule on every item: the last change, from 23 to 35, was already 12."
  - "This doubles 35. Doubling does not fit the earlier items: 5 doubled is 10, not 8."
```

```quiz
type: mcq
question: "A bus leaves the station at 7:10, 7:35, 8:00 and 8:25. If the pattern goes on, when does the first bus after 9:00 leave?"
options:
  - "9:00"
  - "8:50"
  - "9:25"
  - "9:15"
correct: 3
explanations:
  - "The buses leave every 25 minutes, and 9:00 is not one of the times. After 8:25 comes 8:50, then 9:15."
  - "8:50 is the next bus after 8:25, but it leaves before 9:00. The question asks for the first bus after 9:00."
  - "This adds 25 minutes to 9:00, but 9:00 is not a bus time. Count on from the last real time: 8:50, then 9:15."
  - "Right. The rule is 'every 25 minutes'. After 8:25 comes 8:50, then 9:15, which is the first one after 9:00."
```

```quiz
type: mcq
question: "Nour sorts 10 exam papers the slow way: each time, she looks through every paper left to find the highest. How many looks does it take in total?"
options:
  - "100"
  - "10"
  - "55"
  - "45"
correct: 2
explanations:
  - "This is 10 passes of 10 looks. But each pass is one paper shorter than the one before."
  - "This is only the first pass. After it, 9 papers are still left to sort."
  - "Right. 10 + 9 + 8 and so on down to 1. Pair the ends: 10 and 1 make 11, and there are 5 pairs, so 5 times 11 is 55."
  - "This adds 9 + 8 and so on down to 1, and misses the first pass, which looks at all 10 papers."
```

```quiz
type: mcq
question: "Sami's flowchart for leaving home asks 'Is it raining?'. Yes leads to 'Take an umbrella', then to 'Go'. No leads straight to 'Go'. He adds a new question before 'Go': 'Is the bus late?', with only a yes arrow. What is wrong?"
options:
  - "A flowchart can only ask about the weather"
  - "The new question needs a no arrow as well"
  - "The umbrella box should come before the rain question"
  - "Two questions are too many for one flowchart"
correct: 1
explanations:
  - "Flowcharts can ask about anything that has a yes or no answer, such as bus times."
  - "Right. If the bus is not late, there is no arrow to follow and the path stops. Every question needs a yes arrow and a no arrow."
  - "Sami only needs the umbrella if it is raining, so the rain question must come first."
  - "Flowcharts can have many questions. The problem is the missing arrow, not the number of questions."
```
