## Module 4 checklist

- [ ] I can explain why work that is ninety percent finished has little value to the person waiting for it
- [ ] I can name the four checks for a good step: a verb, a visible finish, a day or less, and mine to do
- [ ] I can name the four parts of done: works, tested, documented, handed off
- [ ] I answered the questions in chapters 4.1, 4.2 and 4.3
- [ ] I broke down my own unfinished task, finished the first step, and submitted my report below

## Learning log

1. **Your pattern:** Look at the unfinished task you described in chapter 4.1. Which reason for not finishing fits it best: too big, unclear end, a boring last ten percent, new work, or interruptions?
2. **Your "done":** Think of the last time you told someone a task was done. Which of the four parts of done were really true at that moment?
3. **The last ten percent:** Which part do you most often leave for later: testing, documentation or handoff? Why do you think that is?
4. **Restarting:** What will you write down before you stop work, so that a power cut or a busy week does not cost you your place?

## Finish your first step

Go back to the unfinished task from chapter 4.1. If it is no longer useful to finish, choose another task that someone, maybe you, is still waiting for.

1. Write the end result in one sentence.
2. Break the task into steps. Each step should start with a verb, have a visible finish and fit in a day or less. Include testing, documentation and handoff steps where they apply.
3. Do the first step today or tomorrow, and finish it.
4. Then write your report below. A mentor will review it.
