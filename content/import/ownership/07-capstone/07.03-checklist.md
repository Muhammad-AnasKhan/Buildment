This is the final gate of the course. A plan only helps once you start it, so some boxes ask you to act today. Tick each box only when it is true. Your answers save as you type.

## Module 7 checklist

- [ ] I submitted my improvement plan in chapter 7.2
- [ ] Each goal in my plan has one habit with a minimum version for days with no power or internet
- [ ] I did my first habit at least once, even if only the minimum version
- [ ] My first review date is in my phone calendar or notebook, with what I will check
- [ ] I told my check-in person about my plan and my first review date

## Learning log

1. **Your first habit:** Which habit did you start first? When and where did you do it, and how did it go?
2. **Your first review date:** What is the date, and what exactly will you count and check on that day?
3. **The obstacle most likely to stop you:** Which one is it, and what is your if-then plan for it?
4. **Looking back:** Which module of this course changed how you work the most? Give one example from the last few weeks.
5. **Advice to a new fellow:** If a friend starts this course tomorrow, what is one thing you would tell them about owning their work?
