## Your response to a scenario

Read the scenario, then write your response. A mentor will review it.

Lana works remotely for a small software agency. The agency is late on a project for a client in Germany and needs the final payment. Her manager sends her a message: "The client wants a report on what we tested. Please write that we finished all security testing. We will do it next week, they will never know the difference."

```openquestion
prompt: "Write Lana's response. First, apply the three tests in one or two sentences each. Then write the actual message she should send her manager, using facts, the risk, an alternative and a next step. Finally, say what she should do if the manager insists. You may use a real situation from your own work or study instead, without names."
required: true
minWords: 150
allowSpeechInput: true
modelAnswer: "Newspaper test: Lana would not want the client to see a report that claims testing was done when it was not. Mentor test: any senior developer I respect would say a false security report is a serious problem. Rules test: the contract almost certainly requires honest reporting, and a false claim could create legal trouble for the agency. Message: 'Hi Khalil, I understand we need the final payment soon. I cannot write that security testing is finished, because it is not, and if a security problem appears later, the false report could cost us the client and more. Instead, I can write an honest status: what we tested, what remains, and a firm date next week for the rest. I can draft it today for you to check. Does that work?' If the manager insists, Lana should say no again calmly, keep the messages in writing, and talk to a more senior person in the agency or a trusted mentor before deciding her next step."
```
