```quiz
type: mcq
question: "Ziad's bootcamp team is building a sign-up page for a sports club. Today he wants AI help with four items. A: the club's sheet of 120 members' names, ages and phone numbers. B: the error message the page shows in the browser. C: the settings file, which holds the password for the club's database. D: the club's contract with the bootcamp, marked 'private'. Which item can he paste as it is?"
options:
  - "Item A, since the club asked the team to build the page"
  - "Item B, the error message the page shows in the browser"
  - "Item C, as long as he first switches off the training setting"
  - "Item D, since the bootcamp already has a copy of the contract"
correct: 1
explanations:
  - "Asking for a page is not permission to share 120 members' personal data with an AI company. The sheet fails the stranger test."
  - "Right. The error message has no names, numbers, keys or private terms in it. A stranger could read it and learn nothing about anyone."
  - "The settings file holds a password, and passwords never go in. The training setting does not change that."
  - "The contract is marked private. Having a copy does not make it something to share with a tool the club never chose."
```

```quiz
type: mcq
question: "Aseel, a freelance translator, has 30 Word files of past glossaries in one folder. She asks a chat assistant how to turn them into plain text files. It answers: 'Run this command in the folder. It converts every file to plain text and deletes the original Word files to save space.' What should she do first?"
options:
  - "Run it on all 30 files, since the answer says what the command does"
  - "Ask the chat assistant to confirm the command is safe to run"
  - "Run it, then open a few of the new files to check they look right"
  - "Read the official docs for it, and try it on two copied files"
correct: 3
explanations:
  - "The answer says the command deletes the originals. If the conversion goes wrong, all 30 files are gone, with no copy to go back to."
  - "AI assistants tend to agree with the user, so a second answer from the same tool is not a check. The official docs are."
  - "Checking the new files is good, but by then the originals are already deleted. A mistake would be found too late to undo."
  - "Right. The official docs show what the command really does, and two copied files mean a mistake costs nothing. The 30 originals stay safe until she is sure."
```

```quiz
type: mcq
question: "Yaman volunteers at a clinic desk. He needs to know whether a free spreadsheet app changed its file-sharing rules last week. Three facts: the change, if any, is only a week old; he is 16; he only has his phone's browser. Which choice fits this job?"
options:
  - "A source notebook with last year's guide to the app added to it"
  - "A chat assistant whose own terms say users must be 18 or over"
  - "A search tool with sources, then open the pages it links to"
  - "The phone app of a chat assistant, which he would download first"
correct: 2
explanations:
  - "A guide from last year cannot show a change from last week. A tool that stays inside old sources gives an old answer."
  - "He is 16, so a tool whose terms say 18 or over is not for him, however good it is."
  - "Right. Finding a week-old change needs recent pages, and opening the links checks that they say what the tool claims. It works in his phone's browser."
  - "He only has his phone's browser, so the web version is his path. A download also costs data before he knows if the app opens for him."
```

```quiz
type: mcq
question: "Over one term, Nada wrote 8 lesson plans for her NGO's coding club with a chat assistant. Four facts: the plans exist only in the chat history; the NGO's laptop is shared by five volunteers; she has a free GitHub account; the plans hold no personal data. Where should the plans live?"
options:
  - "In Markdown files she owns, uploaded to a GitHub repository"
  - "In the chat history, since there is nothing private in the plans"
  - "On the shared laptop's desktop, so that the team can find them"
  - "Nowhere yet, until the NGO can pay for a plan of the chat tool"
correct: 0
explanations:
  - "Right. Files she owns, with a second copy on GitHub, survive any change to the chat tool. Since the plans hold no personal data, she can even share the repository with the team."
  - "Nothing private is a reason she may share them, not a reason to keep them in one place. Chat history is exactly how Ahmad lost a month of work."
  - "Five people use that laptop, and one copy on a shared desktop can be moved or deleted by anyone. It is still only one copy."
  - "She does not need to pay. She already has a free GitHub account, and the plans are at risk while they live only in the chat."
```

```quiz
type: mcq
question: "Anas works at a print and copy shop with about 1,500 past orders, each with a customer's name and email. He asks a chat assistant whether he can paste the order list to find repeat customers. It answers: 'Yes, your chats are private and are never read by anyone.' What should he do next?"
options:
  - "Paste the list, since the tool has said that the chats are private"
  - "Check the tool's own help page, and still not paste the real list"
  - "Switch off the training setting, and then paste the whole list"
  - "Ask the chat assistant the same question again to make sure"
correct: 1
explanations:
  - "An AI answer about its own company's rules can be wrong. Some services have people read a sample of chats, and the list holds 1,500 customers' details."
  - "Right. The help page is the source to check, not the chat. Either way, the list fails the stranger test: he can ask for a method using made-up rows instead."
  - "The setting is worth finding, but switching it off does not make 1,500 names and emails safe to paste. The stranger test still applies."
  - "AI assistants tend to agree with the user, so asking again is not a check. The tool's own help page is."
```
