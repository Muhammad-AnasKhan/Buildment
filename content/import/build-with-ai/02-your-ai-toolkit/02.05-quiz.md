```quiz
type: mcq
question: "Ziad's bootcamp team is building a sign-up page for a neighbourhood library. Today he wants AI help with four items. A) The library's sheet of 120 members' names, ages and phone numbers. B) The error message the page shows in the browser. C) The settings file, which holds the password for the library's database. D) The library's contract with the bootcamp, marked 'private'. Which item can he paste as it is?"
options:
  - "Item A, since the library asked the team to build the page"
  - "Item C, since the training setting can be switched off first"
  - "Item B, since it names no person, key or private term"
  - "Item D, since the bootcamp already has its own copy"
correct: 2
explanations:
  - "Asking for a page is not permission to share 120 members' personal data with an AI company. The sheet fails the stranger test."
  - "Switching off the setting is a good habit, but the settings file holds a password, and passwords never go in with any setting."
  - "Right. The error message has no names, numbers, keys or private terms in it. A stranger could read it and learn nothing about anyone."
  - "The contract is marked private. Having a copy does not make it something to share with a tool the library never chose."
```

```quiz
type: mcq
question: "Aseel, a freelance translator, has 30 document files of past glossaries in one folder. She asks a chat assistant how to turn them into plain text files. It answers: 'Run this command in the folder. It converts every file to plain text and deletes the original files to save space.' What should she do first?"
options:
  - "Read the official docs and test on two copies, since it deletes files"
  - "Ask the assistant to confirm, since it knows the command it wrote"
  - "Run it on all 30 files, since the answer says what it does"
  - "Run it, then open a few new files, since that checks the result"
correct: 0
explanations:
  - "Right. The official docs show what the command really does, and two copied files mean a mistake costs nothing. The 30 originals stay safe until she is sure."
  - "Remember the agreeing habit from chapter 2.2: a second answer from the same tool is not a check. The official docs are."
  - "The answer says the command deletes the originals. If the conversion goes wrong, all 30 files are gone, with no copy to go back to."
  - "Checking the new files is good, but by then the originals are already deleted. A mistake would be found too late to undo."
```

```quiz
type: mcq
question: "Yaman volunteers at a clinic desk. He needs to know whether a free spreadsheet app changed its file-sharing rules last week. Three facts. The change, if any, is only a week old. He is 16. At home he has only his phone's browser, and at the clinic desk he shares a laptop. Which choice fits this job?"
options:
  - "A source notebook with last year's guide, since it stays on its sources"
  - "A chat assistant whose terms say 18 or over, since it explains well"
  - "A chat assistant's phone app, since he can download it at home"
  - "A search tool with sources, since the change is a week old"
correct: 3
explanations:
  - "Staying inside sources is useful, but a guide from last year cannot show a change from last week. Old sources give an old answer."
  - "He is 16, so a tool whose terms say 18 or over is not for him, however well it explains."
  - "At home he has only his phone's browser, so the web version is his path. A download also costs data before he knows whether the app opens for him."
  - "Right. Finding a week-old change needs recent pages. He then opens the links to check that they say what the tool claims, in his phone's browser or on the clinic laptop."
```

```quiz
type: mcq
question: "Over one term, Nada wrote 8 lesson plans for her NGO's coding club with a chat assistant. Four facts. 1) The plans exist only in the chat history. 2) The NGO's laptop is shared by five volunteers. 3) She has a free GitHub account. 4) The plans hold no personal data. Where should the plans live?"
options:
  - "In the chat history, since nothing in the plans is private"
  - "In Markdown files on GitHub, since that gives her a second copy"
  - "On the shared laptop's desktop, since the team can find them"
  - "Nowhere new yet, since a paid plan would keep them safe"
correct: 1
explanations:
  - "Nothing private is a reason she may share them, not a reason to keep them in one place. Chat history is exactly how Ahmad lost a month of work."
  - "Right. Files she owns, with a second copy on GitHub, survive any change to the chat tool. Since the plans hold no personal data, she can even share the repository with the team."
  - "The team can find them, but five people use that laptop, and one copy on a shared desktop can be moved or deleted by anyone. It is still only one copy."
  - "She does not need to pay. She already has a free GitHub account, and the plans are at risk while they live only in the chat."
```

question: "Anas works at a pharmacy that keeps about 1,500 past delivery orders, each with a customer's name and email. He asks a chat assistant whether he can paste the order list to find repeat customers. It answers: 'Yes, your chats are private and are never read by anyone.' What should he do next?"
options:
  - "Paste the list, since the tool says its chats are private"
  - "Switch off the training setting and paste, since that makes it private"
  - "Check its help page and use made-up rows, since names stay out"
  - "Ask the assistant again, since a second answer will be more careful"
correct: 2
explanations:
  - "An AI answer about its own company's rules can be wrong. Some services have people read a sample of chats, and the list holds 1,500 customers' details."
  - "The setting is worth finding, but switching it off does not make 1,500 names and emails safe to paste. The stranger test still applies."
  - "Right. The help page is the source to check, not the chat. Either way, the real list fails the stranger test, so he asks for a method using made-up rows in the same columns."
  - "The agreeing habit from chapter 2.2 means asking again is not a check. The tool's own help page is."
