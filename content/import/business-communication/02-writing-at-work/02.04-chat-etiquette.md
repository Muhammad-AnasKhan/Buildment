## The message that said only "Hi"

Mariam is a junior developer in Gaza. Her team uses Slack, a chat tool for work. She needs the latest design file for the settings page from Lucas, a designer in Vancouver. It is 15:00 for Mariam and 05:00 for Lucas, who is still asleep.

```predict
prompt: "Mariam wants the file as early as possible. What should she send now?"
options:
  - id: hi-first
    label: "\"Hi Lucas, are you there?\" and wait for him to reply before asking"
  - id: full-message
    label: "One message with the greeting, the exact file she needs and why"
correctOptionId: full-message
explanation: "Lucas will see the message when his day starts, while Mariam is offline. If it only says \"Hi\", he replies \"Hi, what do you need?\" and nothing happens for another day. A complete message can be answered in one reply."
```

Here is what a complete message looks like:

```text
Hi Lucas, could you share the latest Figma file for the
settings page? I am building it today and the link I
have shows the old version from May. If the design is
not final yet, the old one is fine and I will update
it later. Thanks!
```

Lucas reads it at 08:00 his time, sends the link, and Mariam has it when she logs in the next morning. One message, one reply, no lost day.

## Write messages that can be answered in one reply

In chat, it feels natural to write the way you talk: "Hi", then wait, then the question, then the details. Across time zones, every wait can cost hours. A complete message has:

1. **A short greeting and the person's name**
2. **The question or request**, in one or two sentences
3. **The context** they need to answer: which page, which file, which error
4. **What happens if they cannot help now**, when that is useful

If you need to share an error, paste the error text or a screenshot. "It doesn't work" forces the other person to ask "What doesn't work?"

## Use threads

In a busy channel, many topics mix together. A **thread** keeps the replies to one message under that message. Good habits:

- **Reply in the thread**, not in the main channel, when you answer a message.
- **One topic per thread.** Start a new message for a new topic.
- **Keep decisions where people can find them.** If a thread reaches a decision, write it in one clear line at the end: "Decision: we launch on Monday without the dark mode."

<Callout type="tip" title="Acknowledge, do not stay silent">
If you read a request and cannot do it yet, say so briefly: "Seen, I will look at this after lunch." Many teams also use a reaction, such as a check mark, to mean "seen" or "done". Silence makes people wonder whether you saw it.
</Callout>

## Respect time zones and working hours

Before you send a message, check the other person's local time. Most chat tools show it on their profile. Then:

- **Do not expect an instant reply** outside their working hours. Write the message so it can wait.
- **Schedule your message** if your tool allows it, so it arrives at the start of their day and not at 02:00.
- **Mention people with care.** An @mention sends a notification to that person. `@channel` or `@here` notifies everyone in the channel. Use those only for real emergencies, such as the live site being down.
- **Be honest about urgency.** If something is urgent, say why and by when. If it is not, say "no rush" so people can plan.

The same is true for you. You do not need to answer messages at midnight. If you work fixed hours because of power or study, put them in your chat profile, for example "Usually online 08:00 to 16:00 Gaza time".

## Keep the tone friendly

Short chat messages can sound cold by accident. "Send the file." reads like an order. "Could you send the file? Thanks!" takes two seconds more and sounds like a colleague. A little warmth is normal in chat, but every message should still be clear on its own.

When a chat discussion gets long or tense, move it. Ask for a short call or write one clear email. You learn more about choosing between meetings and writing in module 4.

  - "Write the answer as a new message in the main channel, so the whole team sees it"
  - "Send her a private message with the answer, so the busy channel stays quiet"

  - "A new message in the main channel separates your answer from her question, and other topics mix in between."
