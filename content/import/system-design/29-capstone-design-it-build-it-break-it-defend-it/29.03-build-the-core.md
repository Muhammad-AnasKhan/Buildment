## How the capstone harness works

Your core runs inside a small simulation. The scenario makes traffic: clients that send requests at random moments, like the load generator in challenge 1. The harness hands each request to your core and records when the answer comes back and what it says. Your core is made of boxes, and a box is a simulated machine on the toolkit network from challenge 9: it has a few workers, a waiting line, a price per hour, and it can be killed, restarted or slowed down.

Time in this simulation is virtual: a variable that moves from one event to the next, as in challenges 9 to 12. A 25-second run takes about a second of real time, and the same seed gives the same numbers every time. That is what lets a mentor re-run your work in a minute, and it lets you cut a link at exactly the 12th second in chapter 29.4.

It also means the simulation is a model, and you should say so in your defence. It knows nothing about a real disk, garbage collection or a slow operating system. Its service times are round numbers from the napkin-math table: a query to a cache or a database costs 0.5 ms, a write 0.8 ms, and a message inside a region takes about 0.15 ms one way [S3]. Use it to compare shapes of design and to find which box saturates first. Do not quote its p99 as the p99 of a real machine. In challenge 1 and challenge 4 you measured real servers, and the sandbox lab in 29.2 priced real shapes.

Four choices keep the numbers honest.

**The traffic is an open loop.** Clients do not wait for answers before sending the next request, so a slow system gets more requests while it is slow, as real users do. The gaps between requests are random, drawn from a seed that your core cannot disturb.

**A request with no answer is a failure, and it counts as 1000 ms.** If a client has waited one second, it gives up. A request that never gets a reply is counted as not answered, and its latency is 1000 ms in the p99. Without this rule, a dead box would make your p99 look good, because the slow requests would simply vanish.

**Availability counts every request; p99 counts the requests the scenario names.** Fast errors make p99 look good, which is why the two are always read together. A core that refuses everything instantly will pass the p99 target and fail the availability target. You will see exactly that in a moment.

**Promises are checked on the answers.** Each scenario knows what the right answer is, because the clients keep a record of what the system acknowledged. When your core gives a wrong answer, such as the wrong address for an acknowledged link, the harness counts it. After the traffic stops, the harness waits four seconds and then reads data back, so a design that loses or never merges acknowledged writes is caught.

## Step 1: boxes

Create `toolkit/box.js`. Read the comments: they say what a box can and cannot do. The part to understand well is `epoch`. When a box is killed, work that was running still has a timer in the simulation. The epoch number grows at every kill, and a timer that was started under an older epoch does nothing when it fires, so killed work never finishes.

```js
// toolkit/box.js: a simulated machine on the toolkit network (simnet).
// A box has a few workers. A message needs a free worker for its service time;
// if all workers are busy it waits in a line, and if the line is full it is
// refused. A box can be killed, restarted (memory is lost), or slowed down.
// Time is virtual, so the same seed gives the same run.

// Illustrative sizes and hourly prices. Use them to compare shapes of design,
// not to quote a bill.
export const SIZES = {
  small: { workers: 2, perHour: 0.05 },
  medium: { workers: 4, perHour: 0.1 },
  large: { workers: 8, perHour: 0.2 },
};

export function createBox(net, id, options = {}) {
  const {
    size = "medium",
    queueMax = 200, // how many messages may wait; more than this are refused
    serviceMs = () => 0.25, // how long one message needs a worker
    onMessage = () => {}, // called when a message has been served
    onShed = () => {}, // called when a message is refused (the line is full)
    onRestart = () => {}, // called when the box comes back: wipe your memory here
  } = options;
  const { workers, perHour } = SIZES[size];
  let alive = true;
  let epoch = 0; // grows on every kill, so work started before a kill is forgotten
  let busy = 0;
  let slowBy = 1;
  let busyMs = 0;
  const waiting = [];
  const stats = { served: 0, shed: 0, maxWaiting: 0 };

  function start(from, payload) {
    busy += 1;
    const ms = serviceMs(payload) * slowBy;
    const mine = epoch;
    net.after(ms, () => {
      if (mine !== epoch) return; // the box was killed while this was running
      busy -= 1;
      busyMs += ms;
      stats.served += 1;
      onMessage(from, payload);
      const next = waiting.shift();
      if (next) start(next.from, next.payload);
    });
  }

  const box = {
    id,
    size,
    perHour,
    stats,
    get alive() {
      return alive;
    },
    // A message arrives, from the network or from code on the same machine.
    deliver(from, payload) {
      if (!alive) return false; // nobody is home: the sender simply gets no answer
      if (busy < workers) {
        start(from, payload);
      } else if (waiting.length < queueMax) {
        waiting.push({ from, payload });
        stats.maxWaiting = Math.max(stats.maxWaiting, waiting.length);
      } else {
        stats.shed += 1;
        onShed(from, payload);
        return false;
      }
      return true;
    },
    kill() {
      alive = false;
      epoch += 1;
      busy = 0;
      waiting.length = 0;
    },
    restart(coldMs = 0) {
      net.after(coldMs, () => {
        alive = true;
        onRestart();
      });
    },
    slow(factor = 1) {
      slowBy = factor; // 1 is normal, 10 is ten times slower
    },
    workers,
    // Total worker time spent so far, in ms. Take it twice and subtract to see
    // how busy the box was in between: busy / (workers * elapsed).
    get busyMs() {
      return busyMs;
    },
  };
  net.addNode(id, { onMessage: (from, payload) => box.deliver(from, payload) });
  return box;
}

// Send between two boxes in different places: the network adds its own small
// delay, and extraMs is the distance (for example 40 ms one way between regions).
export function hop(net, from, to, payload, extraMs = 0) {
  if (extraMs > 0) net.after(extraMs, () => net.send(from, to, payload));
  else net.send(from, to, payload);
}

// What a set of boxes costs for one hour.
export function costPerHour(boxes) {
  return Object.values(boxes).reduce((sum, box) => sum + box.perHour, 0);
}
```

A box is deliberately plain. It has `workers` that can serve messages at the same time, a line of messages that wait, and a size that sets both the number of workers and the price per hour. A small box has 2 workers and costs 0.05 an hour, a medium one has 4 and costs 0.10, a large one has 8 and costs 0.20. These prices are illustrative, like the sandbox catalog: use them to compare designs, not to quote a bill. `restart` calls your `onRestart`, and that is where you throw away what lived only in memory.

## Step 2: scenarios

Create `challenges/challenge-18-capstone/scenarios.js`. This file is the same for every learner and you do not edit it, so a mentor can compare two designs on the same traffic. Read it once, slowly, for your own system: the `phases` are the traffic, `inSli` says which requests count for p99, and `check` and `verify` are the promises. The other two systems are in the file too, so you can read how they differ.

```js
// scenarios.js: the three capstone systems. Each one says what the clients do
// (the workload), what the system must promise (the checks) and the targets.
// Times are in virtual milliseconds. All three are fictional composites.
// You do not edit this file: it is the same for every learner, so a mentor
// can compare two designs on the same traffic.

// How long one piece of work needs a worker, in ms. Round numbers from the
// napkin-math table: a cache or database query about 0.5 ms, an SSD write
// with fsync about 0.3 ms on top of it. App code is a guess: 0.25 ms.
export const MS = { app: 0.25, cacheGet: 0.5, dbRead: 0.5, dbWrite: 0.8, memory: 0.01 };

// One way across a region: about 0.15 ms (a round trip of 0.25 ms inside a region).
export const NET = { minDelay: 0.1, maxDelay: 0.2 };

// One way between two regions: half of an 80 ms round trip (EU West to NA East).
export const REGION_ONE_WAY_MS = 40;

// ---------------------------------------------------------------- A: links
// Hayat Links: short links for an aid charity's campaigns. A post goes viral
// and one link gets most of the traffic.
const links = {
  id: "links",
  title: "Hayat Links",
  targets: { p99Ms: 10, availability: 0.999, costPerHour: 0.4 },
  durationMs: 25_000,
  measureFromMs: 2_000,
  peak: [10_000, 20_000], // the busiest stretch: the harness reports how busy each box was in it
  net: NET,
  build(random) {
    const acked = new Map(); // code -> url, only for links the system said yes to
    const codes = []; // the same codes in a list, to pick one quickly
    let made = 0;

    function put() {
      const code = made === 0 ? "viral" : `c${made}`;
      const url = `https://hayat.example/campaign/${made}`;
      made += 1;
      return {
        kind: "write", method: "PUT", path: `/links/${code}`, body: { url },
        onReply(res) {
          if (res.status === 201) { acked.set(code, url); codes.push(code); }
        },
      };
    }
    function get(code) {
      const url = acked.get(code);
      return {
        kind: "read", method: "GET", path: `/links/${code}`,
        // A link the system acknowledged must come back with the same address.
        check: (res) => (res.status === 200 && res.body?.url === url ? null : `GET ${code}: wanted ${url}, got ${res.status} ${res.body?.url}`),
      };
    }
    const mix = (viralShare) => () => {
      if (random() < 0.02) return put();
      if (acked.has("viral") && random() < viralShare) return get("viral");
      return get(codes[Math.floor(random() * codes.length)]);
    };

    return {
      ctx: {},
      phases: [
        { fromMs: 0, toMs: 2_000, rate: 500, make: put }, // 1,000 campaign links
        { fromMs: 2_000, toMs: 10_000, rate: 400, make: mix(0) }, // a normal day
        { fromMs: 10_000, toMs: 20_000, rate: 8_000, make: mix(0.7) }, // the post goes viral
        { fromMs: 20_000, toMs: 25_000, rate: 400, make: mix(0) },
      ],
      inSli: (req) => req.kind === "read",
      // After the run: read back every 10th link, to see that nothing was lost.
      verify: () => codes.filter((_, i) => i % 10 === 0).map(get),
      final: () => [],
    };
  },
};

// ------------------------------------------------------------ B: timeline
// Majlis: a student community app. 5,000 students; 10 popular accounts
// (societies and star students) that most students follow.
const USERS = 5_000;
const POPULAR = 10;
const FRESH_MS = 2_000; // a post must show in followers' timelines within 2 seconds
const hash01 = (a, b) => (((Math.imul(a + 1, 2654435761) ^ Math.imul(b + 7, 40503)) >>> 0) % 1000) / 1000;

function makeGraph() {
  const followingCache = new Map();
  const followersCache = new Map();
  function followingOf(u) {
    if (!followingCache.has(u)) {
      const list = [];
      for (let a = 0; a < POPULAR; a++) if (a !== u && hash01(u, a) < 0.8) list.push(a);
      for (let k = 0; k < 30; k++) {
        const a = POPULAR + ((u * 7919 + k * 104729) % (USERS - POPULAR));
        if (a !== u && !list.includes(a)) list.push(a);
      }
      followingCache.set(u, list);
    }
    return followingCache.get(u);
  }
  function followersOf(a) {
    if (!followersCache.has(a)) {
      const list = [];
      for (let u = 0; u < USERS; u++) if (followingOf(u).includes(a)) list.push(u);
      followersCache.set(a, list);
    }
    return followersCache.get(a);
  }
  return { users: USERS, popular: POPULAR, followingOf, followersOf };
}

const timeline = {
  id: "timeline",
  title: "Majlis",
  targets: { p99Ms: 10, availability: 0.999, costPerHour: 0.5 },
  durationMs: 25_000,
  measureFromMs: 4_000,
  peak: [4_000, 25_000],
  net: NET,
  build(random) {
    const graph = makeGraph();
    const byAuthor = new Map(); // author -> [{ id, at }] in the order they were acknowledged
    const authorOfId = new Map(); // post id -> author, set when the post is made
    let nextId = 1;
    let reads = 0;

    function post() {
      const author = random() < 0.2 ? Math.floor(random() * POPULAR) : POPULAR + Math.floor(random() * (USERS - POPULAR));
      const id = nextId++;
      authorOfId.set(id, author);
      return {
        kind: "write", method: "POST", path: "/posts", body: { author, id },
        onReply(res, now) {
          if (res.status !== 201) return;
          if (!byAuthor.has(author)) byAuthor.set(author, []);
          byAuthor.get(author).push({ id, at: now });
        },
      };
    }
    // The 20 newest posts from accounts the user follows that are at least 2 s old.
    function expected(user, now) {
      const found = [];
      for (const a of graph.followingOf(user)) {
        const list = byAuthor.get(a) ?? [];
        let taken = 0;
        for (let i = list.length - 1; i >= 0 && taken < 20; i--) {
          if (list[i].at <= now - FRESH_MS) { found.push(list[i].id); taken += 1; }
        }
      }
      return found.sort((x, y) => y - x).slice(0, 20);
    }
    function read(user, always = false) {
      reads += 1;
      const sampled = always || reads % 10 === 0; // checking every read would slow the script
      const req = { kind: "read", method: "GET", path: `/timeline/${user}`, user };
      if (sampled) {
        req.check = (res, now) => {
          const ids = res.body?.ids ?? [];
          for (let i = 1; i < ids.length; i++) if (ids[i] >= ids[i - 1]) return `timeline of ${user} is not newest first`;
          const follows = new Set(graph.followingOf(user));
          for (const id of ids) {
            if (!follows.has(authorOfId.get(id))) return `timeline of ${user} has post ${id} from an account it does not follow`;
          }
          const have = new Set(ids);
          const oldest = ids.length === 20 ? ids[19] : 0;
          for (const id of expected(user, now)) {
            if (!have.has(id) && id > oldest) return `post ${id} is missing from the timeline of ${user} after ${FRESH_MS} ms`;
          }
          return null;
        };
      }
      return req;
    }

    return {
      ctx: graph,
      phases: [
        { fromMs: 0, toMs: 4_000, rate: 40, make: post },
        { fromMs: 4_000, toMs: 25_000, rate: 20, make: post },
        { fromMs: 4_000, toMs: 25_000, rate: 400, make: () => read(Math.floor(random() * USERS)) },
      ],
      inSli: (req) => req.kind === "read",
      verify: () => Array.from({ length: 100 }, (_, i) => read((i * 49) % USERS, true)),
      final: () => [],
    };
  },
};

// -------------------------------------------------------------- C: marketplace
// Souq: a small marketplace with shoppers in two regions. Carts must always
// accept an item. Stock must never be sold twice.
const REGIONS = ["eu", "na"];
const SKUS = 20;
const STOCK = 150; // units of each item, in total, for both regions together

const market = {
  id: "market",
  title: "Souq",
  targets: { p99Ms: 30, availability: 0.999, costPerHour: 0.6 },
  durationMs: 24_000,
  measureFromMs: 1_000,
  peak: [1_000, 24_000],
  net: NET,
  build(random) {
    const added = new Map(); // "user|sku" -> units the system acknowledged
    const confirmed = new Array(SKUS).fill(0); // units sold, by item
    const users = 2_000;
    const regionOf = (u) => REGIONS[u % 2]; // every shopper has a home region
    const sku = () => `sku${random() < 0.5 ? Math.floor(random() * 2) : Math.floor(random() * SKUS)}`;

    function add() {
      const user = Math.floor(random() * users);
      const item = sku();
      const qty = 1 + Math.floor(random() * 3);
      return {
        kind: "cart-write", method: "POST", path: `/cart/${user}/add`, region: regionOf(user), body: { sku: item, qty },
        onReply(res) {
          if (res.status === 200) added.set(`${user}|${item}`, (added.get(`${user}|${item}`) ?? 0) + qty);
        },
      };
    }
    function cartOf(user, region) {
      // Everything the system acknowledged for this shopper before now must be in the cart.
      const wanted = [...added].filter(([k]) => k.split("|")[0] === String(user));
      return {
        kind: "cart-read", method: "GET", path: `/cart/${user}`, region,
        check(res) {
          for (const [k, qty] of wanted) {
            const item = k.split("|")[1];
            if ((res.body?.items?.[item] ?? 0) < qty) return `cart of ${user} lost ${item}: wanted ${qty}, got ${res.body?.items?.[item] ?? 0}`;
          }
          return null;
        },
      };
    }
    function buy() {
      const user = Math.floor(random() * users);
      const item = sku();
      const qty = 1 + Math.floor(random() * 3);
      return {
        kind: "buy", method: "POST", path: "/buy", region: regionOf(user), body: { user, sku: item, qty },
        onReply(res) {
          if (res.status === 200) confirmed[Number(item.slice(3))] += qty;
        },
      };
    }
    // Only carts that were written to are worth reading back.
    const writtenUsers = () => [...new Set([...added.keys()].map((k) => Number(k.split("|")[0])))];

    return {
      ctx: { regions: REGIONS, skus: SKUS, stock: STOCK, oneWayMs: REGION_ONE_WAY_MS },
      phases: [
        { fromMs: 0, toMs: 24_000, rate: 200, make: add },
        { fromMs: 1_000, toMs: 24_000, rate: 200, make: () => { const u = Math.floor(random() * users); return cartOf(u, regionOf(u)); } },
        { fromMs: 0, toMs: 24_000, rate: 30, make: buy },
      ],
      inSli: (req) => req.kind === "cart-write" || req.kind === "cart-read",
      // After the run, and after any broken link has healed: read 100 carts from both regions.
      verify: () => writtenUsers().slice(0, 100).flatMap((u) => REGIONS.map((r) => cartOf(u, r))),
      final: () => confirmed.flatMap((units, i) => (units > STOCK ? [`oversold sku${i}: sold ${units}, stock ${STOCK}`] : [])),
    };
  },
};
```

## Step 3: the harness

Create `challenges/challenge-18-capstone/harness.js`. It builds a network and your core, schedules the traffic, runs the events you give it (none in this chapter, a fault in 29.4), waits for the system to settle, reads data back, and returns every record. `summarize` and `perSecond` turn the records into the numbers you need. Two details matter. The late-reply branch ignores an answer that arrives after the client gave up, and `onReply` is not called for it, so a write whose acknowledgement came too late is not counted as acknowledged. And a check runs only on a request that was answered without a server error: an error is a failure of availability, not a wrong answer.

```js
// harness.js: run one scenario against your core, on the toolkit network.
//
// Your core is a function createCore({ net, ctx }) that returns
//   { handle(req, reply), boxes }
// handle is the front door: it gets a request and must call reply({ status, body })
// once. boxes is an object of the machines you made with createBox, so the
// harness can count their cost and so an experiment can break them.
import { createNet } from "../../toolkit/simnet.js";
import { costPerHour } from "../../toolkit/box.js";
import { exponential, percentile, seededRandom } from "../../toolkit/stats.js";
import { SCENARIOS } from "./scenarios.js";

export const TIMEOUT_MS = 1000; // a client that waits longer than this gives up

export function runScenario({ createCore, scenario = "links", seed = 1, events = [], settleMs = 4000 }) {
  const sc = SCENARIOS[scenario];
  if (!sc) throw new Error(`unknown scenario "${scenario}"`);
  const net = createNet({ seed, ...sc.net });
  const load = seededRandom(seed * 7919 + 13); // the traffic does not change when your core uses random numbers
  const built = sc.build(load);
  const core = createCore({ net, ctx: built.ctx });

  const records = []; // one per request: { t, ms, status, ok, sli }
  const examples = []; // the first few things the checks found wrong
  let problems = 0;
  const pending = new Map(); // requests still waiting for an answer

  function send(req, { counted = true } = {}) {
    const t = net.now;
    let done = false;
    const sli = counted && built.inSli(req);
    pending.set(req, { t, counted, sli });
    core.handle(req, (res) => {
      if (done) return;
      done = true;
      pending.delete(req);
      const late = net.now - t > TIMEOUT_MS; // the client had already given up
      if (late) {
        records.push({ t, ms: TIMEOUT_MS, status: 0, ok: false, sli, counted });
        return;
      }
      const ok = res.status >= 200 && res.status < 500 && res.status !== 429;
      req.onReply?.(res, net.now);
      const problem = ok ? req.check?.(res, net.now) : null; // an error is not a wrong answer
      if (problem) {
        problems += 1;
        if (examples.length < 10) examples.push(problem);
      }
      records.push({ t, ms: net.now - t, status: res.status, ok, sli, counted });
    });
  }

  // Poisson arrivals: independent clients, so the gaps are random (an open loop).
  function arrive(phase, from) {
    const at = from + exponential(load, 1000 / phase.rate);
    if (at >= phase.toMs) return;
    net.at(at, () => {
      send(phase.make());
      arrive(phase, at);
    });
  }
  for (const phase of built.phases) arrive(phase, phase.fromMs);
  for (const event of events) net.at(event.atMs, () => event.run({ net, core }));

  // How busy was each box during the busiest stretch?
  const before = {};
  const busy = {};
  net.at(sc.peak[0], () => Object.values(core.boxes).forEach((b) => (before[b.id] = b.busyMs)));
  net.at(sc.peak[1], () =>
    Object.values(core.boxes).forEach((b) => (busy[b.id] = (b.busyMs - before[b.id]) / (b.workers * (sc.peak[1] - sc.peak[0])))));

  net.run(sc.durationMs);
  net.run(sc.durationMs + settleMs); // let the system settle: heal, repair, catch up
  const verifyStart = net.now;
  built.verify().forEach((req, i) => net.at(verifyStart + i * 0.5, () => send(req, { counted: false })));
  net.run(verifyStart + settleMs);

  // Requests that never got an answer count as timeouts.
  for (const info of pending.values()) records.push({ ...info, ms: TIMEOUT_MS, status: 0, ok: false });
  const finals = built.final();
  return {
    scenario: sc, records, violations: [...examples, ...finals], violationCount: problems + finals.length,
    boxes: core.boxes, busy, cost: costPerHour(core.boxes), events,
  };
}

// Availability and p99 for the requests that arrived in a window of time.
export function summarize(run, { fromMs = run.scenario.measureFromMs, toMs = run.scenario.durationMs } = {}) {
  const rows = run.records.filter((r) => r.counted && r.t >= fromMs && r.t < toMs);
  const slis = rows.filter((r) => r.sli);
  return {
    requests: rows.length,
    availability: rows.length ? rows.filter((r) => r.ok).length / rows.length : 1,
    p50: slis.length ? percentile(slis.map((r) => r.ms), 50) : 0,
    p99: slis.length ? percentile(slis.map((r) => r.ms), 99) : 0,
  };
}

// One row per second: how many requests were answered, how many were not, and the p99.
export function perSecond(run) {
  const seconds = Math.ceil(run.scenario.durationMs / 1000);
  return Array.from({ length: seconds }, (_, s) => {
    const rows = run.records.filter((r) => r.counted && r.t >= s * 1000 && r.t < (s + 1) * 1000);
    const slis = rows.filter((r) => r.sli);
    return {
      second: s,
      ok: rows.filter((r) => r.ok).length,
      bad: rows.filter((r) => !r.ok).length,
      p99: slis.length ? percentile(slis.map((r) => r.ms), 99) : 0,
    };
  });
}
```

## When it does not work

**Everything times out and p99 is 1000.** Some path never calls `reply`. A request that reaches a box with a full line is dropped unless you set `onShed`; reply from `onShed` with a 503, so the client hears something at once.

**Different numbers on every run.** You used `Math.random` or the real clock. Use `net.random()` and `net.now` only, so the same seed gives the same run.

**"Cannot find module .../toolkit/box.js".** Count the `../` steps: from `part-1-core` it is three levels up.

**The run takes more than a few seconds.** Something creates many timers per request, such as a repeating timer for every client. Count your `net.after` calls per request.

**A check reports a wrong answer you cannot explain.** Print the request and the reply for that one key. Remember that a check sees the state at the moment the request was sent: a write acknowledged later does not count against the read.

**CI is red but your laptop is green.** The tests do not depend on the machine, so look at the Node version in the workflow (it must be 24) and at files you forgot to `git add`.
