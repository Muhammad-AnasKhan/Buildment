## How the simulation works

The store runs inside one program, on the simulated network you built in challenge 9. Time is a number in a variable, messages take 5 to 40 ms to arrive, and the same seed always gives the same run. That is what makes the numbers in this chapter repeatable: if your code is right, you will print the same numbers as the ones below.

Three design choices keep the numbers honest.

**A client can reach any node.** The node that receives a request coordinates it: it works out the key's three nodes, asks them, and counts the answers. That is the leaderless idea in code. There is no node with special power, so no failover is ever needed.

**Failures are real to the nodes, and visible to the experiment.** `crash(id)` cuts the node off from every other node, and the node ignores any message still on its way. The store also knows which nodes are down, as a perfect failure detector would. A real detector is slower and sometimes wrong (chapter 12.8). Using a perfect one keeps the question clean: what does the design do, given that it knows?

**A judge knows what each person meant.** In parts 3 and 4, Hana and Dina each change a shared cart, and we know the cart they meant to end with. A cart is "right" only if it matches. The store is never allowed to grade itself.

Now the store, `toolkit/dynamo.js`. Read it in four pieces. The first is the ring: `makeRing` gives every node eight points, and `order(key)` walks clockwise from the key and lists each node once. The first three are the key's preference list, and the rest are the stand-ins. The second is `addVersion`, which decides what a node keeps when a new version arrives: it drops a version that another version covers, keeps versions that neither covers, and then applies the policy. The third is `handle`, which is everything a node does when a message arrives. The fourth is `put` and `get`, which are what a client calls. The comments say what each line is for.

```js
// toolkit/dynamo.js: a small leaderless key-value store that runs on the
// simulated network (toolkit/simnet.js). Every key lives on N nodes found on a
// ring. A write is done when W of them confirm, a read when R of them answer.
// Each stored value carries a vector clock, so the store can tell a newer
// version from a concurrent one. Everything runs in virtual time and the same
// seed gives the same run.
import { hash32 } from "./hash.js";
import { vcCompare, vcMerge, vcTick } from "./clocks.js";

const DISK_MS = 1; // time a node needs to touch its own storage

// The ring. order(key) lists every node once, starting at the key's position
// and walking clockwise. The first N are the key's preference list; the rest
// are the stand-ins a sloppy quorum may borrow.
function makeRing(nodes, vnodes) {
  const points = [];
  for (const node of nodes) for (let i = 0; i < vnodes; i++) points.push({ pos: hash32(`${node}#${i}`), node });
  points.sort((a, b) => a.pos - b.pos || (a.node < b.node ? -1 : 1));
  return (key) => {
    const h = hash32(key);
    let start = points.findIndex((p) => p.pos >= h);
    if (start === -1) start = 0; // past the last point: wrap round
    const seen = [];
    for (let i = 0; i < points.length && seen.length < nodes.length; i++) {
      const { node } = points[(start + i) % points.length];
      if (!seen.includes(node)) seen.push(node); // a node with many points counts once
    }
    return seen;
  };
}

const newest = (a, b) => (a.ts !== b.ts ? (a.ts > b.ts ? a : b) : JSON.stringify(a.value) > JSON.stringify(b.value) ? a : b);

// Put one version into a node's list of versions for a key.
// "siblings": keep every version that no other version covers.
// "lww": keep only the version with the latest timestamp, whatever its clock says.
// { merge(a, b) }: when versions are concurrent, merge their values into one.
function addVersion(list, version, resolve) {
  if (resolve === "lww") return [list.reduce(newest, version)];
  for (const old of list) {
    const relation = vcCompare(version.clock, old.clock);
    if (relation === "before" || relation === "equal") return list; // already covered
  }
  const kept = list.filter((old) => vcCompare(old.clock, version.clock) !== "before"); // drop what the new one covers
  kept.push(version);
  if (resolve === "siblings" || kept.length === 1) return kept;
  return [{
    value: kept.map((v) => v.value).reduce((a, b) => resolve.merge(a, b)),
    clock: kept.reduce((acc, v) => vcMerge(acc, v.clock), {}),
    ts: Math.max(...kept.map((v) => v.ts)),
  }];
}

export function createStore({ net, nodes, n = 3, r = 2, w = 2, sloppy = false, hints = true, resolve = "siblings", timeoutMs = 400, hintEveryMs = 100, vnodes = 8, clocks = {} }) {
  const order = makeRing(nodes, vnodes);
  const disk = new Map(nodes.map((id) => [id, { data: new Map(), hints: new Map() }])); // hints: owner -> Map(key -> versions)
  const down = new Set();
  const ops = new Map();
  let nextOp = 1;
  const alive = (id) => !down.has(id);

  function send(from, to, message) {
    if (from === to) net.after(DISK_MS, () => handle(to, from, message)); // a node talking to itself skips the network
    else net.send(from, to, message);
  }

  function finish(op, ok) {
    if (op.finished) return;
    op.finished = true;
    op.done({ ok, ms: net.now - op.start, ...op.result() });
  }

  function handle(id, from, m) {
    if (down.has(id)) return; // a crashed node hears nothing
    const node = disk.get(id);
    if (m.type === "write") {
      if (m.hintFor) {
        const byKey = node.hints.get(m.hintFor) ?? new Map();
        byKey.set(m.key, addVersion(byKey.get(m.key) ?? [], m.version, resolve)); // kept apart, with a note: for whom
        node.hints.set(m.hintFor, byKey);
      } else {
        node.data.set(m.key, addVersion(node.data.get(m.key) ?? [], m.version, resolve));
      }
      send(id, from, { type: "write-ack", op: m.op });
    } else if (m.type === "write-ack") {
      const op = ops.get(m.op);
      if (op && ++op.acks >= op.need) finish(op, true);
    } else if (m.type === "read") {
      send(id, from, { type: "read-reply", op: m.op, versions: node.data.get(m.key) ?? [] });
    } else if (m.type === "read-reply") {
      const op = ops.get(m.op);
      if (!op || op.finished) return;
      for (const v of m.versions) op.versions = addVersion(op.versions, v, resolve);
      if (++op.replies >= op.need) finish(op, true);
    } else if (m.type === "handoff") {
      for (const v of m.versions) node.data.set(m.key, addVersion(node.data.get(m.key) ?? [], v, resolve));
      send(id, from, { type: "handoff-ack", key: m.key, owner: id, sent: m.versions });
    } else if (m.type === "handoff-ack") {
      const byKey = node.hints.get(m.owner);
      if (byKey?.get(m.key) === m.sent) byKey.delete(m.key); // delivered: the hint can go
    }
  }
  for (const id of nodes) net.addNode(id, { onMessage: (from, m) => handle(id, from, m), ...clocks[id] });

  // Every hintEveryMs, each node offers its hints to owners that are back.
  function scanHints() {
    for (const [id, node] of disk) {
      if (down.has(id)) continue;
      for (const [owner, byKey] of node.hints) {
        if (down.has(owner)) continue;
        for (const [key, versions] of byKey) send(id, owner, { type: "handoff", key, versions });
      }
    }
    net.after(hintEveryMs, scanHints);
  }
  if (hints) net.after(hintEveryMs, scanHints);

  return {
    nodes,
    preference: (key) => order(key).slice(0, n),
    standIns: (key) => order(key).slice(n),

    // put(key, value, { context, via, w }, done). The node that receives the
    // request (via) coordinates it. context is the list of clocks the client
    // got from its last read of this key.
    put(key, value, opts, done) {
      const full = order(key);
      const via = opts.via ?? full.find(alive);
      let version = null;
      const op = { start: net.now, need: opts.w ?? w, acks: 0, done, finished: false, result: () => ({ acks: op.acks, clock: version?.clock }) };
      if (via === undefined) return finish(op, false);
      const clock = vcTick((opts.context ?? []).reduce((acc, c) => vcMerge(acc, c), {}), via);
      version = { value, clock, ts: net.wall(via) };
      const spare = full.slice(n).filter(alive);
      const targets = [];
      for (const owner of full.slice(0, n)) {
        if (!sloppy || !down.has(owner)) targets.push({ to: owner });
        else if (spare.length > 0) targets.push({ to: spare.shift(), hintFor: owner }); // a stand-in, with a note
      }
      ops.set((op.id = nextOp++), op);
      for (const t of targets) send(via, t.to, { type: "write", op: op.id, key, version, hintFor: t.hintFor });
      net.after(timeoutMs, () => finish(op, false));
    },

    // get(key, { via, r }, done). done gets { ok, ms, versions, context }.
    get(key, opts, done) {
      const full = order(key);
      const via = opts.via ?? full.find(alive);
      const op = { start: net.now, need: opts.r ?? r, replies: 0, versions: [], done, finished: false, result: () => ({ versions: op.versions, context: op.versions.map((v) => v.clock) }) };
      if (via === undefined) return finish(op, false);
      ops.set((op.id = nextOp++), op);
      for (const to of full.slice(0, n)) send(via, to, { type: "read", op: op.id, key });
      net.after(timeoutMs, () => finish(op, false));
    },

    crash(id) {
      down.add(id);
      for (const other of nodes) if (other !== id) net.cut(id, other);
    },
    recover(id) {
      down.delete(id);
      for (const other of nodes) {
        if (other === id) continue;
        if (down.has(other)) net.cut(id, other); // that one is still down
        else net.heal(id, other);
      }
    },
    isUp: alive,

    // What every node holds for a key, to look inside during a test.
    dump: (key) => Object.fromEntries(nodes.map((id) => [id, disk.get(id).data.get(key) ?? []])),
    hintsHeld: (id) => [...disk.get(id).hints.values()].reduce((sum, byKey) => sum + byKey.size, 0),
  };
}
```

Three details are worth a second look. In `put`, the new clock is the merge of the context clocks with one added to the coordinator's slot, exactly as in chapter 13.6. With a sloppy quorum, `put` swaps a down owner for the next healthy node on the ring and marks the message with `hintFor`; `handle` stores such a message apart, in `hints`, and `scanHints` hands it over when the owner is back. And `get` always asks the usual three nodes, never the stand-ins, which is why a sloppy write can be missed.

Its test file, `toolkit/dynamo.test.js`, checks the store before any experiment uses it. It checks the preference list, a confirmed write, siblings and the context, last write wins, a merge function, strict against sloppy writes, a hint handed over and dropped, and a crashed node.

```js
import assert from "node:assert/strict";
import { createNet } from "./simnet.js";
import { createStore } from "./dynamo.js";

const NODES = ["N1", "N2", "N3", "N4", "N5"];
const make = (options = {}) => {

  const store = createStore({ net, nodes: NODES, ...options });
  return { net, store };
};
const values = (versions) => versions.map((v) => v.value).sort();

test("a key's preference list is 3 different nodes, the same every time, and the stand-ins are the rest", () => {
  const { store } = make();
  for (let i = 0; i < 200; i++) {
    const key = `k${i}`;
    const list = store.preference(key);
    assert.equal(new Set(list).size, 3, `${key}: ${list}`);
    assert.deepEqual(store.preference(key), list);
    assert.deepEqual([...list, ...store.standIns(key)].sort(), NODES);
  }

test("a confirmed write ends up on all three nodes of the preference list", () => {
  const { net, store } = make();
  let result;
  store.put("cart", "v1", {}, (res) => (result = res));
  net.run(500);
  assert.equal(result.ok, true);
  assert.ok(result.acks >= 2);
  const held = store.dump("cart");
  for (const id of store.preference("cart")) assert.deepEqual(values(held[id]), ["v1"]);
  for (const id of store.standIns("cart")) assert.deepEqual(held[id], []);
});

test("a write that builds on what was read replaces it; a read returns the newest", () => {
  const { net, store } = make();
  let read;
  store.put("cart", "v1", { w: 3 }, (first) => {
    store.put("cart", "v2", { w: 3, context: [first.clock] }, () => {
      store.get("cart", { r: 3 }, (res) => (read = res));
    });
  });
  net.run(1000);
  assert.equal(read.ok, true);
  assert.deepEqual(values(read.versions), ["v2"]);
});

test("two writes from the same context become siblings, and a write that carries both contexts replaces them", () => {
  const { net, store } = make();
  let siblings;
  let after;
  store.put("cart", "base", { w: 3, via: "N3" }, (first) => {
    store.put("cart", "milk", { via: "N1", context: [first.clock] }, () => {});
    store.put("cart", "tea", { via: "N2", context: [first.clock] }, () => {});
    net.after(300, () => {
      store.get("cart", { r: 3 }, (read) => {
        siblings = read;
        store.put("cart", "milk and tea", { via: "N5", context: read.context }, () => {
          net.after(300, () => store.get("cart", { r: 3 }, (again) => (after = again)));
        });
      });
    });
  });
  net.run(3000);
  assert.deepEqual(values(siblings.versions), ["milk", "tea"]);
  assert.deepEqual(values(after.versions), ["milk and tea"]);

test("last write wins keeps one version, the one with the latest timestamp", () => {
  const net = createNet({ seed: 3 });
  const store = createStore({ net, nodes: NODES, resolve: "lww", clocks: { N2: { offsetMs: 50 } } });
  let read;
  // N2's clock is 50 ms ahead, so its write has the later timestamp even though it is sent first.
  store.put("k", "from N2", { via: "N2" }, () => {});
  net.after(10, () => store.put("k", "from N1", { via: "N1" }, () => {}));
  net.after(500, () => store.get("k", { r: 3 }, (res) => (read = res)));
  net.run(2000);
  assert.deepEqual(values(read.versions), ["from N2"]);
});

test("a merge function turns concurrent versions into one", () => {
  const { net, store } = make({ resolve: { merge: (a, b) => [...new Set([...a, ...b])].sort() } });
  let read;
  store.put("k", ["a"], { w: 3, via: "N3" }, (first) => {
    store.put("k", ["a", "b"], { via: "N1", context: [first.clock] }, () => {});
    store.put("k", ["a", "c"], { via: "N2", context: [first.clock] }, () => {});
    net.after(300, () => store.get("k", { r: 3 }, (res) => (read = res)));
  });
  net.run(2000);
  assert.equal(read.versions.length, 1);
  assert.deepEqual(read.versions[0].value, ["a", "b", "c"]);

test("with two of three nodes down, a strict write fails and a sloppy write succeeds on stand-ins", () => {
  for (const sloppy of [false, true]) {
    const { net, store } = make({ sloppy });
    const [first, second, third] = store.preference("cart");
    store.crash(second);
    store.crash(third);
    let result;
    store.put("cart", "v1", { via: first }, (res) => (result = res));
    net.run(1000);
    assert.equal(result.ok, sloppy, sloppy ? "sloppy should succeed" : "strict should fail");
  }
});

test("a stand-in keeps a hint and hands it to the owner when the owner is back", () => {
  const { net, store } = make({ sloppy: true });
  const [first, second, third] = store.preference("cart");
  store.crash(second);
  store.crash(third);
  store.put("cart", "v1", { via: first }, () => {});
  net.run(300);
  const holders = store.standIns("cart").filter((id) => store.hintsHeld(id) > 0);
  assert.ok(holders.length >= 1, "a stand-in should hold a hint");
  assert.deepEqual(store.dump("cart")[second], [], "the owner has nothing yet");
  store.recover(second);
  store.recover(third);
  net.run(1000);
  assert.deepEqual(values(store.dump("cart")[second]), ["v1"], "the hint was handed over");
  assert.equal(store.hintsHeld(holders[0]), 0, "a delivered hint is dropped");
});

test("a crashed node keeps what it had, and ignores a message that was already on its way", () => {
  const { net, store } = make();
  const [first, second] = store.preference("cart");
  let v1;
  store.put("cart", "v1", { w: 3 }, (res) => (v1 = res));
  net.run(500);
  store.put("cart", "v2", { via: first, context: [v1.clock] }, () => {});
  store.crash(second); // the write to this node is already in flight
  net.run(1500);
  assert.deepEqual(values(store.dump("cart")[second]), ["v1"]);
});
```

## Step 2: part 1, N, R and W

Part 1 measures what chapter 13.2 promised. There are five nodes, and every key lives on three of them. For each choice of R and W, the script writes a key, and the moment the write is confirmed, it reads the key back through a random node. If the read does not return the new value, it was stale. It also times the writes and the reads. Create `part-1-quorums/trial.js`, which holds the experiment so a test can call it:

```js
// The experiment of part 1, kept apart from the printing so a test can run it.
// Five nodes, every key on N = 3 of them. Write a key with W confirmations, and
// the moment the write is confirmed, read it back through a random node with R
// answers. Count the reads that miss the new value, and time both sides.
import { createNet } from "../../../toolkit/simnet.js";
import { createStore } from "../../../toolkit/dynamo.js";

export const NODES = ["N1", "N2", "N3", "N4", "N5"];
export const N = 3;
export const TRIALS = 300;
export const SETTINGS = [[1, 1], [1, 2], [2, 1], [2, 2], [1, 3], [3, 1]]; // [R, W]

export function measure(r, w, { trials = TRIALS, seed = 11 } = {}) {
  const net = createNet({ seed }); // messages take 5 to 40 ms, like challenge 9
  const store = createStore({ net, nodes: NODES, n: N, r, w });
  const any = () => NODES[Math.floor(net.random() * NODES.length)]; // the node a client happens to reach
  const out = { reads: 0, stale: 0, failedWrites: 0, writeMs: [], readMs: [] };
  for (let i = 0; i < trials; i++) {
    const key = `cart:${i}`;
    net.at(i * 500, () => {
      // Settle version 1 on all N copies, so the only difference is version 2.
      store.put(key, "v1", { w: N, via: any() }, (first) => {
        net.after(100, () => {
          store.put(key, "v2", { context: [first.clock], via: any() }, (second) => {
            if (!second.ok) return void out.failedWrites++;
            out.writeMs.push(second.ms);
            // The write is confirmed. Read it back at once, through another random node.
            store.get(key, { via: any() }, (read) => {
              out.reads++;
              out.readMs.push(read.ms);
              if (!read.versions.some((v) => v.value === "v2")) out.stale++;
            });
          });
        });
      });
    });
  }
  net.run(trials * 500 + 2000);
  return out;
}
```

## Step 3: part 2, failures and hints

Part 2 is the point of a leaderless store. It asks two questions. First, when some of a key's nodes are down, how many writes still succeed, with a strict quorum and with a sloppy one? Second, what is the cost of the sloppy way? Create `part-2-hinted-handoff/trial.js`. Experiment A crashes the last one or two of a key's three nodes and tries to write. Experiment B takes away all three, lets a sloppy write land on two stand-ins, brings the three back, and reads them after a short wait.

```js
// The two experiments of part 2, kept apart from the printing so tests can run them.
import { createNet } from "../../../toolkit/simnet.js";
import { createStore } from "../../../toolkit/dynamo.js";

export const NODES = ["N1", "N2", "N3", "N4", "N5"];

// Experiment A. For each key, crash `down` of the 3 nodes that should hold it,
// then write with W confirmations. What share of the writes succeed?
export function writeSuccess({ down, sloppy, w, trials = 100, seed = 5 }) {
  const net = createNet({ seed });
  const store = createStore({ net, nodes: NODES, n: 3, w, sloppy });
  let ok = 0;
  for (let i = 0; i < trials; i++) {
    const key = `cart:${i}`;
    net.at(i * 1000, () => {
      const victims = store.preference(key).slice(3 - down); // the last `down` of the usual three
      for (const id of victims) store.crash(id);
      store.put(key, "v1", {}, (res) => void (res.ok && ok++));
      net.after(600, () => victims.forEach((id) => store.recover(id)));
    });
  }
  net.run(trials * 1000 + 1000);
  return (100 * ok) / trials;
}

// Experiment B. The whole usual group of a key is away (cut off from the rest).
// A sloppy write lands on two stand-ins, and the group comes back at once.
// `delta` ms later, a client reads the key from the usual nodes. Is it stale?
export function staleAfterReturn({ delta, hints, trials = 100, seed = 8 }) {
  const net = createNet({ seed });
  const store = createStore({ net, nodes: NODES, n: 3, r: 2, w: 2, sloppy: true, hints, hintEveryMs: 100 });
  let stale = 0;
  let reads = 0;
  let writes = 0;
  for (let i = 0; i < trials; i++) {
    const key = `cart:${i}`;
    const start = i * 1500;
    net.at(start, () => {
      const usual = store.preference(key);
      for (const id of usual) store.crash(id);
      store.put(key, "v2", { via: store.standIns(key)[0] }, (res) => void (res.ok && writes++));
      // The group returns after 300 ms, at a random point of the 100 ms hint cycle.
      net.after(300 + net.random() * 100, () => {
        for (const id of usual) store.recover(id);
        net.after(delta, () => {
          store.get(key, { via: usual[0] }, (read) => {
            reads++;
            if (!read.versions.some((v) => v.value === "v2")) stale++;
          });
        });
      });
    });
  }
  net.run(trials * 1500 + 1500);
  return { stale: (100 * stale) / reads, reads, writes };
}
```

## Step 4: part 3, siblings and last write wins

Parts 3 and 4 share one workload, so build it first. Create `challenges/challenge-12-leaderless-kv/cart.js`. Hana, on her phone, talks to node N1. Dina, on her laptop, talks to node N2. They share one cart that starts as eggs and milk. Each trial uses a fresh key and one of three scenarios, and the same scenario can run under three policies for settling a conflict. The file records what each person meant, so it can judge the cart that comes out.

```js
// The cart workload shared by parts 3 and 4. Hana (on her phone, talking to
// node N1) and Dina (on a laptop, talking to node N2) share one cart, which
// starts as eggs and milk. Each trial uses a fresh key and one of three
// scenarios. The same scenario runs under three ways of settling a conflict:
//   "lww"       the store keeps the version with the latest timestamp
//   "siblings"  the store keeps concurrent versions, the app merges them by union
//   "orset"     the cart is a CRDT (your ORSet) and the store merges it
import { createNet } from "../../toolkit/simnet.js";
import { createStore } from "../../toolkit/dynamo.js";
import { ORSet } from "../../toolkit/crdt.js";

const NODES = ["N1", "N2", "N3", "N4", "N5"];

// What each person meant to do, and the cart they meant to end with. skewMs is how far ahead
// N1's clock runs: 0 where the clocks are in sync, 100 ms for a node that missed its time sync.
export const SCENARIOS = {
  "both add": { added: ["tea", "rice"], removed: [], expected: ["eggs", "milk", "rice", "tea"], skewMs: 0 }, // both open the cart, then Hana adds tea and Dina adds rice
  "remove and add": { added: ["tea"], removed: ["milk"], expected: ["eggs", "tea"], skewMs: 0 }, // both open the cart, then Hana removes milk and Dina adds tea
  "one after the other": { added: ["tea", "rice"], removed: [], expected: ["eggs", "milk", "rice", "tea"], skewMs: 100 }, // Hana adds tea; once it is confirmed, Dina reads and adds rice
};

// How the app reads a cart, changes it, and lists its items under each policy.
const policies = {
  lww: {
    resolve: "lww",
    initial: () => ["eggs", "milk"],
    read: (versions) => versions[0].value,
    add: (cart, item) => [...cart, item],
    remove: (cart, item) => cart.filter((x) => x !== item),
    items: (cart) => cart,
  },
  siblings: {
    resolve: "siblings",
    initial: () => ["eggs", "milk"],
    read: (versions) => [...new Set(versions.flatMap((v) => v.value))], // merge siblings by union
    add: (cart, item) => [...cart, item],
    remove: (cart, item) => cart.filter((x) => x !== item),
    items: (cart) => cart,
  },
  orset: {
    resolve: { merge: (a, b) => a.merge(b) },
    initial: () => {
      const cart = new ORSet("setup");
      cart.add("eggs");
      cart.add("milk");
      return cart;
    },
    // Each person works on their own replica, made by merging what the store holds into a fresh set.
    read: (versions, who) => new ORSet(who).merge(versions[0].value),
    add: (cart, item) => (cart.add(item), cart),
    remove: (cart, item) => (cart.remove(item), cart),
    items: (cart) => cart.values(),
  },
};
export const POLICIES = Object.keys(policies);

export function runCarts({ policy, scenario, trials = 200, seed = 21 }) {
  const p = policies[policy];
  const plan = SCENARIOS[scenario];
  const net = createNet({ seed });
  const store = createStore({ net, nodes: NODES, n: 3, r: 2, w: 2, resolve: p.resolve, clocks: { N1: { offsetMs: plan.skewMs } } });
  const out = { trials, right: 0, addsLost: 0, removalsUndone: 0, siblingReads: 0, failures: 0 };

  // A person opens the cart: the app reads it and keeps the context the store gave back.
  const open = (key, who, via, done) =>
    store.get(key, { via }, (read) => {
      if (!read.ok) return void out.failures++;
      done({ cart: p.read(read.versions, `${who}-${key}`), context: read.context });
    });
  // Then they save a changed cart, sending that context with it.
  const save = (key, via, opened, change, done) =>
    store.put(key, change(opened.cart), { via, context: opened.context }, (res) => {
      if (!res.ok) out.failures++;
      done?.();
    });

  const [hanaChange, dinaChange] =
    scenario === "remove and add"
      ? [(cart) => p.remove(cart, "milk"), (cart) => p.add(cart, "tea")]
      : [(cart) => p.add(cart, "tea"), (cart) => p.add(cart, "rice")];

  for (let i = 0; i < trials; i++) {
    const key = `cart:${i}`;
    net.at(i * 1000, () => {
      store.put(key, p.initial(), { w: 3, via: "N3" }, () => {
        net.after(200, () => {
          if (scenario === "one after the other") {
            // Dina opens the cart only after Hana's save is confirmed.
            open(key, "hana", "N1", (hana) => save(key, "N1", hana, hanaChange, () => open(key, "dina", "N2", (dina) => save(key, "N2", dina, dinaChange))));
          } else {
            // Both open the cart first. Then one saves, and the other saves up to 20 ms later.
            const opened = {};
            const ready = () => {
              if (!opened.hana || !opened.dina) return;
              const hanaFirst = net.random() < 0.5;
              net.after(hanaFirst ? 0 : net.random() * 20, () => save(key, "N1", opened.hana, hanaChange));
              net.after(hanaFirst ? net.random() * 20 : 0, () => save(key, "N2", opened.dina, dinaChange));
            };
            open(key, "hana", "N1", (o) => ((opened.hana = o), ready()));
            open(key, "dina", "N2", (o) => ((opened.dina = o), ready()));
          }
        });
      });
    });
    // Much later, read the cart through another node with R = 3 and see what is left.
    net.at(i * 1000 + 800, () => {
      store.get(key, { via: "N4", r: 3 }, (read) => {
        if (!read.ok || read.versions.length === 0) return void out.failures++;
        if (read.versions.length > 1) out.siblingReads++;
        const items = [...p.items(p.read(read.versions, "check"))].sort();
        if (items.join() === plan.expected.join()) out.right++;
        out.addsLost += plan.added.filter((x) => !items.includes(x)).length;
        out.removalsUndone += plan.removed.filter((x) => items.includes(x)).length;
      });
    });
  }
  net.run(trials * 1000 + 2000);
  return out;
}
```

The scenarios are the three cases of chapter 13.6. In "both add", both people open the cart, then Hana adds tea and Dina adds rice at nearly the same moment. In "remove and add", Hana removes milk while Dina adds tea. In "one after the other", Dina opens the cart only after Hana's save is confirmed. In that last scenario, node N1's clock runs 100 ms ahead of the others. A time sync that has been missed for a while does that: 50 ppm for about 33 minutes, by the arithmetic of challenge 9.

## When something goes wrong

**`SyntaxError: The requested module '../../../toolkit/crdt.js' does not provide an export named 'ORSet'`.** You copied a class from chapter 13.8 without `export` in front, or missed one. Open `toolkit/crdt.js` and check that all three classes start with `export`.

**`Cannot find module` with a path that ends in `simnet.js`, `clocks.js`, `hash.js`, `stats.js` or `chart.js`.** A file is in the wrong folder, or you skipped the challenge that makes it. `simnet.js` is from challenge 9, `hash.js` from challenge 8, and `stats.js` and `chart.js` from challenges 1 and 2.

**`percentile is not a function` or `barChart is not a function`.** The helper is not exported. `percentile` must be exported from `toolkit/stats.js`, and both `lineChart` and `barChart` from `toolkit/chart.js`.

**Part 1 shows stale reads where R + W is more than 3.** Look at `addVersion` in `dynamo.js`. A version that another version covers must be dropped, and one that neither covers must be kept. Then check `vcCompare` in your `clocks.js`: run the 10.8 tests again.

**Part 2 table A shows the strict quorum succeeding with two nodes down.** `crash` must cut the node off from every other node, and `handle` must ignore messages for a node in `down`. The test "a crashed node keeps what it had" catches the second mistake.

**Part 3 shows sibling counts that never come down.** The app must send `read.context` with the write. In `cart.js`, check that `save` passes `context: opened.context`.

**A part prints different numbers every time you run it.** The runs are seeded, so the numbers must repeat. Something is using `Math.random()` or `Date.now()` instead of the network's `net.random` and `net.wall`. Search your files for both words.

**Break it on purpose.** See each kind of test fail once before you trust it. In `toolkit/dynamo.js`, delete the line `if (down.has(id)) return;` in `handle`, and run the store tests: "a crashed node keeps what it had, and ignores a message that was already on its way" fails, because a node that is down stored a write that was already on its way. Undo it. Then change `if (!sloppy || !down.has(owner))` to `if (true)` in `put`: the sloppy tests fail with `a sloppy quorum borrows a stand-in`. Undo that. Then delete the line `if (byKey?.get(m.key) === m.sent) byKey.delete(m.key);`: "a stand-in keeps a hint and hands it to the owner when the owner is back" fails with `a delivered hint is dropped`.
