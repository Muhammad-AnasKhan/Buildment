## How the simulation works

The idea is to run a whole distributed system inside one program. Time is a number in a variable, so two hours of virtual time take a fraction of a second, and the same seed always gives the same run. That matters because a bug you can repeat is a bug you can fix, and a result you can repeat is a result a mentor can check.

Three design choices keep the numbers honest.

**Every node has its own clock, and nobody can read the true time.** The simulation knows the true time, but a node may only call `net.wall(id)`, which returns its own clock: the true time plus an offset plus drift. That is exactly what a real server has. The true time is used only by the test and by the judge, never by a node.

**The vector clock is the judge.** To count mistakes, we need to know which events really caused which. A vector clock tells that exactly (chapter 10.4), so each event carries a vector besides the stamp being tested. A Lamport stamp or a hybrid stamp is then checked against the vector: did the cause get the smaller stamp?

**The messages are random but repeatable.** Delays are random between a minimum and a maximum, and some experiments cut links. The random numbers come from the seeded generator you made in challenge 1, so a run is repeatable.

Next, `toolkit/simnet.js`, the simulated network. Read the comments: they describe what a node can and cannot do. The queue is kept sorted by time, so the program always runs the next thing that would happen. `run` moves virtual time forward, one event at a time, up to the moment you give it.

```js
// toolkit/simnet.js: a small simulated network. Time is virtual (milliseconds
// in a variable), so a two-hour run takes a fraction of a second. Messages
// have random delays and can be dropped or cut off. Every node has a physical
// clock that can start wrong and drift. The same seed gives the same run.
import { seededRandom } from "./stats.js";

export function createNet({ seed = 1, minDelay = 5, maxDelay = 40, dropRate = 0 } = {}) {
  const random = seededRandom(seed);
  const nodes = new Map(); // id -> { onMessage, offsetMs, driftPpm, syncedAt }
  const queue = []; // scheduled work: { at, order, run }, kept sorted by time
  const cutLinks = new Set(); // pairs of nodes that cannot talk, as "a|b"
  let now = 0; // virtual time in ms: the true time, which no node can see
  let order = 0; // keeps work scheduled for the same moment in the order it was added
  const stats = { sent: 0, delivered: 0, dropped: 0 };

  const pair = (a, b) => [a, b].sort().join("|");

  function schedule(at, run) {
    const item = { at, order: order++, run };
    // Binary search for the place that keeps the queue sorted.
    let lo = 0;
    let hi = queue.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (queue[mid].at < at || (queue[mid].at === at && queue[mid].order < item.order)) lo = mid + 1;
      else hi = mid;
    }
    queue.splice(lo, 0, item);
  }

  return {
    get now() {
      return now;
    },
    stats,

    // Add a node. offsetMs is how wrong its clock starts; driftPpm is how fast
    // it gains (positive) or loses (negative), in microseconds per second.
    addNode(id, { onMessage = () => {}, offsetMs = 0, driftPpm = 0 } = {}) {
      nodes.set(id, { onMessage, offsetMs, driftPpm, syncedAt: now });
    },

    // What the node's own clock says right now. Nodes may only use this.
    wall(id) {
      const n = nodes.get(id);
      return now + n.offsetMs + ((now - n.syncedAt) * n.driftPpm) / 1000000;
    },

    // A time sync: the clock is set to the true time, plus an error you choose.
    sync(id, errorMs = 0) {
      const n = nodes.get(id);
      n.offsetMs = errorMs;
      n.syncedAt = now;
    },

    // Send a message. It arrives after a random delay, unless it is dropped or
    // the two nodes are cut off from each other. Returns false when it is lost.
    send(from, to, payload) {
      stats.sent++;
      if (cutLinks.has(pair(from, to)) || random() < dropRate) {
        stats.dropped++;
        return false;
      }
      const delay = minDelay + random() * (maxDelay - minDelay);
      schedule(now + delay, () => {
        stats.delivered++;
        nodes.get(to).onMessage(from, payload);
      });
      return true;
    },

    at(ms, fn) {
      schedule(ms, fn);
    },
    after(ms, fn) {
      schedule(now + ms, fn);
    },
    cut(a, b) {
      cutLinks.add(pair(a, b));
    },
    heal(a, b) {
      cutLinks.delete(pair(a, b));
    },
    random,

    // Run everything scheduled up to a moment in virtual time.
    run(untilMs) {
      while (queue.length > 0 && queue[0].at <= untilMs) {
        const item = queue.shift();
        now = item.at;
        item.run();
      }
      now = untilMs;
    },
  };
}
```

Three details are worth a second look. `wall(id)` is the only way a node may read the time. It adds up three things: the true time `now`, the offset the clock started with, and the drift, which is the microseconds gained per second (`driftPpm`) times the seconds since the last sync. `sync` is a time sync from chapter 10.2: it sets the offset to an error you choose and restarts the drift count. And `send` draws the delay from the seeded random numbers, so the same seed gives the same delays.

## Step 2: part 1, drift

Part 1 measures what chapter 10.2 predicted. Two servers, A and B, drift 50 ppm in opposite directions. A sync leaves up to 1 ms of error, the figure for a quiet network. Pairs of writes, 1 ms apart, land on a random node first and the other node second, each stamped with its node's own clock. If the later write gets a stamp at or below the earlier one, the order is wrong. The script runs two hours of virtual time for five sync intervals, then draws the gap between the two clocks over 30 minutes. Create `part-1-drift/drift.js`:

```js
// Part 1: two servers whose clocks drift in opposite directions, synced every
// T seconds. How far apart do they get, and how often do two writes 1 ms apart
// get timestamps in the wrong order?
import { writeFileSync } from "node:fs";
import { createNet } from "../../../toolkit/simnet.js";
import { exponential } from "../../../toolkit/stats.js";
import { lineChart } from "../../../toolkit/chart.js";

const DRIFT_PPM = 50; // A gains 50 microseconds per second, B loses 50
const SYNC_ERROR_MS = 1; // a sync leaves up to this much error, either way
const HOURS = 2;
const GAP_MS = 1; // the second write happens 1 ms after the first

// Two nodes that sync to the true time every `everySeconds` (0 = only at the start).
function makeNet(everySeconds) {
  const net = createNet({ seed: 3 });
  net.addNode("A", { driftPpm: +DRIFT_PPM });
  net.addNode("B", { driftPpm: -DRIFT_PPM });
  const syncBoth = () => {
    for (const id of ["A", "B"]) net.sync(id, (net.random() * 2 - 1) * SYNC_ERROR_MS);
    if (everySeconds > 0) net.after(everySeconds * 1000, syncBoth);
  };
  syncBoth();
  return net;
}

// Write pairs at random moments: one write on a random node, then a write on
// the other node 1 ms later. Each write is stamped with its node's own clock.
function measure(everySeconds) {
  const net = makeNet(everySeconds);
  let pairs = 0;
  let wrong = 0;
  let worstGap = 0;
  const nextPair = () => {
    const first = net.random() < 0.5 ? "A" : "B";
    const second = first === "A" ? "B" : "A";
    const stamp1 = net.wall(first);
    worstGap = Math.max(worstGap, Math.abs(net.wall("A") - net.wall("B")));
    net.after(GAP_MS, () => {
      pairs++;
      if (net.wall(second) <= stamp1) wrong++; // the later write got the smaller stamp
    });
    net.after(exponential(net.random, 360), nextPair);
  };
  net.after(1, nextPair);
  net.run(HOURS * 3600 * 1000);
  return { pairs, wrongPercent: (100 * wrong) / pairs, worstGap };
}

console.log(`two clocks, ${DRIFT_PPM} ppm each way, ${HOURS} hours, writes ${GAP_MS} ms apart\n`);
console.log("sync every   worst gap ms   writes in wrong order");
const rows = [[1, "1 second"], [10, "10 seconds"], [60, "1 minute"], [600, "10 minutes"], [3600, "1 hour"]];
for (const [seconds, label] of rows) {
  const r = measure(seconds);
  console.log(`${label.padEnd(10)}  ${r.worstGap.toFixed(1).padStart(12)}   ${r.wrongPercent.toFixed(1).padStart(8)}% of ${r.pairs}`);
}

// The chart: the gap between the two clocks for 30 minutes, sampled every 2 minutes.
const synced = makeNet(600);
const never = makeNet(0);
const points = [];
for (let s = 0; s <= 1800; s += 120) {
  for (const net of [synced, never]) net.run(s * 1000);
  points.push({
    x: s / 60,
    "sync every 10 min": Math.abs(synced.wall("A") - synced.wall("B")),
    "never synced": Math.abs(never.wall("A") - never.wall("B")),
  });
}
writeFileSync(new URL("./chart.svg", import.meta.url), lineChart({
  title: "Gap between two clocks (50 ppm each way)",
  xLabel: "minutes",
  yLabel: "gap in milliseconds",
  points,
  series: [{ key: "never synced", color: "#dc2626" }, { key: "sync every 10 min", color: "#2563eb" }],
}));
console.log("\nwrote chart.svg");
```

Its test, `part-1-drift/drift.test.js`, checks the network itself, because every later part stands on it. It checks that 50 ppm gains 180 ms in an hour, that a sync sets the error you give, that delays stay inside their bounds and repeat for the same seed, that a cut link drops messages, and that a clock 3 ms ahead stamps two writes 1 ms apart in the wrong order.

```js
import test from "node:test";
import assert from "node:assert/strict";
import { createNet } from "../../../toolkit/simnet.js";

test("a clock that is 50 ppm fast gains 180 ms in an hour", () => {
  const net = createNet();
  net.addNode("A", { driftPpm: 50 });
  net.run(3600 * 1000);
  assert.ok(Math.abs(net.wall("A") - net.now - 180) < 1e-6, `gained ${net.wall("A") - net.now} ms`);
});

test("a sync sets the clock to the true time plus the error you give", () => {
  const net = createNet();
  net.addNode("A", { driftPpm: 50, offsetMs: 40 });
  net.run(10 * 1000);
  net.sync("A", 0.5);
  assert.equal(net.wall("A") - net.now, 0.5);
  net.run(20 * 1000); // 10 more seconds of drift: 50 us/s x 10 s = 0.5 ms
  assert.ok(Math.abs(net.wall("A") - net.now - 1.0) < 1e-9);
});

test("messages arrive after a delay inside the bounds, and the same seed repeats the run", () => {
  const arrivals = (seed) => {
    const net = createNet({ seed, minDelay: 5, maxDelay: 40 });
    const got = [];
    net.addNode("A");
    net.addNode("B", { onMessage: (from, payload) => got.push([payload, net.now]) });
    for (let i = 0; i < 20; i++) net.at(i * 100, () => net.send("A", "B", i));
    net.run(5000);
    return got;
  };
  const first = arrivals(7);
  assert.equal(first.length, 20);
  for (const [i, at] of first) assert.ok(at - i * 100 >= 5 && at - i * 100 <= 40, `message ${i} took ${at - i * 100} ms`);
  assert.deepEqual(arrivals(7), first);
  assert.notDeepEqual(arrivals(8), first);
});

test("a cut link drops messages until it is healed", () => {
  const net = createNet();
  let got = 0;
  net.addNode("A");
  net.addNode("B", { onMessage: () => got++ });
  net.cut("A", "B");
  assert.equal(net.send("A", "B", "lost"), false);
  net.heal("A", "B");
  assert.equal(net.send("A", "B", "kept"), true);
  net.run(1000);
  assert.equal(got, 1);
  assert.deepEqual(net.stats, { sent: 2, delivered: 1, dropped: 1 });
});

test("with A 3 ms ahead, two writes 1 ms apart are stamped in the wrong order", () => {
  const net = createNet();
  net.addNode("A", { offsetMs: 3 });
  net.addNode("B");
  net.run(1000);
  const first = net.wall("A"); // write 1, on A
  net.run(1001);
  const second = net.wall("B"); // write 2, on B, 1 ms later
  assert.ok(second <= first, `second ${second} should be at or below first ${first}`);
});

## Step 3: part 2, Lamport clocks on a chat

Parts 2, 3 and 4 share one workload. Create `challenges/challenge-9-clocks/chat.js`. It starts four nodes. Each node, at random moments about 100 ms apart, either does a local event or sends a message to a random other node, and the receiving node handles it when it arrives. Every node runs a Lamport clock, a vector clock and a hybrid clock at once, using your code from `toolkit/clocks.js`. Every event is written down with all three stamps and the node's own wall clock.

```js
// A small chat workload on the simulated network, shared by parts 2, 3 and 4.
// Every node runs a Lamport clock, a vector clock and a hybrid clock at once,
// and every event is recorded with all three stamps and the node's wall clock.
import { createNet } from "../../toolkit/simnet.js";
import { exponential } from "../../toolkit/stats.js";
import { HybridClock, LamportClock, vcReceive, vcTick } from "../../toolkit/clocks.js";

export function runChat({ nodes = 4, seconds = 5, talk = 0.6, seed = 1, offsets = [], minDelay = 5, maxDelay = 40 } = {}) {
  const net = createNet({ seed, minDelay, maxDelay });
  const ids = Array.from({ length: nodes }, (_, i) => `N${i + 1}`);
  const events = [];
  const state = {};

  for (const [i, id] of ids.entries()) {
    state[id] = {
      lamport: new LamportClock(),
      vector: {},
      hybrid: new HybridClock(() => Math.floor(net.wall(id))), // the node's own clock, in whole ms
    };
    net.addNode(id, { offsetMs: offsets[i] ?? 0, onMessage: (from, m) => receive(id, m) });
  }

  // Write one event down, with the stamps the node holds right after it.
  function record(node, kind, hlc) {
    const s = state[node];
    events.push({
      node,
      kind,
      lamport: s.lamport.time,
      vector: s.vector,
      hlc,
      physical: Math.floor(net.wall(node)),
      wall: net.wall(node),
    });
  }

  function receive(node, m) {
    const s = state[node];
    s.lamport.receive(m.lamport);
    s.vector = vcReceive(s.vector, m.vector, node);
    record(node, "receive", s.hybrid.receive(m.hlc));
  }

  function act(node) {
    const s = state[node];
    if (net.random() < talk && nodes > 1) {
      const others = ids.filter((id) => id !== node);
      const to = others[Math.floor(net.random() * others.length)];
      const lamport = s.lamport.send();
      s.vector = vcTick(s.vector, node);
      const hlc = s.hybrid.send();
      record(node, "send", hlc);
      net.send(node, to, { lamport, vector: s.vector, hlc });
    } else {
      s.lamport.tick();
      s.vector = vcTick(s.vector, node);
      record(node, "local", s.hybrid.tick());
    }
    if (net.now < seconds * 1000) net.after(exponential(net.random, 100), () => act(node));
  }

  for (const id of ids) net.after(exponential(net.random, 100), () => act(id));
  net.run(seconds * 1000 + 1000); // a last second for messages still on their way
  return { events, net };
}
```

Notice that `record` is called after the clocks have moved, so each event holds the stamps it was given. A send event holds the stamp that travels with the message, and a receive event holds the stamp after the receive rule. Also notice that the hybrid clock reads `Math.floor(net.wall(id))`, the node's own clock in whole milliseconds, never the true time.

Part 2 checks both halves of the Lamport story from chapter 10.3. First, every pair where one event really caused the other, judged by the vector clock, must give the cause the smaller number. Second, among all pairs with different numbers, it counts how many have a smaller number that is a cause and how many are concurrent. Create `part-2-lamport/lamport.js`:

```js
// Part 2: run the chat with Lamport clocks and check both halves of the story.
// The vector clock is used as the judge: it knows which events really caused which.
import { writeFileSync } from "node:fs";
import { runChat } from "../chat.js";
import { vcCompare } from "../../../toolkit/clocks.js";
import { barChart } from "../../../toolkit/chart.js";

const { events, net } = runChat({ nodes: 4, seconds: 5, talk: 0.6, seed: 2 });

let caused = 0; // pairs where one event really caused the other
let conditionBroken = 0; // of those, pairs where the cause did NOT get the smaller number
let smallerCaused = 0; // pairs with different numbers, where the smaller one is a cause
let smallerConcurrent = 0; // pairs with different numbers, but neither event caused the other
for (let i = 0; i < events.length; i++) {
  for (let j = i + 1; j < events.length; j++) {
    const a = events[i];
    const b = events[j];
    const truth = vcCompare(a.vector, b.vector); // "before" or "concurrent": b cannot come before a in the log
    if (truth === "before") {
      caused++;
      if (!(a.lamport < b.lamport)) conditionBroken++;
    }
    if (a.lamport !== b.lamport) {
      const [small, big] = a.lamport < b.lamport ? [a, b] : [b, a];
      const relation = vcCompare(small.vector, big.vector);
      if (relation === "before") smallerCaused++;
      else if (relation === "concurrent") smallerConcurrent++;
    }
  }
}

const different = smallerCaused + smallerConcurrent;
const pct = (n) => ((100 * n) / different).toFixed(1);
console.log(`${events.length} events on 4 nodes, ${net.stats.delivered} messages delivered\n`);
console.log(`Pairs where one event caused the other: ${caused}`);
console.log(`  cause did not get the smaller number:   ${conditionBroken}   (the Clock Condition says 0)\n`);
console.log(`Pairs with different Lamport numbers: ${different}`);
console.log(`  the smaller number is a cause:        ${smallerCaused} (${pct(smallerCaused)}%)`);
console.log(`  neither event caused the other:       ${smallerConcurrent} (${pct(smallerConcurrent)}%)`);

writeFileSync(new URL("./chart.svg", import.meta.url), barChart({
  title: "What a smaller Lamport number means",
  yLabel: "pairs of events",
  groups: [
    { label: "smaller one is a cause", pairs: smallerCaused },
    { label: "neither caused the other", pairs: smallerConcurrent },
  ],
  series: [{ key: "pairs", color: "#2563eb" }],
}));
console.log("\nwrote chart.svg");
```

## Step 6: part 5, an ID generator that survives a clock step back

The last part builds the generator from chapter 10.7. Create `part-5-snowflake-ids/snowflake.js`. A Snowflake-style ID is a 64-bit number: 41 bits of milliseconds since a chosen start, 10 bits of worker number, 12 bits of count. JavaScript numbers are only exact up to 53 bits, so the ID is a `BigInt`. The generator keeps the last millisecond it used. If the clock now reads earlier than that, it waits out a small step back (up to 10 ms by default) and refuses a bigger one with a clear error. If all 4,096 counts of one millisecond are used, it waits for the next millisecond.

```js
// A Snowflake-style ID generator: 41 bits of milliseconds since a chosen
// start, 10 bits for the worker, 12 bits for a count inside one millisecond.
// It never issues the same ID twice, even if the clock goes backwards.
export const DEFAULT_EPOCH = 1_700_000_000_000; // the chosen start: 14 November 2023
const WORKER_BITS = 10n;
const SEQUENCE_BITS = 12n;
const MAX_WORKER = (1 << 10) - 1; // 1023
const MAX_SEQUENCE = (1 << 12) - 1; // 4095

// A real pause, for production use: block this thread for `ms` milliseconds.
const sleepSync = (ms) => Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms);

export class SnowflakeGenerator {
  constructor({ workerId, now = () => Date.now(), wait = sleepSync, epoch = DEFAULT_EPOCH, maxBackwardsMs = 10 }) {
    if (!Number.isInteger(workerId) || workerId < 0 || workerId > MAX_WORKER) {
      throw new RangeError(`workerId must be a whole number from 0 to ${MAX_WORKER}, got ${workerId}`);
    }
    this.workerId = workerId;
    this.now = now;
    this.wait = wait;
    this.epoch = epoch;
    this.maxBackwardsMs = maxBackwardsMs;
    this.lastMs = -1; // the millisecond of the last ID
    this.sequence = 0; // the count inside that millisecond
    this.waitedMs = 0; // for the results: how long we paused in total
  }

  next() {
    let ms = this.now();
    if (ms < this.lastMs) {
      // The clock went backwards. A small step is waited out. A big one is an error.
      const behind = this.lastMs - ms;
      if (behind > this.maxBackwardsMs) throw new Error(`clock moved back ${behind} ms; refusing to issue IDs`);
      this.wait(behind);
      this.waitedMs += behind;
      ms = this.now();
      if (ms < this.lastMs) throw new Error("clock is still behind after waiting");
    }
    if (ms === this.lastMs) {
      this.sequence = (this.sequence + 1) & MAX_SEQUENCE;
      if (this.sequence === 0) {
        // All 4,096 counts of this millisecond are used. Wait for the next one.
        while (ms <= this.lastMs) {
          this.wait(1);
          this.waitedMs += 1;
          ms = this.now();
        }
      }
    } else {
      this.sequence = 0;
    }
    this.lastMs = ms;
    const elapsed = ms - this.epoch;
    if (elapsed < 0 || elapsed >= 2 ** 41) throw new RangeError("the clock is outside the 41-bit range");
    return (BigInt(elapsed) << (WORKER_BITS + SEQUENCE_BITS)) | (BigInt(this.workerId) << SEQUENCE_BITS) | BigInt(this.sequence);
  }
}

// Take an ID apart again: { ms, workerId, sequence }.
export function decode(id, epoch = DEFAULT_EPOCH) {
  return {
    ms: Number(id >> (WORKER_BITS + SEQUENCE_BITS)) + epoch,
    workerId: Number((id >> SEQUENCE_BITS) & BigInt(MAX_WORKER)),
    sequence: Number(id & BigInt(MAX_SEQUENCE)),
  };
}
```

// 1 second mark its clock is stepped back. Compare a generator that trusts the
// clock with the guarded SnowflakeGenerator. Then make a million IDs for real.
import { writeFileSync } from "node:fs";
import { DEFAULT_EPOCH, SnowflakeGenerator } from "./snowflake.js";
import { barChart } from "../../../toolkit/chart.js";

// The generator without a guard: it believes whatever the clock says.
function trustingGenerator(workerId, now) {
  let last = -1;
  let sequence = 0;
  return {
    next() {
      const ms = now();
      sequence = ms === last ? (sequence + 1) & 4095 : 0;
      last = ms;
      return (BigInt(ms - DEFAULT_EPOCH) << 22n) | (BigInt(workerId) << 12n) | BigInt(sequence);
    },
  };
}

function run(rollbackMs, guarded) {
  let tick = 0; // the true time, in ms since the run began
  let behind = 0; // how many ms the clock is behind the true time
  const now = () => DEFAULT_EPOCH + 1000 + tick - behind;
  const wait = (ms) => (behind -= ms); // waiting lets the clock catch up
  const g = guarded ? new SnowflakeGenerator({ workerId: 7, now, wait, maxBackwardsMs: 10 }) : trustingGenerator(7, now);
  const seen = new Set();
  let duplicates = 0;
  let refused = 0;
  for (tick = 0; tick < 2000; tick++) {
    if (tick === 1000) behind = rollbackMs; // the step back
    for (let i = 0; i < 20; i++) {
      try {
        const id = g.next();
        if (seen.has(id)) duplicates++;
        seen.add(id);
      } catch {
        refused++; // the generator said no
      }
    }
  }
  return { duplicates, refused, waitedMs: g.waitedMs ?? 0 };
}

For the 50 ms step it refuses requests for 39 ms, 780 in all, until the clock is within 10 ms of the last time, then waits out the rest. That is the cost of the guard: some delay for small steps, and failed requests for large ones. A caller that retries after a short pause survives both.

The last line shows the opposite worry. A million IDs from four workers took well under a second, with no pause, because each worker made far fewer than 4,096 IDs per millisecond. All million are unique.

## When something goes wrong

**`SyntaxError: The requested module '../../../toolkit/clocks.js' does not provide an export named 'HybridClock'`.** You copied a piece from chapter 10.8 without `export` in front, or missed one. Open `toolkit/clocks.js` and check that all seven pieces start with `export`.

**`barChart is not a function` or `lineChart is not a function`.** The chart helpers are not exported. Both must be in `toolkit/chart.js` with `export` in front.

**A part prints different numbers every time you run it.** The runs are seeded, so the numbers must repeat. Something is using `Math.random()` or `Date.now()` instead of the network's `net.random` and `net.wall`. Search your files for both words.

**Part 2 shows a Clock Condition count that is not 0.** One of your clocks from chapter 10.8 is wrong. Run the 10.8 tests again. The most common cause is a Lamport `receive` that forgets to add 1.

**Part 4 shows hybrid mistakes.** Your `HybridClock.receive` has a wrong branch. Test the four cases of the rule by hand with the worked example in chapter 10.8, and check that `receive` reads `now()` only once.

**Part 5 loops forever.** The test's `wait` does not move the fake clock. With a fake clock, `wait(ms)` must advance it, as in the test file, or the loop that waits for the next millisecond never ends.

**Break it on purpose.** See each kind of test fail once before you trust it.
