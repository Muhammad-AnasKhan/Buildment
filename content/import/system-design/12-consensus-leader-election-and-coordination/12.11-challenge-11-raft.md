## How the simulation works

The idea is the same as in challenge 9: run the whole distributed system inside one program. Time is a number in a variable, so seconds of virtual time take milliseconds of real time, and the same seed always gives the same run. That matters even more here. A Raft bug often shows up only in one unlucky order of messages. If the run repeats, you can find that order, fix the bug, and prove it with a test.

Three design choices keep the numbers honest.

**A node keeps what a real server would keep.** A real Raft server writes its term, its vote and its log to disk before it answers, so a crash and restart does not erase them. In the simulation, `crash()` stops the node and throws away only what a real crash would lose: its role, its timers, its commit index. The term, the vote and the log stay. A node that forgot its vote after a restart could vote twice in one term, which is exactly the bug the rules exist to stop.

**Messages can be late, lost, or never sent.** The network gives every message a random delay of 5 to 20 ms, the range chapter 12.5 used for its broadcast time. A cut link drops messages. A crashed node sends and receives nothing. The nodes cannot see the true time or know whether a link is cut. They only see the messages that arrive and the timers they set themselves.

**Everything random comes from one seed.** The delays and the election timeouts both draw from `net.random`, the seeded generator. A run with seed 5 is the same every time, and a run with seed 6 is a different story. The experiments use seeds 1 to 200, and the tests use seeds that you can name in a bug report.

## Step 2: a node that can win an election

Create `challenges/challenge-11-raft/raft.js`. It holds the node for part 1: it can be a follower, a candidate or a leader, it keeps a random election timer, it asks for votes and answers vote requests with your `handleRequestVote`, and a leader sends heartbeats. It already carries a `log` list and sends its last entry in every vote request, because the vote rule needs it, but it does not copy entries yet. That comes in part 2.

Read the comments. The most important idea is the timer. A node has only one election timer. When it sets a new one, it adds 1 to a number called `timer`. When the old timer fires, it checks whether its number is still the newest one. If not, someone reset the timer in the meantime, and the old one does nothing. This is how a heartbeat "cancels" the timeout without any way to delete a scheduled call.

```js
// Challenge 11: a Raft node that can win and lose elections. It keeps a log and
// sends heartbeats, but it does not copy log entries yet: that is part 2.
// Everything runs on toolkit/simnet.js, so time is virtual and a run repeats.
import { createNet } from "../../toolkit/simnet.js";
import { handleRequestVote, majority } from "../../toolkit/raft-rules.js";

export class RaftNode {
  constructor({ id, peers, net, trace, electionMin = 150, electionMax = 300, heartbeatMs = 50 }) {
    Object.assign(this, { id, peers, net, trace, electionMin, electionMax, heartbeatMs });
    // Persistent state: a crash does not erase it.
    this.currentTerm = 0;
    this.votedFor = null;
    this.log = []; // entries: { term, command }; the first entry is index 1
    // Volatile state: a crash erases it.
    this.role = "follower";
    this.up = true;
    this.votes = new Set();
    this.timer = 0; // a timer only fires if no newer timer was set after it
    this.leaderId = null;
  }

  get clusterSize() {
    return this.peers.length + 1;
  }

  start() {
    this.resetElectionTimer();
  }

  note(kind) {
    this.trace.push({ at: this.net.now, node: this.id, term: this.currentTerm, kind });
  }

  send(to, message) {
    if (this.up) this.net.send(this.id, to, message);
  }

  broadcast(message) {
    for (const peer of this.peers) this.send(peer, message);
  }

  // One election timer per node. Setting a new one cancels the old one,
  // because the old one finds that its number is out of date.
  resetElectionTimer() {
    const mine = ++this.timer;
    const wait = this.electionMin + this.net.random() * (this.electionMax - this.electionMin);
    this.net.after(wait, () => {
      if (this.up && mine === this.timer && this.role !== "leader") this.startElection();
    });
  }

  startElection() {
    this.role = "candidate";
    this.currentTerm += 1;
    this.votedFor = this.id;
    this.votes = new Set([this.id]);
    this.note("candidate");
    this.resetElectionTimer(); // if this round splits, try again after a new random wait
    const last = this.log.length;
    this.broadcast({
      type: "rv",
      term: this.currentTerm,
      lastLogIndex: last,
      lastLogTerm: last > 0 ? this.log[last - 1].term : 0,
    });
    if (this.votes.size >= majority(this.clusterSize)) this.becomeLeader();
  }

  becomeFollower(term) {
    if (term > this.currentTerm) {
      this.currentTerm = term;
      this.votedFor = null;
    }
    if (this.role !== "follower") this.note("follower");
    this.role = "follower";
  }

  becomeLeader() {
    this.role = "leader";
    this.leaderId = this.id;
    this.timer += 1; // cancels any election timer
    this.note("leader");
    this.onBecomeLeader();
    this.sendAppendEntries();
    const term = this.currentTerm;
    const beat = () => {
      if (!this.up || this.role !== "leader" || this.currentTerm !== term) return;
      this.sendAppendEntries();
      this.net.after(this.heartbeatMs, beat);
    };
    this.net.after(this.heartbeatMs, beat);
  }

  onBecomeLeader() {} // part 2 uses this to set up its bookkeeping

  // A heartbeat is an AppendEntries message with no entries.
  sendAppendEntries() {
    this.broadcast({ type: "ae", term: this.currentTerm, entries: [] });
  }

  onMessage(from, m) {
    if (!this.up) return;
    if (m.term > this.currentTerm) this.becomeFollower(m.term); // a newer term always wins
    if (m.type === "rv") this.handleRequestVote(from, m);
    else if (m.type === "rvr") this.handleVoteReply(from, m);
    else if (m.type === "ae") this.handleAppendEntries(from, m);
    else if (m.type === "aer") this.handleAppendReply(from, m);
  }

  handleRequestVote(from, m) {
    const state = { currentTerm: this.currentTerm, votedFor: this.votedFor, log: this.log };
    const result = handleRequestVote(state, { ...m, candidateId: from });
    this.currentTerm = result.state.currentTerm;
    this.votedFor = result.state.votedFor;
    if (result.reply.voteGranted) this.resetElectionTimer(); // only a granted vote postpones my own election
    this.send(from, { type: "rvr", ...result.reply });
  }

  handleVoteReply(from, m) {
    if (this.role !== "candidate" || m.term !== this.currentTerm || !m.voteGranted) return;
    this.votes.add(from);
    if (this.votes.size >= majority(this.clusterSize)) this.becomeLeader();
  }

  handleAppendEntries(from, m) {
    if (m.term < this.currentTerm) {
      this.send(from, { type: "aer", term: this.currentTerm, success: false });
      return;
    }
    this.becomeFollower(m.term); // a candidate that hears a leader of its own term gives up
    this.leaderId = from;
    this.resetElectionTimer();
    this.send(from, { type: "aer", term: this.currentTerm, success: true });
  }

  handleAppendReply() {} // part 2

  // For experiments: stop the node, or bring it back with its persistent state.
  crash() {
    this.up = false;
    this.role = "follower";
    this.timer += 1;
  }

  restart() {
    this.up = true;
    this.role = "follower";
    this.leaderId = null;
    this.resetElectionTimer();
  }
}

// Build a cluster of n nodes on one simulated network.
export function makeCluster({ n = 5, seed = 1, NodeClass = RaftNode, minDelay = 5, maxDelay = 20, dropRate = 0, ...options } = {}) {
  const net = createNet({ seed, minDelay, maxDelay, dropRate });
  const ids = Array.from({ length: n }, (_, i) => `S${i + 1}`);
  const trace = [];
  const nodes = {};
  for (const id of ids) {
    nodes[id] = new NodeClass({ id, peers: ids.filter((x) => x !== id), net, trace, ...options });
    net.addNode(id, { onMessage: (from, m) => nodes[id].onMessage(from, m) });
  }
  for (const id of ids) nodes[id].start();
  return { net, nodes, ids, trace };
}

// The running node that thinks it is the leader, if any. If an old leader on the
// wrong side of a partition still thinks so, the one with the newest term is returned.
export function currentLeader(cluster) {
  const leaders = Object.values(cluster.nodes).filter((x) => x.up && x.role === "leader");
  leaders.sort((a, b) => b.currentTerm - a.currentTerm);
  return leaders[0] ?? null;
}

// Cut every link between two groups of nodes, or mend them.
export function cutGroups(net, groupA, groupB) {
  for (const a of groupA) for (const b of groupB) net.cut(a, b);
}

export function healGroups(net, groupA, groupB) {
  for (const a of groupA) for (const b of groupB) net.heal(a, b);
}
```

Four details deserve a second look. First, `onMessage` begins with the term rule: any message with a larger term makes the node a follower in that term before it does anything else, as in chapter 12.5. Second, `handleRequestVote` copies the node's term, vote and log into a plain object, calls your rule, and copies the answer back. Your pure function does the thinking, and the node only does the bookkeeping. Third, the election timer is reset only when a vote is granted, never when it is refused, so a candidate with a bad log cannot keep everyone from running. Fourth, `currentLeader` returns the running leader with the newest term. During a split network there can be two nodes that think they lead, and the newest term is the real one.

Now the experiment for part 1. It builds a cluster of five and asks two questions, 200 times each, for three ranges of election timeout. How long does a cold start take, and how many rounds? And when the leader is killed, how long is the cluster without one? Create `part-1-election/election.js`:

```js
// Part 1: how long does a cluster of five go without a leader, and what does the
// random wait before an election buy? Three timeout ranges, 200 runs each.
import { writeFileSync } from "node:fs";
import { currentLeader, makeCluster } from "../raft.js";
import { percentile } from "../../../toolkit/stats.js";
import { barChart } from "../../../toolkit/chart.js";

const RUNS = 200;
const LIMIT_MS = 5000; // give up on an election after 5 seconds

// Run until a leader newer than `afterTerm` exists. Returns the wait in ms, or null.
function waitForLeader(cluster, afterTerm) {
  const start = cluster.net.now;
  while (cluster.net.now - start < LIMIT_MS) {
    cluster.net.run(cluster.net.now + 1);
    const leader = currentLeader(cluster);
    if (leader && leader.currentTerm > afterTerm) return { ms: cluster.net.now - start, leader };
  }
  return null;
}

function trial(seed, electionMin, electionMax) {
  const cluster = makeCluster({ n: 5, seed, electionMin, electionMax });
  const cold = waitForLeader(cluster, 0); // the first election, from a cold start
  if (!cold) return { coldMs: null, rounds: null, failoverMs: null };
  cluster.net.run(cluster.net.now + 500); // let the leader settle
  const old = currentLeader(cluster);
  old.crash(); // the leader dies
  const again = waitForLeader(cluster, old.currentTerm);
  return { coldMs: cold.ms, rounds: cold.leader.currentTerm, failoverMs: again ? again.ms : null };
}

const configs = [
  { label: "150 to 300 ms", min: 150, max: 300 },
  { label: "150 to 160 ms", min: 150, max: 160 },
  { label: "all 150 ms", min: 150, max: 150 },
];

console.log(`5 nodes, messages take 5 to 20 ms, ${RUNS} runs per row\n`);
console.log("timeout range    elected at start  rounds to first leader  failover median  failover p99");
const groups = [];
for (const c of configs) {
  const results = Array.from({ length: RUNS }, (_, i) => trial(i + 1, c.min, c.max));
  const elected = results.filter((r) => r.coldMs !== null);
  const failovers = results.filter((r) => r.failoverMs !== null).map((r) => r.failoverMs);
  const rounds = elected.length ? elected.reduce((s, r) => s + r.rounds, 0) / elected.length : NaN;
  const med = failovers.length ? percentile(failovers, 50) : NaN;
  const p99 = failovers.length ? percentile(failovers, 99) : NaN;
  console.log(
    `${c.label.padEnd(15)}  ${(elected.length + "/" + RUNS).padStart(16)}  ${(Number.isNaN(rounds) ? "none" : rounds.toFixed(2)).padStart(22)}  ` +
    `${(Number.isNaN(med) ? "none" : med.toFixed(0) + " ms").padStart(15)}  ${(Number.isNaN(p99) ? "none" : p99.toFixed(0) + " ms").padStart(12)}`
  );
  groups.push({ label: c.label, median: Number.isNaN(med) ? 0 : med, p99: Number.isNaN(p99) ? 0 : p99 });
}

writeFileSync(new URL("./chart.svg", import.meta.url), barChart({
  title: "Time without a leader after the leader dies",
  yLabel: "milliseconds",
  groups,
  series: [{ key: "median", color: "#2563eb" }, { key: "p99", color: "#dc2626", name: "p99" }],
}));
console.log("\nwrote chart.svg");
```

Its test, `part-1-election/election.test.js`, checks six facts. A cluster of five elects one leader and all nodes agree on the term. The same seed repeats the same elections. In 100 runs where nodes crash and restart at random, no term ever has two leaders. With the leader and two more nodes down, the two that remain cannot elect anyone. A cut-off leader steps down when it hears a newer term. And with no random wait at all, a cold start never elects.

```js
import test from "node:test";
import assert from "node:assert/strict";
import { currentLeader, cutGroups, healGroups, makeCluster } from "../raft.js";

// Which nodes became leader in each term, read from the trace.
function leadersByTerm(trace) {
  const byTerm = new Map();
  for (const e of trace) if (e.kind === "leader") byTerm.set(e.term, [...(byTerm.get(e.term) ?? []), e.node]);
  return byTerm;
}

test("a cluster of five elects one leader, and every node agrees on the term", () => {
  const cluster = makeCluster({ seed: 1 });
  cluster.net.run(1000);
  const leaders = Object.values(cluster.nodes).filter((x) => x.role === "leader");
  assert.equal(leaders.length, 1);
  const terms = new Set(Object.values(cluster.nodes).map((x) => x.currentTerm));
  assert.equal(terms.size, 1, "all five nodes should be in the same term");
  for (const x of Object.values(cluster.nodes)) assert.equal(x.leaderId, leaders[0].id);
});

test("the same seed gives the same elections", () => {
  const run = (seed) => {
    const c = makeCluster({ seed });
    c.net.run(2000);
    return c.trace.map((e) => `${e.at.toFixed(3)} ${e.node} ${e.term} ${e.kind}`);
  };
  assert.deepEqual(run(9), run(9));
  assert.notDeepEqual(run(9), run(10));
});

test("at most one leader per term, in 100 runs where nodes crash and come back", () => {
  for (let seed = 1; seed <= 100; seed++) {
    const cluster = makeCluster({ seed });
    const { net, nodes, ids } = cluster;
    for (let t = 500; t < 8000; t += 400) {
      net.at(t, () => {
        const victim = nodes[ids[Math.floor(net.random() * ids.length)]];
        if (victim.up) victim.crash();
        else victim.restart();
      });
    }
    net.run(9000);
    for (const [term, who] of leadersByTerm(cluster.trace)) assert.equal(who.length, 1, `seed ${seed}, term ${term}: leaders ${who}`);
  }
});

test("with the leader and two more nodes down, the two that remain cannot elect anyone", () => {
  const cluster = makeCluster({ seed: 4 });
  cluster.net.run(1000);
  const leader = currentLeader(cluster);
  const termBefore = leader.currentTerm;
  const others = cluster.ids.filter((id) => id !== leader.id);
  leader.crash();
  cluster.nodes[others[0]].crash();
  cluster.nodes[others[1]].crash();
  cluster.net.run(6000);
  assert.equal(currentLeader(cluster), null, "2 votes out of 5 is not a majority");
  assert.ok(cluster.nodes[others[2]].currentTerm > termBefore + 2, "the live nodes keep trying, so their term keeps rising");
});

test("an old leader that was cut off steps down when it hears a newer term", () => {
  const cluster = makeCluster({ seed: 2 });
  const { net, nodes, ids } = cluster;
  net.run(1000);
  const old = currentLeader(cluster);
  const rest = ids.filter((id) => id !== old.id);
  cutGroups(net, [old.id], rest);
  net.run(2500);
  assert.equal(old.role, "leader", "alone, it still believes it is the leader");
  const fresh = currentLeader(cluster);
  assert.notEqual(fresh.id, old.id);
  healGroups(net, [old.id], rest);
  net.run(3000);
  assert.equal(old.role, "follower");
  assert.equal(old.currentTerm, nodes[rest[0]].currentTerm);
});

test("with no random wait at all, a cold start never elects anyone", () => {
  const cluster = makeCluster({ seed: 1, electionMin: 150, electionMax: 150 });
  cluster.net.run(5000);
  assert.equal(currentLeader(cluster), null);
});
```

## Step 3: a log that is copied and committed

Part 2 adds the log. Create `challenges/challenge-11-raft/raft-log.js`. It extends the node from `raft.js` and changes only the parts that touch the log. A leader accepts a command with `propose`, adds it to its log, and sends each follower the entries it is missing, together with a pointer to the entry just before them. A follower accepts the new entries only if its own log has that entry with the same term, which is the consistency check from chapter 12.6. If it does not, it refuses, and the leader backs up one entry and tries again. When a follower confirms, the leader moves its `matchIndex` and asks your `commitIndexFor` what is now committed. Committed entries are applied, in order, to a small key-value store.

```js
// Challenge 11, part 2: a Raft node that copies its log to the followers, commits
// an entry once a majority holds it, and applies committed entries in order to a
// small key-value store. It extends the node from raft.js and changes only the
// parts that touch the log.
import { RaftNode } from "./raft.js";
import { commitIndexFor } from "../../toolkit/raft-rules.js";

export class LogNode extends RaftNode {
  constructor(options) {
    super(options);
    this.commitIndex = 0; // the highest entry known to be committed
    this.lastApplied = 0; // the highest entry applied to the store
    this.store = {}; // the state machine: key -> value
    this.nextIndex = {}; // leader only: the next entry to send to each follower
    this.matchIndex = {}; // leader only: the highest entry each follower is known to hold
    this.proposedAt = {}; // leader only: when each entry was proposed, for latency
    this.onCommit = null; // an experiment can set this: (index, latencyMs) => {}
  }

  onBecomeLeader() {
    for (const peer of this.peers) {
      this.nextIndex[peer] = this.log.length + 1;
      this.matchIndex[peer] = 0;
    }
    // A new leader starts with an empty entry of its own term. Once that entry
    // commits, every older entry before it commits too.
    this.log.push({ term: this.currentTerm, command: null });
  }

  // A client asks the leader to store a command. Returns the entry's index, or
  // null when this node is not the leader. Not committed yet: that takes a majority.
  propose(command) {
    if (!this.up || this.role !== "leader") return null;
    this.log.push({ term: this.currentTerm, command });
    const index = this.log.length;
    this.proposedAt[index] = this.net.now;
    this.sendAppendEntries();
    this.advanceCommit(); // with a cluster of one, the leader alone is a majority
    return index;
  }

  sendAppendEntries() {
    for (const peer of this.peers) this.sendTo(peer);
  }

  sendTo(peer) {
    const prevIndex = this.nextIndex[peer] - 1;
    this.send(peer, {
      type: "ae",
      term: this.currentTerm,
      prevIndex,
      prevTerm: prevIndex > 0 ? this.log[prevIndex - 1].term : 0,
      entries: this.log.slice(prevIndex, prevIndex + 50), // at most 50 entries per message
      commit: this.commitIndex,
    });
  }

  handleAppendEntries(from, m) {
    if (m.term < this.currentTerm) {
      this.send(from, { type: "aer", term: this.currentTerm, success: false, matchIndex: 0 });
      return;
    }
    this.becomeFollower(m.term);
    this.leaderId = from;
    this.resetElectionTimer();
    // The consistency check: my log must hold the entry just before the new ones,
    // with the same term. If not, refuse, and the leader will back up one step.
    const hasPrev = m.prevIndex === 0 || (m.prevIndex <= this.log.length && this.log[m.prevIndex - 1].term === m.prevTerm);
    if (!hasPrev) {
      this.send(from, { type: "aer", term: this.currentTerm, success: false, matchIndex: 0 });
      return;
    }
    m.entries.forEach((entry, i) => {
      const index = m.prevIndex + 1 + i;
      if (index <= this.log.length && this.log[index - 1].term !== entry.term) this.log.length = index - 1; // a clash: drop my entry and all after it
      if (index > this.log.length) this.log.push(entry);
    });
    const lastNew = m.prevIndex + m.entries.length;
    if (m.commit > this.commitIndex) {
      this.commitIndex = Math.min(m.commit, lastNew);
      this.applyCommitted();
    }
    this.send(from, { type: "aer", term: this.currentTerm, success: true, matchIndex: lastNew });
  }

  handleAppendReply(from, m) {
    if (this.role !== "leader" || m.term !== this.currentTerm) return;
    if (m.success) {
      this.matchIndex[from] = Math.max(this.matchIndex[from], m.matchIndex);
      this.nextIndex[from] = this.matchIndex[from] + 1;
      this.advanceCommit();
    } else {
      this.nextIndex[from] = Math.max(1, this.nextIndex[from] - 1); // back up one entry and try again
      this.sendTo(from);
    }
  }

  advanceCommit() {
    const matchIndex = [this.log.length, ...this.peers.map((p) => this.matchIndex[p])];
    const next = commitIndexFor({ matchIndex, log: this.log, currentTerm: this.currentTerm, commitIndex: this.commitIndex });
    if (next === this.commitIndex) return;
    for (let i = this.commitIndex + 1; i <= next; i++) {
      if (this.onCommit && this.proposedAt[i] !== undefined) this.onCommit(i, this.net.now - this.proposedAt[i]);
    }
    this.commitIndex = next;
    this.applyCommitted();
  }

  applyCommitted() {
    while (this.lastApplied < this.commitIndex) {
      this.lastApplied += 1;
      const { command } = this.log[this.lastApplied - 1];
      if (command && command.key !== undefined) this.store[command.key] = command.value;
    }
  }

  restart() {
    super.restart();
    this.commitIndex = 0; // volatile: relearned from the next leader message
    this.lastApplied = 0;
    this.store = {};
  }
}
```

Three details are worth a second look. In `onBecomeLeader`, a new leader adds an empty entry of its own term. Your commit rule only counts entries from the current term, so this entry gives the leader something it can commit, and committing it commits everything before it. In `handleAppendEntries`, the follower drops its own entries only when one of them has the same index but a different term from the new one. A repeated or late message that carries entries the follower already holds changes nothing. And in `restart`, the commit index goes back to 0, because a real server learns it again from the next leader message. The log itself survives.

```js
// A client sends 100 commands, one every 20 ms. How long does each take to commit
// when 0, 1, 2 or 3 followers are down?
import { writeFileSync } from "node:fs";
import { LogNode } from "../raft-log.js";
import { currentLeader, makeCluster } from "../raft.js";
import { percentile } from "../../../toolkit/stats.js";
import { barChart } from "../../../toolkit/chart.js";

const RUNS = 50;
const COMMANDS = 100;

function trial(seed, down) {
  const cluster = makeCluster({ n: 5, seed, NodeClass: LogNode });
  cluster.net.run(1000); // elect a leader
  const leader = currentLeader(cluster);
  const latencies = [];
  leader.onCommit = (index, ms) => latencies.push(ms);
  const followers = cluster.ids.filter((id) => id !== leader.id);
  for (const id of followers.slice(0, down)) cluster.nodes[id].crash();
  for (let i = 0; i < COMMANDS; i++) {
    cluster.net.at(1000 + i * 20, () => leader.propose({ key: "k" + i, value: i }));
  }
  cluster.net.run(1000 + COMMANDS * 20 + 3000);
  return { latencies, committed: Math.max(0, leader.commitIndex - 1) }; // minus the leader's empty first entry
}

console.log(`5 nodes, ${COMMANDS} commands one every 20 ms, messages take 5 to 20 ms, ${RUNS} runs per row\n`);
console.log("followers down  commands committed  median commit  p99 commit");
const groups = [];
for (const down of [0, 1, 2, 3]) {
  const all = [];
  let committed = 0;
  for (let seed = 1; seed <= RUNS; seed++) {
    const r = trial(seed, down);
    all.push(...r.latencies);
    committed += r.committed;
  }
  const med = all.length ? percentile(all, 50) : NaN;
  const p99 = all.length ? percentile(all, 99) : NaN;
  console.log(
    `${String(down).padStart(14)}  ${(committed / RUNS).toFixed(0).padStart(9)} of ${COMMANDS}  ` +
    `${(Number.isNaN(med) ? "none" : med.toFixed(1) + " ms").padStart(13)}  ${(Number.isNaN(p99) ? "none" : p99.toFixed(1) + " ms").padStart(10)}`
  );

}

writeFileSync(new URL("./chart.svg", import.meta.url), barChart({
```

## Step 4: cut the network in two

Part 3 is the test of everything. It builds a cluster, commits five writes, then cuts the network in two. The old leader goes on one side, alone, with one friend, or with two. It sends five more writes to the old leader, waits for the other side to elect a new leader if it can, sends five more writes there, mends the network, and looks at the logs. Create `part-3-partitions/scenario.js`, the one run that the script and the tests share:

```js
// One partition run, used by partition.js and by the tests.
import { LogNode } from "../raft-log.js";
import { currentLeader, cutGroups, healGroups, makeCluster } from "../raft.js";

// `withLeader` is how many nodes sit on the old leader's side, the leader included.
export function runScenario(seed, withLeader) {
  const cluster = makeCluster({ n: 5, seed, NodeClass: LogNode });
  const { net, nodes, ids } = cluster;
  net.run(1000);
  const old = currentLeader(cluster);
  for (let i = 0; i < 5; i++) old.propose({ key: "before" + i, value: i }); // committed before the cut
  net.run(1500);
  const others = ids.filter((id) => id !== old.id);
  const sideA = [old.id, ...others.slice(0, withLeader - 1)];
  const sideB = others.slice(withLeader - 1);
  cutGroups(net, sideA, sideB);
  const cutAt = net.now;

  const committedAtCut = old.commitIndex;
  for (let i = 0; i < 5; i++) old.propose({ key: "a" + i, value: i }); // sent to the old leader
  // Wait up to 2 seconds for a new leader on the other side, if that side has a majority.
  let newLeader = null;
  let newLeaderMs = null;
  while (net.now - cutAt < 2000) {
    net.run(net.now + 1);
    const found = sideB.map((id) => nodes[id]).find((x) => x.role === "leader" && x.currentTerm > old.currentTerm);
    if (found) {
      newLeader = found;
      newLeaderMs = net.now - cutAt;
      break;
    }
  }
  if (newLeader) for (let i = 0; i < 5; i++) newLeader.propose({ key: "b" + i, value: i });
  net.run(cutAt + 2000);
  const committedOnOldSide = old.commitIndex - committedAtCut; // commits the old leader made while cut off
  const oldThoughtLeader = old.role === "leader";

  healGroups(net, sideA, sideB);
  net.run(net.now + 1500);
  const finalLeader = currentLeader(cluster);
  const keys = new Set(finalLeader.log.map((e) => e.command?.key));
  const lost = [0, 1, 2, 3, 4].filter((i) => !keys.has("a" + i)).length; // accepted by the old leader, gone now
  const kept = [0, 1, 2, 3, 4].filter((i) => keys.has("before" + i)).length;
  const sameLogs = ids.every((id) => JSON.stringify(nodes[id].log) === JSON.stringify(finalLeader.log));
  return { cluster, newLeaderMs, committedOnOldSide, oldThoughtLeader, lost, kept, sameLogs };
}
```

Its test, `part-3-partitions/partition.test.js`, has the strongest check of the challenge. The last test runs 60 clusters through 12 seconds of random crashes, restarts, cut links, mended links and client writes. After every step it checks every node's committed entries against a table of what was committed at each index so far. If any committed entry ever changes, the test fails. At the end it checks that no term had two leaders. This is the safety promise of Raft, tested under abuse.

```js
import test from "node:test";
import assert from "node:assert/strict";

import { currentLeader, cutGroups, healGroups, makeCluster } from "../raft.js";
import { runScenario } from "./scenario.js";

test("a leader on the small side cannot commit anything while it is cut off", () => {
  for (const withLeader of [1, 2]) {
    for (let seed = 1; seed <= 20; seed++) {
      const r = runScenario(seed, withLeader);
      assert.equal(r.committedOnOldSide, 0, `seed ${seed}, ${withLeader} on its side`);
      assert.equal(r.oldThoughtLeader, true, "it does not know it was cut off");
    }
  }
});

test("the big side elects a new leader, and the old leader's writes are overwritten after the cut heals", () => {
  for (const withLeader of [1, 2]) {
    for (let seed = 1; seed <= 20; seed++) {
      const r = runScenario(seed, withLeader);
      assert.ok(r.newLeaderMs !== null && r.newLeaderMs < 1000, `seed ${seed}: new leader after ${r.newLeaderMs}`);
      assert.equal(r.lost, 5, "the 5 writes the old leader accepted were never committed, so they are gone");
      assert.equal(r.kept, 5, "the 5 writes committed before the cut survive");
      assert.equal(r.sameLogs, true, "after healing, all five logs are the same");
    }
  }
});

test("a leader on the big side keeps committing, and nothing is lost", () => {
  for (let seed = 1; seed <= 20; seed++) {
    const r = runScenario(seed, 3);
    assert.equal(r.newLeaderMs, null);
    assert.equal(r.committedOnOldSide, 5);
    assert.equal(r.lost, 0);
    assert.equal(r.sameLogs, true);
  }
});

test("under random crashes, cuts and writes, no term has two leaders and no committed entry changes", () => {
  for (let seed = 1; seed <= 60; seed++) {
    const cluster = makeCluster({ seed, NodeClass: LogNode });
    const { net, nodes, ids } = cluster;
    const committed = new Map(); // index -> the entry that was committed there, as JSON
    let n = 0;
    for (let t = 300; t < 12000; t += 100) {
      net.at(t, () => {
        const r = net.random();
        const a = ids[Math.floor(net.random() * ids.length)];
        const b = ids[Math.floor(net.random() * ids.length)];
        if (r < 0.1) {
          if (nodes[a].up) nodes[a].crash();
          else nodes[a].restart();
        } else if (r < 0.2 && a !== b) cutGroups(net, [a], [b]);
        else if (r < 0.4) healGroups(net, ids, ids);
        else currentLeader(cluster)?.propose({ key: "k", value: n++ });
        // The rule that matters: once an entry is committed anywhere, it never changes.
        for (const node of Object.values(nodes)) {
          for (let i = 1; i <= node.commitIndex; i++) {
            const json = JSON.stringify(node.log[i - 1]);
            if (!committed.has(i)) committed.set(i, json);
            assert.equal(json, committed.get(i), `seed ${seed}: entry ${i} changed after it was committed`);
          }
        }
      });
    }
    net.run(12500);
    const byTerm = new Map();
    for (const e of cluster.trace) if (e.kind === "leader") byTerm.set(e.term, [...(byTerm.get(e.term) ?? []), e.node]);
    for (const [term, who] of byTerm) assert.equal(who.length, 1, `seed ${seed}, term ${term}: leaders ${who}`);
```

## When something goes wrong

**`SyntaxError: The requested module '../../toolkit/raft-rules.js' does not provide an export named 'commitIndexFor'`.** You copied a function from chapter 12.10 without `export` in front, or missed one. Open `toolkit/raft-rules.js` and check that all five start with `export`.

**`Cannot find module` with a path that ends in `simnet.js`, `stats.js` or `chart.js`.** A file is in the wrong folder, or you skipped an earlier challenge. `simnet.js` comes from challenge 9, `stats.js` (with `percentile` and `seededRandom`) from challenge 1, and `barChart` in `chart.js` from challenge 2. Count the `../` steps: `raft.js` is two levels below the top folder, and the part folders are three.

**A part prints different numbers every time you run it.** The runs are seeded, so the numbers must repeat. Something is using `Math.random()` or `Date.now()` instead of `net.random` and `net.now`. Search your files for both words.

**Part 1 shows a cluster that never elects with the normal range.** Check that `resetElectionTimer` picks a new random wait each time, and that `handleVoteReply` ignores a reply from an older term. The test "a cluster of five elects one leader" will tell you if it is a problem with the rules or the node.

**Part 2 commits nothing, even with all nodes up.** Look at `handleAppendReply` and `advanceCommit` in `raft-log.js`. A common mistake is to update `matchIndex` but never call `advanceCommit`, or to forget that the leader's own log counts as one copy in the list passed to `commitIndexFor`.

**Part 3 shows a lost write that was committed.** This is the serious one. Run the last test in `partition.test.js`: it names the seed and the index where a committed entry changed. The usual cause is a vote granted to a server with an out-of-date log, so check `isUpToDate`, or a follower that drops entries when it should only drop on a clash.

**Break it on purpose.** See the tests catch real bugs before you trust them. In `toolkit/raft-rules.js`, change the line `const free = votedFor === null || votedFor === request.candidateId;` to `const free = true;` and run `npm test`. The test "at most one leader per term" fails with `seed 2, term 1: leaders S3,S2`, because a server now votes for every candidate. Undo it. Next, in the same function change `const voteGranted = free && isUpToDate(request, mine);` to `const voteGranted = free;`. A server with an old log can now win, and two tests fail: "a leader on the big side keeps committing, and nothing is lost" with `5 !== 0`, and the random test with `seed 1: entry 5 changed after it was committed`. A committed entry was erased. Undo it. Then in `raft-log.js`, change the consistency check to `const hasPrev = true;`. The test "a follower with the wrong entries is repaired by the leader" fails, because the follower now accepts entries that do not fit and its log no longer matches. Undo that too. Last, delete the line `this.log.push({ term: this.currentTerm, command: null });` in `onBecomeLeader`: the test "a command is stored on every node and applied in order" fails with `20 !== 21`, because the leader's empty entry is missing.
