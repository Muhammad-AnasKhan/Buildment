Three design choices keep the numbers honest.

**Each step is timed on its own.** A browser reports "the page took 400 ms". That number hides the steps. `toolkit/net.js` opens the connection by hand: it asks the operating system for the address, opens TCP, then TLS, then sends one small request, and notes the time at each step. That turns one number into four, and each one can be checked against chapter 3.2.

**The TCP handshake is the ruler.** You do not know how far away `example.com` is from you. But the TCP handshake is exactly one round trip, SYN out and SYN-ACK back. So the script divides every other step by the TCP time, and you can read each step in round trips, not only in milliseconds. If the theory is right, TLS 1.3 should come out near 1.0 and the request near 1.0.

**Medians, not single runs.** One connection can be slow because your Wi-Fi hiccupped. Each step is measured five times and the script reports the median, the middle value, which one bad run cannot move much. You met this idea in chapter 2.4 with percentiles.

## Step 1: the toolkit

Create `toolkit/net.js`. It has three functions. `timeConnection` opens one connection by hand and times each step. `timeRequests` sends requests one after another with a Node.js HTTP agent that either keeps the connection open or does not. `median` picks the middle value. Read the comments on the timing lines: each one names the round trip it measures.

```js
// toolkit/net.js: time the steps of a connection, and send requests one
// after another with or without reusing the connection. No packages needed.
import net from "node:net";
import tls from "node:tls";
import http from "node:http";
import https from "node:https";
import { lookup } from "node:dns/promises";

// Open one connection and time each step: DNS lookup, TCP handshake, TLS
// handshake, then one small request until its first byte comes back.
// All times are in milliseconds.
export async function timeConnection({ host, port = 443, secure = true, tlsVersion = "TLSv1.3" }) {
  const start = performance.now();
  let address = host;
  if (!net.isIP(host)) {
    // Ask the operating system, which asks its DNS resolver or answers from its cache.
    ({ address } = await lookup(host, { family: 4 }));
  }
  const looked = performance.now();
  return new Promise((resolve, reject) => {
    const socket = secure
      ? tls.connect({ host: address, port, servername: host, minVersion: tlsVersion, maxVersion: tlsVersion })
      : net.connect({ host: address, port });
    const times = { dns: looked - start, tcp: 0, tls: 0, firstByte: 0 };
    let connected = 0;
    let asked = 0;
    const ask = () => {
      asked = performance.now();
      socket.write(`HEAD / HTTP/1.1\r\nHost: ${host}\r\nConnection: close\r\n\r\n`);
    };
    socket.once("connect", () => {
      connected = performance.now();
      times.tcp = connected - looked; // SYN out, SYN-ACK back: one round trip
      if (!secure) ask();
    });
    socket.once("secureConnect", () => {
      times.tls = performance.now() - connected; // hello out, keys back
      times.protocol = socket.getProtocol();
      ask();
    });
    socket.once("data", () => {
      times.firstByte = performance.now() - asked; // request out, answer back
      socket.destroy();
      resolve(times);
    });
    socket.once("error", reject);
    socket.setTimeout(10_000, () => socket.destroy(new Error(`no answer from ${host} within 10 s`)));
  });
}

// Send `count` GET requests one after another and time each one. With
// reuse = false every request opens a new connection; with reuse = true
// they share one kept-alive connection. Returns each request's time and
// how many new connections were opened.
export async function timeRequests({ url, count, reuse }) {
  const lib = url.startsWith("https:") ? https : http;
  const agent = new lib.Agent({ keepAlive: reuse, maxSockets: 1 });
  const times = [];
  let newConnections = 0;
  for (let i = 0; i < count; i++) {
    const start = performance.now();
    await new Promise((resolve, reject) => {
      const req = lib.get(url, { agent }, (res) => {
        res.resume(); // read and drop the body
        res.on("end", resolve);
      });
      req.on("socket", () => {
        if (!req.reusedSocket) newConnections++;
      });
      req.on("error", reject);
    });
    times.push(performance.now() - start);
  }
  agent.destroy();
  return { times, newConnections };
}

// The middle value: half the runs were faster, half slower.
export function median(values) {
  const sorted = [...values].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
}
```

Two lines deserve a closer look. `minVersion` and `maxVersion` are set to the same TLS version, so the server cannot pick a different one; that is how part 1 forces TLS 1.2 for comparison. And `req.reusedSocket` is set by Node.js when a request goes out on a connection that an earlier request already opened, so counting the requests where it is false counts the new connections.

## Step 2: part 1, handshakes

Create `part-1-handshakes/handshakes.js`. It times five connections with TLS 1.3 and five with TLS 1.2 against the host you give it, `example.com` by default, takes the median of each step, and prints each step in milliseconds and in round trips.

```js
// Part 1: time DNS, TCP, TLS and the first byte for TLS 1.3 and TLS 1.2,
// and count how many round trips each step took.
import { writeFileSync } from "node:fs";
import { median, timeConnection } from "../../../toolkit/net.js";
import { barChart } from "../../../toolkit/chart.js";

const HOST = process.argv[2] ?? "example.com"; // any HTTPS site that allows HEAD requests
const RUNS = 5; // connections per TLS version; we report the median

const results = {};
for (const version of ["TLSv1.3", "TLSv1.2"]) {
  const runs = [];
  for (let i = 0; i < RUNS; i++) runs.push(await timeConnection({ host: HOST, tlsVersion: version }));
  results[version] = Object.fromEntries(["dns", "tcp", "tls", "firstByte"].map((k) => [k, median(runs.map((r) => r[k]))]));
}

// The TCP handshake is exactly one round trip, so it measures the distance.
const rtt = results["TLSv1.3"].tcp;
console.log(`host ${HOST}, median of ${RUNS} connections each, one round trip is about ${rtt.toFixed(0)} ms\n`);
console.log("step        TLS 1.3 ms  round trips   TLS 1.2 ms  round trips");
const steps = [["DNS", "dns"], ["TCP", "tcp"], ["TLS", "tls"], ["first byte", "firstByte"]];
for (const [name, key] of steps) {
  const a = results["TLSv1.3"][key];
  const b = results["TLSv1.2"][key];
  console.log(
    `${name.padEnd(10)}  ${a.toFixed(0).padStart(10)}  ${(a / rtt).toFixed(1).padStart(11)}   ` +
    `${b.toFixed(0).padStart(10)}  ${(b / rtt).toFixed(1).padStart(11)}`
  );
}
const total = (r) => r.dns + r.tcp + r.tls + r.firstByte;
console.log(`${"total".padEnd(10)}  ${total(results["TLSv1.3"]).toFixed(0).padStart(10)}  ${"".padStart(11)}   ${total(results["TLSv1.2"]).toFixed(0).padStart(10)}`);

writeFileSync(new URL("./chart.svg", import.meta.url), barChart({
  title: `Time for each step of one HTTPS request to ${HOST}`,
  yLabel: "milliseconds (median)",
  groups: steps.map(([label, key]) => ({ label, tls13: results["TLSv1.3"][key], tls12: results["TLSv1.2"][key] })),
  series: [{ key: "tls13", name: "TLS 1.3", color: "#2563eb" }, { key: "tls12", name: "TLS 1.2", color: "#9ca3af" }],
}));
console.log("\nwrote chart.svg");
```

Its test, `part-1-handshakes/handshakes.test.js`, needs no internet. It checks `median`, then starts a tiny local server that waits 30 ms before it answers, and checks that `timeConnection` puts the steps in the right order: no TLS on a plain connection, a quick local TCP handshake, and a first byte no sooner than the server's 30 ms.

```js
import test from "node:test";
import assert from "node:assert/strict";
import net from "node:net";
import { median, timeConnection } from "../../../toolkit/net.js";

test("median is the middle value", () => {
  assert.equal(median([30, 10, 20]), 20);
  assert.equal(median([40, 10, 30, 20]), 25);
});

test("times every step of a plain connection, in order", async () => {
  // A tiny local server that answers any request after 30 ms.
  const server = net.createServer((socket) => {
    socket.once("data", () => setTimeout(() => socket.end("HTTP/1.1 200 OK\r\nContent-Length: 0\r\n\r\n"), 30));
  });
  await new Promise((resolve) => server.listen(0, "127.0.0.1", resolve));
  try {
    const t = await timeConnection({ host: "127.0.0.1", port: server.address().port, secure: false });
    assert.ok(t.dns >= 0, "dns must not be negative");
    assert.equal(t.tls, 0, "no TLS on a plain connection");
    assert.ok(t.tcp >= 0 && t.tcp < 30, `local TCP took ${t.tcp.toFixed(1)} ms`);
    assert.ok(t.firstByte >= 29, `first byte after ${t.firstByte.toFixed(1)} ms, before the server answered`);
  } finally {
    server.close();
  }
});
```

Read it in round trips, the right-hand columns. TCP is 1.0 by definition, because it is the ruler. TLS 1.3 came out at 1.0: one round trip, exactly as RFC 8446 says. TLS 1.2 came out at 2.0: the older version needs one more round trip for a full handshake. The request itself is about 1.0: the HEAD request goes out and its first byte comes back one round trip later, because the server's own work is tiny.

DNS shows about 1 ms. That is not the true cost of a lookup across the internet: the operating system had the answer in its own cache from an earlier run. Run the script right after restarting your machine, and the first DNS number can be much larger. That is the TTL from chapter 3.3, working on your own laptop.

The total, about 375 ms with TLS 1.3 and 485 ms with TLS 1.2, is what one new HTTPS connection costs from this laptop before a single byte of a page arrives. On the same network, a server ten times nearer would cost about a tenth.

## Step 3: part 2, keep-alive

Create `part-2-keep-alive/keepalive.js`. It sends ten GET requests one after another, first with a new connection for each, then on one reused connection, and prints both columns, their totals and how many connections each opened.

```js
// Part 2: send 10 requests one after another, first opening a new connection
// for each, then reusing one kept-alive connection. Compare the times.
import { writeFileSync } from "node:fs";
import { timeRequests } from "../../../toolkit/net.js";
import { lineChart } from "../../../toolkit/chart.js";

const URL_TO_GET = process.argv[2] ?? "https://example.com/";
const COUNT = 10;

const fresh = await timeRequests({ url: URL_TO_GET, count: COUNT, reuse: false });
const reused = await timeRequests({ url: URL_TO_GET, count: COUNT, reuse: true });

console.log(`${COUNT} requests to ${URL_TO_GET}, one after another\n`);
console.log("request  new connection ms  reused connection ms");
const points = [];
let sumFresh = 0;
let sumReused = 0;
for (let i = 0; i < COUNT; i++) {
  sumFresh += fresh.times[i];
  sumReused += reused.times[i];
  points.push({ x: i + 1, new: sumFresh, reused: sumReused });
  console.log(`${String(i + 1).padStart(7)}  ${fresh.times[i].toFixed(0).padStart(17)}  ${reused.times[i].toFixed(0).padStart(20)}`);
}
console.log(`  total  ${sumFresh.toFixed(0).padStart(17)}  ${sumReused.toFixed(0).padStart(20)}`);
console.log(`\nconnections opened: ${fresh.newConnections} without reuse, ${reused.newConnections} with reuse`);

writeFileSync(new URL("./chart.svg", import.meta.url), lineChart({
  title: "Total time for N requests in a row",
  xLabel: "requests sent",
  yLabel: "milliseconds, added up",
  points,
  series: [{ key: "new", color: "#dc2626" }, { key: "reused", color: "#2563eb" }],
}));
console.log("wrote chart.svg");
```

The test, `part-2-keep-alive/keepalive.test.js`, uses a local server that counts the TCP connections it accepts. Without reuse, five requests must open five connections; with reuse, they must share one. This is the test that tells you the agent setting really does what you think.

```js
import test from "node:test";
import assert from "node:assert/strict";
import http from "node:http";
import { timeRequests } from "../../../toolkit/net.js";

// A local server that counts the TCP connections it accepts.
async function countingServer() {
  let connections = 0;
  const server = http.createServer((req, res) => res.end("ok"));
  server.on("connection", () => connections++);
  await new Promise((resolve) => server.listen(0, "127.0.0.1", resolve));
  return { url: `http://127.0.0.1:${server.address().port}/`, count: () => connections, close: () => server.close() };
}

test("without reuse, every request opens a new connection", async () => {
  const s = await countingServer();
  try {
    const r = await timeRequests({ url: s.url, count: 5, reuse: false });
    assert.equal(r.times.length, 5);
    assert.equal(r.newConnections, 5);
    assert.equal(s.count(), 5);
  } finally {
    s.close();
  }
});

test("with reuse, five requests share one connection", async () => {
  const s = await countingServer();
  try {
    const r = await timeRequests({ url: s.url, count: 5, reuse: true });
    assert.equal(r.newConnections, 1);
    assert.equal(s.count(), 1);
  } finally {
    s.close();
  }
});
```

## Step 4: part 3, polling versus WebSockets

Part 3 needs a chat server. Create `challenges/challenge-2-network-costs/chat-server.js`. It publishes five messages at fixed times after each `/reset`, offers them four ways, and counts every request, every pushed message and every byte on its connections. The WebSocket part is a deliberately tiny version of RFC 6455: it answers the upgrade request and sends small text frames, which is all this experiment needs.

```js
// A tiny chat server that offers the same messages four ways: polling,
// long polling, server-sent events and a WebSocket. It counts every request,
// every WebSocket message and every byte on the wire, so the four can be compared.
import http from "node:http";
import { createHash } from "node:crypto";

// When each message is "written", in ms after /reset. Override with SCHEDULE="200,500".
const SCHEDULE = (process.env.SCHEDULE ?? "1200,1900,5600,8300,10400").split(",").map(Number);
const HOLD_MS = Number(process.env.HOLD_MS ?? 20000); // longest time a long poll is held

let messages = []; // { id, text, sentAt }
let timers = [];
let listeners = new Set(); // called with each new message
let stats = { requests: 0, pushes: 0 };
const sockets = new Map(); // socket -> bytes already counted before the last reset

function publish(text) {
  const msg = { id: messages.length + 1, text, sentAt: Date.now() };
  messages.push(msg);
  for (const listener of listeners) listener(msg);
}

function reset() {
  for (const t of timers) clearTimeout(t);
  messages = [];
  listeners = new Set();
  stats = { requests: 0, pushes: 0 };
  for (const socket of sockets.keys()) sockets.set(socket, socket.bytesRead + socket.bytesWritten);
  timers = SCHEDULE.map((ms, i) => setTimeout(() => publish(`message ${i + 1}`), ms));
}

const newer = (after) => messages.filter((m) => m.id > after);
const json = (res, body) => {
  res.writeHead(200, { "content-type": "application/json" });
  res.end(JSON.stringify(body));
};

const server = http.createServer((req, res) => {
  const url = new URL(req.url, "http://localhost");
  const after = Number(url.searchParams.get("after") ?? 0);
  if (url.pathname === "/reset" || url.pathname === "/stats") {
    sockets.delete(req.socket); // control requests are not part of the comparison
    if (url.pathname === "/reset") reset();
    let bytes = 0;
    for (const [socket, before] of sockets) bytes += socket.bytesRead + socket.bytesWritten - before;
    return json(res, { ...stats, bytes });
  }
  stats.requests++;
  if (url.pathname === "/poll") return json(res, newer(after)); // answer at once, even if empty
  if (url.pathname === "/long") {
    if (newer(after).length) return json(res, newer(after));
    const onMessage = () => { finish(); json(res, newer(after)); };
    const timer = setTimeout(() => { finish(); json(res, []); }, HOLD_MS); // hold, then give up
    const finish = () => { clearTimeout(timer); listeners.delete(onMessage); };
    listeners.add(onMessage);
    req.on("close", finish);
    return;
  }
  if (url.pathname === "/events") {
    res.writeHead(200, { "content-type": "text/event-stream", "cache-control": "no-cache" });
    const send = (m) => { res.write(`id: ${m.id}\ndata: ${JSON.stringify(m)}\n\n`); stats.pushes++; };
    newer(Number(req.headers["last-event-id"] ?? 0)).forEach(send); // resume after a reconnect
    listeners.add(send);
    req.on("close", () => listeners.delete(send));
    return;
  }
  res.writeHead(404).end();
});

server.on("connection", (socket) => sockets.set(socket, 0));

// WebSocket: answer the upgrade request, then push each message as one
// small text frame (RFC 6455). Messages from the client are not needed here.
server.on("upgrade", (req, socket) => {
  stats.requests++;
  const accept = createHash("sha1").update(req.headers["sec-websocket-key"] + "258EAFA5-E914-47DA-95CA-C5AB0DC85B11").digest("base64");
  socket.write(`HTTP/1.1 101 Switching Protocols\r\nUpgrade: websocket\r\nConnection: Upgrade\r\nSec-WebSocket-Accept: ${accept}\r\n\r\n`);
  const send = (m) => {
    const payload = Buffer.from(JSON.stringify(m));
    socket.write(Buffer.concat([Buffer.from([0x81, payload.length]), payload])); // final text frame, under 126 bytes
    stats.pushes++;
  };
  listeners.add(send);
  socket.on("close", () => listeners.delete(send));
  socket.on("error", () => listeners.delete(send));
});

server.listen(0, "127.0.0.1", () => {
  const { port } = server.address();
  if (process.send) process.send({ port }); // started by toolkit/load.js
  else console.log(`chat server on http://127.0.0.1:${port}/`);
});
```

Then `part-3-polling-vs-websockets/clients.js`, four ways for an app to hear about new messages. Each one runs for a set time and returns the messages it got and how late each one was. The server-sent events client reads the stream by hand with `fetch`, so you can see that SSE is plain text; in a browser, `EventSource` does this for you and also reconnects by itself. `WebSocket` is built into Node.js 22 and later.

```js
// Four ways for a chat app to hear about new messages. Each one runs for
// `ms` milliseconds and returns the messages it got, with each one's delay:
// how long after the server had it the client saw it.
const seen = (got, m) => got.push({ id: m.id, delay: Date.now() - m.sentAt });
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

// Polling: ask every `everyMs`, whether or not anything happened.
export async function polling({ base, ms, everyMs }) {
  const got = [];
  let after = 0;
  const end = Date.now() + ms;
  while (Date.now() < end) {
    const list = await (await fetch(`${base}/poll?after=${after}`)).json();
    for (const m of list) { seen(got, m); after = m.id; }
    await sleep(everyMs);
  }
  return got;
}

// Long polling: ask, and let the server hold the question until it has news.
export async function longPolling({ base, ms }) {
  const got = [];
  let after = 0;
  const stop = AbortSignal.timeout(ms);
  try {
    while (true) {
      const list = await (await fetch(`${base}/long?after=${after}`, { signal: stop })).json();
      for (const m of list) { seen(got, m); after = m.id; }
    }
  } catch (err) {
    if (err.name !== "TimeoutError") throw err;
  }
  return got;
}

// Server-sent events: one request, then read events from the open answer.
export async function serverSentEvents({ base, ms }) {
  const got = [];
  try {
    const res = await fetch(`${base}/events`, { signal: AbortSignal.timeout(ms) });
    const decoder = new TextDecoder();
    let buffer = "";
    for await (const chunk of res.body) {
      buffer += decoder.decode(chunk, { stream: true });
      let end;
      while ((end = buffer.indexOf("\n\n")) >= 0) { // a blank line ends one event
        const data = buffer.slice(0, end).split("\n").find((line) => line.startsWith("data: "));
        buffer = buffer.slice(end + 2);
        if (data) seen(got, JSON.parse(data.slice(6)));
      }
    }
  } catch (err) {
    if (err.name !== "TimeoutError") throw err;
  }
  return got;
}

// WebSocket: one upgraded connection; the server pushes each message.
export function webSocket({ base, ms }) {
  return new Promise((resolve, reject) => {
    const got = [];
    const ws = new WebSocket(`${base.replace("http", "ws")}/ws`);
    ws.onmessage = (event) => seen(got, JSON.parse(event.data));
    ws.onerror = () => reject(new Error("the WebSocket failed to open"));
    setTimeout(() => { ws.close(); resolve(got); }, ms);
  });
}
```

```js

import http from "node:http";
import { writeFileSync } from "node:fs";
import { spawnServer } from "../../../toolkit/load.js";

const base = server.url.replace(/\/$/, "");
// Control calls use their own short connection, so they are not counted.
const control = (path) => new Promise((resolve, reject) => {
  http.get(`${base}${path}`, { agent: false }, (res) => {
    let body = "";
    res.on("data", (c) => (body += c));
    res.on("end", () => resolve(JSON.parse(body)));
  }).on("error", reject);
});

const ways = [
  ["polling 1 s", () => polling({ base, ms: SECONDS * 1000, everyMs: POLL_MS })],
  ["long polling", () => longPolling({ base, ms: SECONDS * 1000 })],
  ["SSE", () => serverSentEvents({ base, ms: SECONDS * 1000 })],
  ["WebSocket", () => webSocket({ base, ms: SECONDS * 1000 })],
];

console.log(`5 messages in ${SECONDS} s, one client\n`);
console.log("way            got  requests  pushes  bytes  mean delay ms  max delay ms");

for (const [name, run] of ways) {
  await control("/reset");
  const got = await run();
  const s = await control("/stats");
  const delays = got.map((m) => m.delay);
  const mean = delays.reduce((a, b) => a + b, 0) / delays.length;
  groups.push({ label: name, requests: s.requests });
  console.log(
    `${name.padEnd(13)}  ${String(got.length).padStart(3)}  ${String(s.requests).padStart(8)}  ${String(s.pushes).padStart(6)}  ` +
    `${String(s.bytes).padStart(5)}  ${mean.toFixed(0).padStart(13)}  ${Math.max(...delays).toFixed(0).padStart(12)}`
  );
}
server.stop();

writeFileSync(new URL("./chart.svg", import.meta.url), barChart({
  title: `HTTP requests to deliver 5 messages in ${SECONDS} s`,
  yLabel: "requests",
  groups,
  series: [{ key: "requests", name: "requests", color: "#2563eb" }],
}));
console.log("\nwrote chart.svg");
```

## When something goes wrong

**`getaddrinfo ENOTFOUND example.com` or `no answer from example.com within 10 s`.** Parts 1 and 2 need the internet. Check that a browser can open the site. If your network blocks it, pass another HTTPS host you are allowed to test as the first argument, for example `node .../handshakes.js your-own-site.example`. The tests do not need the internet, so `npm test` still works.

**Part 1 fails with an SSL or "protocol version" error.** The host no longer accepts TLS 1.2. That is a good sign for the host, and bad luck for the comparison. Try another host, or change the script to measure TLS 1.3 only and say so in your results.

**TCP is under 5 ms but TLS takes hundreds.** Something on your machine or network, such as a VPN, a proxy or security software, is answering the TCP handshake itself and making the real connection further away. Your ruler then measures the wrong distance. Note it in your results, and try again without the VPN if you can.

**Every number is different each run.** Wi-Fi and mobile networks vary from second to second. That is why part 1 takes medians. Run it three times and report the run in the middle, or all three.

**`WebSocket is not defined`.** Your Node.js is older than version 22. Run `node --version`; the repository needs Node.js 24.

**Part 3 shows fewer than 5 messages for one way.** Something stopped that client early, usually an error printed above the table. Run the test file on its own, `node --test challenges/challenge-2-network-costs/part-3-polling-vs-websockets/realtime.test.js`, which names the way that failed.
